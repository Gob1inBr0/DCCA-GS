# 分析论文提纲：无模型码流的代价（2026-10-19）

> 工作标题：**The Price of a Model-Free 3DGS Bitstream: When Self-Contained Beats Learned Compression**
> 本稿当时的 venue 首选为 DCC 2027（期刊扩展 IEEE TCSVT）；2026-10-20 起由 ICME2027 版提纲接续。
> 数据来源：DCCA `experiments.csv`、3DGSmixNeRF `experiments.csv`、规划文档 §15–§16。

## 0. 一句话论点

**DCCA 用 42–48% 的满精度码率，换来了"码流不依赖任何学习模型"的部署属性；这笔交易在 garden/train 上只落后 HAC++ 0.2–0.3 dB，在 truck 上落后 1.3 dB，解码 14.3 s 而渲染 6–7 s。真正的问题不是"谁压缩率更高"，而是"在什么场景、什么客户端、什么延迟预算下，自包含码流值得这个溢价"。** 自包含的价值在部署，不在压缩率。

## 1. 贡献（三条，按证据强度）

1. **把"零模型"的代价拆成可测的三块**：学习式上下文模型的熵增益（HAC++ 33–40%）、DCCA 的静态表/层帧溢价（42–48%）、头部本身的字节（PCGS 1.27–2.60 MB；ProGS B_ref 0.382 MB；OIC-GS 低码率 header+MLP 32%）。结论：**代价主要不是头部，是失去学习式熵模型。**
2. **给出场景相关的基座对照**（同分辨率、同大小）：

| 场景 | DCCA | HAC++ | Δ |
|---|---|---|---|
| garden | 26.8183 @ 9.4588 | 27.0117 @ 8.9933 | −0.193 dB / +5.2% MB |
| train | 21.8467 @ 3.6145 | 22.1229 @ 3.1433 | −0.276 dB / +15.0% MB |
| truck | 24.4425 @ 3.8823 | 25.7659 @ 3.7641 | −1.323 dB / +3.1% MB |

   **"无模型"不是普遍免费，也不是普遍落后；truck 是反例。** 定论需更多场景（室内/bicycle/stump）；truck 反例的候选解释：锚点/视角/纹理、SPA/MiniSplat 的场景依赖，机制未定。
3. **给出部署侧的时间画像**：DCCA 解码 14.331 s（10 个语义块，0.335–2.224 s/块），渲染稳态 6–7 s/档（P0–P2 6.2–6.8 s；P3 首跑 152.5 s 属 warmup，不计入稳态）；解码是主要成本，且是 CPU/constriction，不是 HAC++ 的 CUDA 块长（HAC++ chunk=1000，−72% 的数字不能直接套用）。**"可截断"要变成"可部署"，还得解解码时间。**

## 2. 测量口径

- 同一场景、同一分辨率、同一视角、同一训练步数；DCCA 的 `EVAL_FACTOR` 必须等于训练 factor（Stage 0 的教训）；HAC++ 同协议。
- 三个对照：同大小、同画质、同延迟。指标：PSNR/SSIM/LPIPS、MB、解码 s、TTFF、编码 s。
- 明确"不能比"的跨场景数字：ProGS 10.75 MB 是 17 场景平均；PCGS 27.81@12.19 是 Mip360 平均。

## 3. 决策规则

三个条件同时满足时，自包含码流值得溢价：

1. 客户端不能/不愿携带模型版本（版本解耦、离线交付、长期归档）；
2. 需要"一个文件多档画质"（带宽未知/异构客户端）；
3. 场景在基座可比区（garden/train 类，而不是 truck 类）。

否则，单码率 HAC++ 更划算。

## 4. 边界与既知限制

- 只有 3 个场景的同大小点；11 景矩阵未完成；truck 反例机制未解释；
- 解码时间只在 garden 上测了一次，P3 warmup 未完全分离（数据文件 `decode_profile_garden_f2.json`）；
- 没有真实带宽轨迹/客户端实验；
- DCCA 的 1-78 内部场景不能公开，garden/train/truck 是公开替身。

## 5. 与三轴融合的关系

- 本文是**方案 B（分析）**，不是 2+3 方法论文；它把 Stage 0 的负结果（2×2 方向 3 弱、truck 弱、解码 14.3 s）变成论文的"边界"。
- 若后续 1+2 系统原型（并行解码/上下文深度）成功，本文可作为系统论文的"测量"前半部分，或独立投 DCC；若 11 景矩阵显示 DCCA 在多数场景落后 1 dB 以上，"场景相关"结论更强，但仍可发表。
