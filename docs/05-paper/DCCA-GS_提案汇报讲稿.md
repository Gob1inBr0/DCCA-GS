# DCCA-GS 提案汇报稿（对应提案的事实整理）

> 对应 Word 提案：`3366-14-M0015-DCCA-GS Decoder-Reproducible Content-Adaptive
> Compression for Anchor-Based 3D Gaussian Splatting.docx`。
> 本稿为该提案汇报的内容整理，保留全部规格与数字。

## 0. 提案构成

DCCA-GS：面向锚点式三维高斯泼溅的解码端可复现内容自适应压缩。保留 HAC++ 主链路（结构化锚点、哈希网格上下文、条件熵模型、算术编码、G-PCC 几何），做三个改动：

1. 解码端可复现的内容自适应量化（FQ+RSS，联合设计）；
2. 混合精度的 MLP 权重量化；
3. 训练侧锚点稀疏 SPA（GaussianSpa-style 的训练侧稀疏预算，ADMM 投影）。

部署要求：压缩率高之外，解码端必须自包含、可复现、推理高效。

## 1. 基线 HAC++

- 每锚点维护特征 f、缩放 s 和 K = 10 个候选偏移 o(i,k) 及学习掩码 m(i,k)，特征维度 50；
- mask-aware 熵模型做属性联合分布分解，被掩码的偏移维度不编码；
- 多分辨率哈希网格 + mlp_grid 预测每字段的均值、方差（scale）、混合权重和基础量化步长 logits qa/qs/qo；
- 符号用整数 CDF 算术编码，锚点坐标用 G-PCC；
- 训练、编码、解码共用同一条条件模型路径，是各端可复现的基础。

与原版自适应量化 AQM 的关系：原版 q = Q0 × (1 + tanh(r))，r = MLP_q(f^h)。FQ 保留该框架，只升级输入和目标：输入换成解码端可重建的四维结构描述符，目标换成 RSS 的渲染敏感度监督。

## 2. 创新点一：解码端可复现的内容自适应量化（FQ+RSS）

**FQ（步长由解码端重算，零侧信息）**

- 步长公式：Q = Q0 × (1 + tanh(z) × α)，α = 0.35，用于 feature、scaling、offset；
- logits z 来自小复杂度网络 mlp_complexity，输入为四维结构描述符：局部锚点密度、预测缩放各向异性、预测偏移能量、有效掩码比例；
- 四个量全部由解码端从锚点坐标、mlp_grid 输出和已解码掩码重建，编码端与解码端同输入同规则，步长逐比特一致；
- 码流中无逐锚点步长数组；Q0 对特征、缩放、偏移分别取 1、0.001、0.2。

**RSS（同一网络的训练目标）**

- 累积每锚点渲染损失梯度范数的指数滑动平均，有界归一化后作为目标乘子，监督同一复杂度网络逼近渲染敏感度最优的步长；
- 只影响训练目标，编码和解码仍走 FQ 公式路径，不增加任何码流字段。

**联合设计的依据**（提案 Table 4）

| 对比 | 发现 |
| --- | --- |
| FQ 单独（无 SPA） | +0.002 dB，几乎无贡献 |
| RSS 在 SPA 下 | +0.42 dB，低码率关键 |
| FQ 在 SPA 下（无 RSS） | −0.29 dB，反而有害 |
| FQ+RSS 联合（SPA 下） | +0.13 dB |

高码率下 RSS 约 +0.1 dB；按联合设计报告，不在低码率工作点单独讨论 FQ。

## 3. 创新点二：混合精度 MLP 权重量化

- 解码侧 MLP 共六组：熵模型侧 mlp_grid、mlp_deform、mlp_complexity；渲染侧 mlp_opacity、mlp_cov、mlp_color；
- 按输出通道做对称量化，静态算术编码压缩整数索引；
- 位宽：复杂度和形变网络 8 位，其余（opacity、cov、color、grid）16 位；
- 依据逐 MLP 敏感性消融：8 位不透明度直接伤渲染；8 位网格使熵模型变差、属性码率增加约 0.25 MiB；复杂度、形变 8 位几乎无损；
- 量化后重新生成属性码流，压缩后 MLP 载荷替换 float32 口径计入报告体积：5.65 → 5.49 MiB，无任何侧信息。

## 4. 创新点三：训练侧锚点稀疏 SPA

- 与编码端 top-k 剪枝的区别：SPA 在训练中用 ADMM 硬预算直接控制锚点数，剪掉后幸存锚点在预算下继续训练；
- 软得分 a = mean(mask)，对 K 个候选偏移取平均；每 100 步 ADMM 更新：z = TopK(a+u, κ)，u = clamp(u+a−z, −1, 1)；
- 预算 κ = round(max(N_ref) × ratio(t))，锚定历史最大锚点数乘线性斜坡，避免 ratio × N(t) 调度的“每轮减半”几何塌缩；
- 增广损失进训练，SPA 状态不写进码流；
- 结果：相同锚点数下比编码端 top-k 高 5.5 dB；解码载荷约 4.38 MB → 1.13 MB（≈74%），代价 0.84 dB PSNR，定义为低码率工作点。

## 5. 实验协议与主结果

- 数据集：4-28（室外无人机航拍，1200 张训练图像、150 个验证视角）；Deep Blending（室内手持、以物体为中心的 playroom 与 drjohnson）；
- 评估统一在解码后的真实码流上：1600 宽、data_factor = 1、test_every = 8，体积按解码必需载荷（MiB）计，指标 PSNR/SSIM/VGG-LPIPS；
- 4-28：110k 迭代 + MLP 量化 28.82 dB / 5.49 MiB，HAC++ 论文同场景参考点 28.31 dB / 6.95 MiB（+0.51 dB，体积约 −21%）；开 SPA 后 28.30 dB / 3.77 MiB，体积再省约 31%；
- Deep Blending：高码率点 playroom 30.73 dB / 4.22 MiB（SSIM 0.913）、drjohnson 30.04 dB / 6.85 MiB；SPA 低码率点 29.90 dB / 0.96 MiB、28.76 dB / 1.55 MiB，进入现有综述方法未覆盖的亚 1 MiB 区间；
- RD 行为：λ 从 0.001 扫到 0.004，playroom 体积 5.80 → 3.01 MB、drjohnson 9.63 → 4.76 MB，PSNR 几乎不变（30.62–30.73 dB 与 30.04–30.09 dB 区间内），码率可连续切换。

## 6. 体积与可信度

- 字段级分解：特征、缩放、偏移三类属性合计约 82.8%；哈希参数 + 边界/头部合计不到 0.5%；
- 编码效率：实际码流比特 / 模型交叉熵接近 1.0，算术编码器贴紧熵模型；
- KL 审计：缩放字段至少 0.49 bit/符号的模型侧冗余下界；
- 所有码流通过独立解码验证：符号、量化步长、整数 CDF 不匹配数均为零；压缩比最高约 111 倍；
- 体积口径 = 解码必需载荷：G-PCC 锚点坐标 + 特征/缩放/偏移算术流 + 掩码 + 哈希参数 + 压缩后 MLP 载荷 + 边界/头部；不含检查点与调试数据。

## 7. 已记录的负结果

跨锚点条件熵增益低于 2.3%；残差编码无收益；敏感度侧信息与解码端可重算输入的相关性接近零。说明熵模型输入侧和编码器本身已接近饱和，进一步压缩的空间在表示侧（锚点数、步长、模型载荷），即三个创新点的选点依据。
