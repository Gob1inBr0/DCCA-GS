## 0. TL;DR

1. **共享基建（本轮唯一新原语）**：`bits_ema`——熵模型 5% 子采样（RD 损失
   本来就在算）的逐锚点编码比特估计，EMA 累积全量覆盖。一个缓冲同时喂
   方向 1（码率感知选择）和方向 3（每比特重要度监督目标）。
2. **方向 1**：预算的记账单位从"锚点个数"换成"比特"。两臂：rate 折扣
   （score/bits^τ，安全臂）与比特预算（B = κ×中位数比特，贪心填充，完全臂）。
   依据是自己的每锚点成本分解：锚点 −45% 时每锚点成本 +33%，体积由结构选择
   决定而非锚点数——现有 ADMM 对此完全盲。
3. **方向 2**：次模 v1/v2 代码已就位（`submodular.py`，A2/A3 臂），v2 即
   "敏感度加权覆盖"。队列带 `submod_keep>0` 硬验证门槛。约束去留由 A4 消融
   （次模 + 覆盖约束 off）回答——若次模过门，硬约束降级为消融脚注。
4. **方向 3**：复杂度乘子的监督目标从"敏感度"升级为"每比特敏感度"
   （sens / bits），把 RD 分配的码率侧补进 I6——量化路径扩展的最小可行形态。
5. **方向 4**：Fisher 平方 EMA（近免费，零额外反向）、holdout 恢复闸门
   （κ ramp 冻结，Phase 2a）、验证集学权重（坐标搜索 w/γ，替代手调 0.7/0.3）。
6. **查新结论（证据 B）**：损失级 RD 优化在 3DGS 压缩是主流做法（RDO-Gaussian、
   CAT-3DGS、ADC-GS、PCGS 等）；**"训练侧剪枝投影按每锚点比特预算做选择"
   未检索到先例**。投稿声称前需人工精读确认（§1）。

## 1. 查新：码率感知剪枝预算（方向 1）

### 1.1 检索记录（2026-09-13，两轮 web 检索 + 既有调研文档比对）

检索词：`rate-distortion aware pruning anchor Gaussian splatting bit budget`、
`pruning neural compression bit cost importance score rate-aware ADMM`。
对照既有调研文档的六谱系（训练统计量/贡献度覆盖/一阶可学习/二阶显著性/
恢复机制/优化理论）——谱系表内无"比特预算选择"条目。

检索到的最近工作（全部是**损失级**码率感知，不是**选择级**）：

| 工作 | 码率进入哪里 | 与方向 1 的差异 |
| --- | --- | --- |
| [RDO-Gaussian](https://arxiv.org/abs/2411.19842)（论文 refs wang2024a） | RD 损失 | 无训练侧选择/预算概念 |
| [CAT-3DGS](https://nycu-mapl.github.io/CAT-3DGS_page/)（ICLR 2025） | RD 损失 + 熵模型 | 同上 |
| [ADC-GS](https://www.ijcai.org/proceedings/2025/0132.pdf)（IJCAI 2025） | 多维熵模型 RD | 锚点系但无比特预算投影 |
| [PCGS](https://ojs.aaai.org/index.php/AAAI/article/view/37304/41266)（AAAI） | 渐进 mask 增锚 | 预算是渐进加入，非比特记账 |
| [CSGaussian](https://arxiv.org/html/2601.12814v1) | RD 压缩+分割 | 与剪枝选择正交 |
| [End-to-End RD 3DGS](https://arxiv.org/html/2406.01597v2) | RD 损失 + 剪枝 | 剪枝按重要性，不按比特 |
| [Structured Pruning for LIC](https://arxiv.org/html/2506.01229v1) | 图像压缩网络剪枝 | 对象是熵模型网络本身 |

### 1.2 结论与风险

- **结论**：方向 1 的组合——"ADMM 训练侧稀疏化 + 每锚点比特估计 + 比特记账
  预算"——在检索范围内无先例；与损失级 RDO 正交（可叠加，不冲突）。
- **风险**：检索为浅层（证据 B）。投稿级声称前必须：①人工精读 ADC-GS 与
  PCGS 全文确认无同构机制；②补一轮 Semantic Scholar / arXiv 全文检索
  "bit budget" + "pruning" + "gaussian"；③经典编码文献里 rate-control
  （如 MPEG 码率控制）只作用量化参数不作用元素选择，引用说明即可。

## 2. 共享基建：`bits_ema`（逐锚点比特估计）

**数据源（零额外前向）**：`_estimate_rate_terms` 每训练步已在 5% 锚点子采样上
算 `bit_feat / bit_scaling / bit_offsets`（熵模型逐元素比特）。新增：逐锚点求和
`b_i = Σ三组`，`index_add` 进全量 `bits_ema[N,1]`，decay 0.995——约 100 步覆盖
全部锚点。与 RD 损失同源，detached，训练侧 only，解码端零 footprint。

**审计**：启动 banner（`[TrainerVer]`）打印全部 round-2 旗标；PruneLog 新增
`bits_med=... tau=... bit_budget=kappa->N`（生效证据）与
`gate_fired=`/`fisher_engaged=`；Fisher / sens_per_bit 失效回退时各有一次
显式告警打印（教训 3：getattr 静默默认的对策）。

**对齐**：新缓冲已进全部对齐循环（gaussian_model.py 4 处：anchor_growing /
prune_anchor 补齐与选择×2 / append_depth_anchors；hacpp.py 1 处：
load_state_dict 兜底）。
**审计注（2026-09-13 三审查修复）**：①`append_depth_anchors` 一处是本轮新
发现并修复的遗漏点；②审查发现并修复了一个**既有 P0**——adjust_anchor 末尾
曾对逐锚点缓冲手动切片、随后 prune_anchor 又把短缓冲补零回 N 再选一遍，
导致每次投影后部分幸存者的缓冲值被替换成 0（spa_z / coverage_ema /
sensitivity_feat 等老缓冲同样中招）。修复方式：删除手动切片，
prune_anchor 成为唯一选择点。**注意这会改变老缓冲的历史行为**，同步到
服务器前必须让在跑的 ph1 队列跑完，并在 CSV 登记行为变更点。

## 3. 方向 1：码率感知剪枝预算（D1）

### 3.1 动机（自己的数据）

- 每锚点成本分解（组会汇报 §2.3）：同 λ 下我们 808k×158 bit vs HAC++
  938k×233 bit，每维特征效率相同——**体积差来自结构选择，不来自锚点数**；
- 深剪枝代价：锚点 −45% → 每锚点成本 **+33%**——剪得越深，幸存者越贵，
  锚点数预算对此完全盲；
- 结论：真正稀缺的是比特，不是锚点。预算应按比特记账，选择应按
  "重要度 / 比特"排序。

### 3.2 设计（两臂，独立消融）

```text
臂 R1（rate 折扣，安全臂）:  rank by (a+u 或融合分) / b_i^τ   预算仍 κ 个锚点
臂 R2（比特预算，完全臂）:   B = κ × median(b)；按分数贪心保留至 Σb ≤ B
                             下限 κ/2（防退化），上限由 B 天然给出
```

- `b_i` 为 `bits_ema`（正中位数归一，clamp [0.25, 4]），无估计锚点中性排序；
- 估计覆盖率 <10%（或 <1000 锚）时该周期退化为普通投影——天然 warm-up；
- 与次模互斥（R2 不进次模路径）；与融合可叠加（R3 = fusA + R1）；
- τ ∈ [0, 2] 硬限；默认 1.0。

### 3.3 实验矩阵与判定门（预注册）

全部 1-78 · 30k · r_post=0.85 · λ=0.004（选择压力最大档）· seed 42 探索、
**采纳判定必须 {42,104} 双种子**：

| 臂 | 配置 | 对照 | 判定门 |
| --- | --- | --- | --- |
| R1 | base + rate 折扣 τ=1.0 | ph0c_base_r085_lam0004（26.983 @ 11.08） | 同尺寸 ±2% 下 ΔPSNR ≥ +0.10 |
| R2 | base + 比特预算 | 同上 | ΔPSNR ≥ +0.10 且 \|Δsize\| ≤ 2%；或任意点 ≥ +0.15 |
| R3 | fusA + rate 折扣 | ph0c_fusA_r085_lam0004（27.426 @ 11.25） | ≥ max(R1, fusA) + 0.10 |

- 过门 → 该臂进入选择栈固定臂，补 2-06/4-10 泛化 + 60k + 双种子；
- 证负 → 记负结果，bits_ema 基建保留（供方向 3 与分析小节）；
- τ 敏感性：过门臂补 τ ∈ {0.5, 1.5} 两点。

## 4. 方向 2：敏感度加权次模（D2，已在跑）

- **状态**：`submodular.py` v1（纯覆盖）+ v2（`submodular_sens_weighted`，
  边权 ×(1+sens)）代码齐备；ph1 v2 队列（A2→A3，带 `submod_keep>0` 硬门槛）
  已在服务器排队。判定门 G1（均值 Δ ≥ +0.15，≥2/3 λ 同号，双种子）沿用
  期刊版设计 §4.3，不重复。
- **与覆盖硬约束的关系（本轮新增明确）**：次模目标像素只算一次，覆盖性
  由目标函数自带，硬约束理论冗余。A4 消融（次模 + 约束 off @ λ=0.004）
  即"约束能不能不要"的判决实验：
  - A4 ≈ A2（差 ≤0.05 dB）→ 期刊版主配置**去掉硬约束**，降为消融脚注；
  - A4 明显差（>0.10 dB）→ 保留约束，论文叙事改为"软目标 + 硬保险双层"。

## 5. 方向 3：熵感知步长分配（D3，量化路径扩展）

### 5.1 设计

复杂度乘子 I6 的监督目标从"敏感度"升级为"每比特敏感度"：

```text
现状 I6:   target ∝ z(sens_i)                        —— 只看失真侧
D3:        ema_adj = sens_i / clamp(b_i/median(b), 0.25, 4)
           target ∝ ema_adj / mean(ema_adj) - 1      —— 失真/码率联合
```

直觉：同样重要的两个锚点，编码便宜的拿更细的步长（加一点比特换来更多
质量）；编码昂贵的让步。这是 RDO 的"每比特最优"思想进入乘子监督，
实现只动 target 计算（`sensitivity_supervision`），梯度路径与解码契约
不变（bits 只是训练侧目标成分，detached）。

### 5.2 判定门 G-SPB

- base + sens_per_bit vs base（I6 现状）@ r085/λ=0.004，双种子：
  同尺寸 ΔPSNR ≥ +0.10 → 采纳为乘子默认目标，补全矩阵；
- 证负 → 记负结果（"敏感度与每锚点比特的相关性"本身是分析小节素材，
  corr 预检脚本可先跑，无 GPU 成本）。

## 6. 方向 4：三件配件

### 6.1 D4a Fisher 二阶敏感度（近免费）

- `accumulate_sensitivity` 同批梯度顺手累积 E[g²]（三个 [N,1] buffer，
  已进对齐循环）；`sensitivity_score_vector` 在 `sensitivity_use_fisher`
  时切换为 log1p(E[g²])（OBD 式显著性，调研 §8.4/§5.1）；
- 生效证据：PruneLog `fisher_engaged=`；失效回退有一次显式告警；
- 判定门 G-F：fusA + fisher vs fusA @ r085/λ=0.004，双种子，Δ ≥ +0.10
  → 进选择栈；证负 → 归档（buffer 留作分析工具）。

### 6.2 D4b holdout 恢复闸门（Phase 2a）

- 每投影周期后 8 个固定 holdout 相机快测 PSNR（decode 路径，MSE 直算）；
  相对 EMA 基线掉点 > max(3σ, 0.05 dB) → κ ramp 冻结 2 个周期
  （`core.spa_gate_freeze_cycles`，adjust_anchor 内按冻结进度持 κ）；
  终身上限 5 次触发；基线只在健康周期漂移（防训练性慢改进误触发）；
- 判定门 G-GATE（预注册，沿用期刊版 §5.3 的 50% 回收判据）：
  r_post=0.55/λ=0.002 下，闸门臂 vs B0（ph0a 27.285 @ 11.10）：
  ΔPSNR ≥ 0.5 × (27.730 − 27.285) = +0.22 dB 且 size ≤ +2% → 采纳；
  触发率诊断：>20% 周期 = ε 过敏感，回 5.1 重标定；
- 2b 隔离缓冲（ARGP 式回补）本阶段不实现——渲染路径改动大，等 G-GATE
  数据决定是否需要（闸门若够用，缓冲不值得它的复杂度）。

### 6.3 D4c 验证集学权重

- 坐标搜索替代手调：stage 1 w ∈ {0.1, 0.2, 0.3}（γ=0.25 固定，r085/λ=0.004，
  w=0.3 即现有 fusA 基线）→ 最优 w 后 stage 2 γ ∈ {0.1, 0.5}；
- 判定门 G-W：最优组合 ≥ fusA 默认 + 0.05 dB（单种子过筛、双种子确认）
  → 后续所有融合/次模臂统一换用该权重并登记 CSV。

## 8. 静默失效对策（本轮内置）

| 机制 | 生效证据 | 失效告警 |
| --- | --- | --- |
| rate 折扣 / 比特预算 | PruneLog `bits_med=` / `bit_budget=` | 未生效 = 无字段（watcher 11k 步硬门） |
| sens_per_bit | `[SensPerBit] engaged`（首次生效打印） | `[SensPerBit]` 12k 步后回退告警 |
| Fisher | PruneLog `fisher_engaged=`（按投影周期计数） | `[Fisher]` 回退告警（累积侧与选择侧各一） |
| holdout 闸门 | `[HoldoutGate]` 每周期打印 | armed 即打印，缺失 = 未布防；post_ratio=1.0 时显式 NOT armed |
