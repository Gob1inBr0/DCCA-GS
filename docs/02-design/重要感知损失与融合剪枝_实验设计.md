# 重要感知损失 与 融合剪枝 实验设计

> 版本：v0.1（2026-09-03）
> 定位：把"重要性"贯彻到两个可创新的环节——**重建损失（D）** 与 **训练侧剪枝**。
> 前置：`语义感知剪枝与空间上下文_实验设计.md`（方向一已判负）、
> `语义感知剪枝_融合重要性_设计.md`（方向二）、`../01-architecture/训练与压缩全流程说明.md`。

---

## 0. TL;DR

1. 现在重建损失 D 是**逐像素等权**的（标准 3DGS）。创新点 A：**把 D 改成"重要感知"**——
   用重要性图给不同区域不同的权重，让优化把失真压到重要区域、把比特花在刀刃上。
2. 剪枝现在是"按撑得实不实（mask+对偶）"选留。创新点 B：**改成按"融合重要性"选留**——
   敏感度 + 覆盖面积 + 哈希上下文派生 +（可选）语义。
3. 两者**都在训练侧、零码流代价**（不进解码端，无重算墙）。
4. 判定：同体积 PSNR +≥0.05 dB 或同质量体积 −≥2%；逐层消融看哪一层贡献。

---

## 1. 动机：把"重要性"落到损失和剪枝两个可创新处

前面已证明：在解码端 Q 路径上"加信息"收效有限（空间 Δr≈0、DINO 目标错、敏感度 r≈0.29）。
但**训练侧没有重算墙**。所以重要性可以自由用在两个训练侧的地方：

- **损失端（创新 A）**：直接改"画面差多少"的权重 → 影响优化方向，让模型优先保证重要区域。
- **剪枝端（创新 B）**：直接改"留哪些钉子"的判据 → 影响拓扑，让预算留给重要钉子。

---

## 2. 创新 A：重要感知重建损失

### 2.1 现状

```text
D = (1 − λ_dssim)·L1(pred, gt) + λ_dssim·SSIM(pred, gt) + scale_reg
```

每个像素等权重。没区分"某个像素坏了影响大/小"。

### 2.2 方法

```text
D' = Σ_pixel w(p) · d(pred(p), gt(p)) / Σ_pixel w(p)   + λ_dssim·SSIM + scale_reg
```

`w(p)` 是**逐像素重要性图**（0~1），可用下面任一来源：

| 权重来源 | 从哪来 | 强调什么 |
| --- | --- | --- |
| **语义显著性** | 离线 DINO 特征 → 前景/物体/边界更显著 | 物体 vs 平坦背景 |
| **渲染敏感度** | 训练时渲染损失对像素的梯度 | 像素对当前模型"难而重要" |
| **前景/遮挡** | 深度 or SAM2 区域 | 近景 vs 远景 |

**建议首版用 DINO 显著性**（离线、稳定、直指"内容重要"），`w = sigmoid(zscore(显著性))`，
或更简单 `w = 1 + β·显著性`（β 控制强度），并做每步归一化（`Σw`）。

### 2.3 关键属性

- **只训练用**：`w(p)` 不进码流、解码端不出现 → **无重算墙**。
- **直接改 D**：比只在 Q 上加乘子更"底层"——优化方向就偏向重要区。
- **不改变容量**：不改网络/布局，只改 loss 权重。
- **可与创新 B 叠加**：损失让"优化偏向重要区"，剪枝让"拓扑偏向重要钉"。

### 2.4 风险

- `w` 若过度锐利，会把低权重区域（背景）完全放弃，导致背景伪影。
  对策：clamp `w` 到 `[w_min, 1]`（如 `w_min=0.2`），且用 `sigmoid`/`1+β·s` 软加权。
- DINO 有域偏差（无人机 vs 预训练）；建议前景/显著性用同一场景校验。
- SSIM 项仍全图等权；若只加权 L1，SSIM 可能抵消一部分。可尝试对 SSIM 也乘 `w`（首版先只加权 L1 看差异）。

## 3. 创新 B：融合重要性剪枝

（详见 `语义感知剪枝_融合重要性_设计.md`，此处只列要点。）

把 `adjust_anchor` 里的 `scores = (a + spa_u)` 换成融合重要性：

```text
scores = w_mask·norm(a) + w_u·norm(spa_u) + w_sens·norm(敏感度)
       + w_area·norm(贡献面积) + w_ctx·norm(哈希上下文重要性) [+ w_sem·norm(语义)]
```

- 归一化 `norm()`：每分量 z-score（或 min-max），权重才可解释。
- 哈希上下文重要性：训练期小头 `Linear(ctx_dim→1)` 从哈希上下文回归"真实重要性"
  （标签=敏感度+贡献面积），只训练不进码流。
- MiniSplat-full 的 `scores = area` 也换成同一融合分数。

## 4. 消融矩阵（先 playroom 冒烟，再 4-28/drone 30k）

| 组 | 配置 | 验证什么 |
| --- | --- | --- |
| 0 | 基线（无 A、无 B） | 对照 |
| 1 | 仅损失 A（DINO 显著性加权） | 损失端是否有用 |
| 2 | 仅剪枝 B（敏感度+面积+哈希上下文） | 剪枝端是否有用 |
| 3 | A + B 叠加 | 两者是否正交/增强 |
| 4 | A(或 B) + DINO 语义进融合 | 语义消融（域偏差风险） |

指标：PSNR/SSIM/LPIPS、total_MB（float32 与 MLP 量化双口径）、训练时间、显存峰值；
解码后指标必须来自真实 bitstream。

> 建议顺序：先跑组 1（损失改动最小、最快验证），再组 2，再组 3。若组 3 明显优于任一组，说明两创新正交。

---

## 5. 决策规则

1. 组 1/2/3 相对组 0：同体积 PSNR +≥0.05 dB，或同质量体积 −≥2% → 保留。
2. 组 3 优于组 1、组 2 → 两创新正交，都保留；否则只保留贡献更大者。
3. 若某层（如哈希上下文 `w_ctx`）无增量（Δr≈0 或 RD 无差）→ 关掉该层，避免复杂度。
4. 进入下一 stage 前，对优选配置做 λ ∈ {0.0005,0.002,0.004} 的 RD + BD-rate，确认跨码率可用。

## 6. 实现要点

### 6.1 损失 A

- `trainer.py`：算 `w`（从缓存/模型读出逐像素图），`loss_D = (w * (pred-gt)^2).sum()/w.sum()` 替换 L1；
  SSIM 保持全图或乘 `w`（实验开关）。
- 缓存：DINO 显著性在 `extract_semantic_priors.py` 离线提取逐视角显著性图，存 npz；训练每步读。
- 归一化：`w = 1 + β · zscore(显著性)`，`β` 可调（默认 0.5），`w` clamp `[0.2, 2.0]`。

### 6.2 剪枝 B

- `gaussian_model.py` `adjust_anchor`：新增 `_fusion_scores()`，读 `sensitivity_*`、
  `mini_splat_importance`、`calc_context_feat`（经 `importance_head`）、`semantic_*`。
- `config.py`：`fusion_prune` + 各 `fusion_weight_*`（默认关）。
- 新增 `importance_head` 参数组（训练器），不进导出。
- 状态切片：确认 `mini_splat_importance`、新增融合状态在 `prune_anchor` 中被裁剪/同步。

### 6.3 体积护栏

创新 A/B 均不进码流、不改布局；只改 loss 权重与 topk 分数。比较时盯 `total_MB` 双口径与解码后指标，
避免"体积换质量"假增益。
