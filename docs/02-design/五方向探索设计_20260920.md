## 方向一：语义驱动的压缩（DINOv2 先验）

- 已有证据：语义先验与敏感度真值的 Pearson 相关 r=0.6034（达标；
  注意验证集是按 Morton 连续区间切的，空间自相关可能高估——**第 0 道
  门：随机切分复测**，r 掉到 0.15 以下关闭方向）。代码就位的是**监督
  路线**（`semantic_supervision`：DINO 目标监督复杂度乘子的输出），
  与 9 月语义先验设计文档一致。查新需收窄表述："语义先验监督锚点
  复杂度乘子且码流零依赖"未见先例；语义特征蒸馏 + 特征重要性剪枝
  已有相邻工作。
- 红线（不可违反）：**语义先验绝不进解码路径**——乘子是码流组成部分，
  解码端没有图像、算不了 DINO。只能作为训练期监督目标（同 I6 机制）。
  明确写低先验概率：I6-off 已证明这类监督贡献约 0（−0.021 dB）；本
  方向的唯一赌注是"语义目标比敏感度目标更可达"（r=0.60）。
- 最小实验：第 0 道门通过后，30k 全程（1-78，λ=0.002）监督路线
  （T-A）对照四统计量版。冒烟必须跑到监督真实生效的步数之后
  （`semantic_start_iter` 默认 20000，冒烟要改短并加日志硬标记，
  沿用 `[Submod]` 打印惯例；无生效标记不许登记）。
- 及格线（预注册，双种子确认）：ΔPSNR ≥ +0.10 立项；0.05–0.10 介于
  达标与不达标之间（补第三种子）；< +0.05 关闭方向。
- 真实成本：两次 30k 全程训练（不是一次冒烟）。

## 方向二：4D 动态场景锚点压缩

- 已有证据：9 月简报查新——"解码端可重算的内容自适应量化"在 4D 压缩
  检索不到先例；现有资产（RD 协议、逐位还原校验、字段级体积统计）
  可直接迁移。
- 窗口：MPEG 动态高斯测试素材征集 2026-10-15 截止。赶窗口 = 高风险
  （新数据集 + 新时间维 + 新协议）；不赶 = 把 4D 作为期刊版扩展章节。
- 最小实验（不赶窗口版）：拿一组公开动态序列（如 Neu3D/DyNeRF 子集，
  1–2 GB 级），把静态锚点管线原样跑通（每帧独立 + 跨帧共享锚点两档），
  只测"逐帧独立编码 vs 锚点共享 + 帧间残差"的体积差，不训练新模型。
- 及格线：共享锚点方案体积 ≤ 逐帧独立的 60% 且 PSNR 掉幅 ≤ 0.3 dB →
  立项完整设计；否则记负结果。
- 风险：时间维锚点对应关系不稳定；渲染管线对动态支持未知。先花 1 天
  做数据可得性确认再投入。

## 方向三：渐进码流 / 分块解码

- 已有证据：自家负结果——跨锚点邻居条件熵增益不到 1%，说明把锚点
  分组切开的码率代价很小；LOD 曾以"熵模型输入"的形式失败。
- 最小实验（离线可行，110k checkpoint 不改训练）：**共用同一条码流，
  只改解码顺序**（组序号是元数据，比较干净）；同时跑"按组重编码"版时
  横轴必须用"已收到字节 / 自身总字节"并报绝对字节数。三个对照：
  随机分组（弱对照，只要不输即过）、**按渲染贡献降序分组（竞争对照，
  真正的判据）**、Morton 序（卖点：解码端从坐标算出顺序、零元数据）。
  缺锚点时的渲染策略预注册：缺失锚点跳过（不补替身）。
- 及格线：**Morton 对贡献排序**在同比例下 ≥0.3 dB → 立项（Morton 赢
  随机只说明有空间自相关，赢贡献排序才说明有独特价值）；两曲线重合 →
  记负结果（渐进性来自贡献排序，与空间序无关）。立项前须定位与
  PCGS（AAAI 2026 Oral，渐进可伸缩压缩）的机制差别。
- 风险：熵模型按全局统计编码，切组后截断处上下文缺失的代价未测——
  第一小步先量"截断到前 k% 码流的实际可渲染性"。

## 方向四：删后恢复（重新加锚点）

- 已有证据：全部闸门实验同向——删错的锚点救不回来（留出闸门只挽回 7%）；
  "删后恢复"从未立项。深度重初始化本身证明"重新铺锚点 + 继续训练"有效
  （+0.215 dB），这是该方向的正面旁证。
- 最小实验：λ=0.004，在第 18000 步（避开第 15000 步的深度重初始化）
  在预算外重加 2% 锚点（深度重初始化的采样器，限制在覆盖空洞区域），
  预算相应上调 2%，第 27000 步压回原预算至结束。**三臂**：恢复组
  （空洞区 +2%）、**随机放置对照**（中期 +2%、随机位置——区分"空洞
  补锚"和"单纯预算临时放宽"）、恒定基准。生效硬检查：日志记录实际
  加锚数与落入空洞区的比例，无记录不许判读。单种子过筛、双种子确认。
- 及格线（对恒定基准）：恢复组 ΔPSNR ≥ +0.15 且显著高于随机对照 →
  立项；恢复组 ≤ +0.05 或与随机对照无差 → 记负结果；两者之间 → 补
  第三种子再判（预注册无空档）。
- 风险：预算回调会让"删后恢复"和"预算放宽"混杂——对照臂是同预算
  恒定组，恢复组的 2% 只在中期存在。

## 方向五：熵模型单点改进（scaling 字段）

- 已有证据：熵审计显示 scaling 字段还有约 0.49 bit/符号的冗余
  （当前用均匀/单高斯，分布实际重尾多峰）；这是量化主线里最干净
  的单点改进。
- 最小实验（离线大部分可行）：用已有 checkpoint 导出 scaling 字段的
  真实量化符号分布，离线拟合 Laplace / 混合高斯（2-4 分量），重编码
  该字段算理论码长（不用重训练——重编码即可验证）。
- 及格线：重编码后 scaling 字段比特下降 ≥8%（约等于 0.33 MB @ λ0.002）
  且逐位还原通过 → 立项接入训练（量化感知重训 1 run 确认端到端）。
- 风险：小——纯编码端改动，最坏情况是无收益。

## 优先级建议

1. 方向五（离线验证为主，收益确定性最高，接量化主线）
2. 方向一（数据与代码就位，一个冒烟定生死）
3. 方向三（离线 + 轻渲染，用自家负结果反推的正方向）
4. 方向四（一个 1-run 消融定去留）
5. 方向二（数据可得性未确认，窗口压力自选）
