# 背景场 与 ADMM 覆盖约束 设计

> 版本：v0.1（2026-09-06）
> 动机：融合剪枝（敏感度重要性）在**低码率（λ=0.004）崩**（25.95 vs 基线 27.51）。
> 根因：低预算下"敏感度"压过"覆盖"，把敏感度低但**管大片区域**的背景锚点删掉 → 覆盖空洞。
> 目标：① 让背景用**更少/更省**的方式表示；② 让剪枝**从结构上保证覆盖**，不因敏感度偏置删掉覆盖锚点。

---

## 0. 结论速览

- **背景表示**：主推 **方案 D（共享"背景场"，独立码流字段，允许侧信息）**——背景归背景场，锚点只留前景，最治本。B/C/A 为增量备选。
- **剪枝修复**：用 **ADMM 覆盖约束**——保留原 SPA-ADMM 骨架，只把**硬投影步骤**改成"每区域必保 1 颗锚点 + 其余按敏感度补满"。
- **验证**：先改 SPA 硬投影，重跑 **λ=0.004 一个点**：PSNR 若从 25.95 恢复到 ≥27.4，则覆盖约束成立。

## 1. 病根（w_sens 偏置）

### 1.1 现象

```python
imp = normalize( coverage(贡献面积) + w_sens · sensitivity )
scores = imp + 0.25 · (mask + dual)
keep = topk(scores, kappa)
```

低码率（κ 小，锚点稀缺）时，敏感度高的"细节/前景"锚点分数高被保留，敏感度低的"背景/大覆盖"锚点分数低被删 → **覆盖空洞 → 重建崩**。

### 1.2 为什么 w_sens 会偏

敏感度是"渲染损失梯度范数"，**跨量级**；归一化后仍可能把前景抬得很高、背景压得很低。`w_sens` 一高，目标就**过度看重"谁一动变化大"**，忽略"谁在管大区域"。低码率被放大。

### 1.3 解法（三层，从浅到深）

1. **重平衡**：`w_cov ≥ w_sens`，或敏感度归一后封顶（0~0.3）；
2. **预算自适应**：`w_sens(t)` 随预算收紧下降；
3. **覆盖做成约束**（**采用**，治本）：不再用软权重"但愿"，而是硬性"每区域至少 1 颗锚点覆盖"，交给 ADMM。

## 2. 背景表示：4 方案

> 前提：用户允许背景走侧信息 → **方案 D 可行且最干净**。

### 2.1 方案 D：共享"背景场"（独立字段）【推荐】

- **表示**：场景背景用一块**低分辨率辐射/颜色场**（粗体素格点 RGB，或几颗大背景高斯），存为码流独立字段（小，几十 KB）。
- **分工**：背景场负责大片平滑区；**锚点只表示前景/细节**。渲染 = 先铺背景场，再叠前景锚点子高斯。
- **决策（训练侧）**：给锚点算"背景度"（低纹理/低梯度/高覆盖/低敏感度）；背景锚点被**吸收进背景场**，不再作锚点。
- **存储/代价**：新增背景字段（已接受）；需背景度分割；前景/背景边界衔接。
- **优点**：背景锚点基本消失（数量/特征/剪枝问题都没了）；不会误删。

### 2.2 方案 B：背景锚点"少而大"

识别背景锚点 → **合并**成几颗大锚点。仍是锚点，数量少、单颗大。需合并逻辑 + 与剪枝协调。

### 2.3 方案 C：区域共享背景特征

按空间聚成区域，每区域**共享一份背景特征**；背景锚点用共享特征。省特征存储；但锚点位置仍要存。

### 2.4 方案 A：尺度自适应锚点

成长时按"局部信息量"决定锚点大小/密度：平滑区少而大，细节区多而小。需改成长/缩放逻辑 + 平滑区合并。

**优先级：D > B > C > A。**

## 3. ADMM 覆盖约束（剪枝修复，本版实施）

### 3.1 背景：ADMM 是什么

ADMM（交替方向乘子法）解 `min f(x)+g(z), s.t. Ax+Bz=c`：把"连续可训练"与"硬性稀疏"拆成两个子问题**交替解**，用**对偶变量 `u`** 把二者拧一起。

SPA 已是 ADMM：
```python
loss = ρ/2·||a − z + u||²
步1：训练优化 a（软掩码）
步2：z = topk(a + u, κ)          # 硬投影（保留决策）
步3：u += a − z                  # 对偶更新
```

**我们在 `step2`（硬投影）改**：把"覆盖"做成硬约束。

### 3.2 修改点（SCA 硬投影）

```python
# 伪代码：z 更新（覆盖约束版）
1) 画粗 3D 空间网格（cell = anchor / cell_size 取整）
2) 对每个 cell，集合其内锚点
3) mandatory = 每个占用 cell 取分数最高的 1 颗（spa_coverage_min_per_cell）
   （保证每个空间区域至少留 1 颗 → 杜绝区域空洞）
4) score = (a + u)  （敏感度排名仍在）
5) 剩余预算 = κ − |mandatory| → 从非 mandatory 里按 score 补满
6) z = mandatory ∪ filled；u 更新照旧
```

### 3.3 配置（config.py + hacpp.py 接线）

```text
spa_coverage_constraint: bool = False
spa_coverage_cell_size:  float = 0.01      # 场景坐标下粗格边长（按场景尺度调）
spa_coverage_min_per_cell: int = 1
```

### 3.4 为什么能治

步骤 3 **从结构上**保证"每个空间区域都留锚点"；无论敏感度怎么偏，管大面的锚点都不会被删。敏感度只用于排名"非必保"的灵活锚点。

### 3.5 所需数据

锚点位置 `self.get_anchor`（可重算，解码端一致）+ 分数 `score`；粗格占用 → 覆盖代理。成本低、够用。
