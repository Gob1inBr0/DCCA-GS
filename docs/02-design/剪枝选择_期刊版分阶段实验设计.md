## 0. TL;DR

1. **起点状态**：融合剪枝 8 点记分板（fusion 6 + fusA 2）全部落在 ±0.1 dB 噪声带内；
   已证实的价值只剩防坍缩（25.95 dB 崩溃为真实负结果）。ICRA 论文按"安全免费"框架冻结。
2. **核心未解混杂**：复盘问题 6——κ 冻结使后半程不剪枝、增长期仅温和压缩
   （889k→803k）。在"选择决策几乎不发生"的协议下，**任何选择信号都无法证明自己**。
   fusA 把信号修好仍未过门，瓶颈可能不在信号而在协议。
3. **四个阶段，四个假设，四个预注册判定门**：
   - Phase 0（协议修复）：让预算真正咬合，并重测 fusA 解除混杂；
   - Phase 1（次模覆盖选择）：换目标函数——从"逐锚点独立打分"到"冗余感知的集合覆盖"，
     调研确认无先例，是唯一的算法级新颖性赌注；
   - Phase 2（恢复机制）：宏观闸门 + 隔离缓冲，给一切打分方案兜底；
   - Phase 3（可学习打分器）：软门控让打分可导，仅在 Phase 0 证明"决策真实发生"后有意义。
4. **Plan B 明示**：若 Phase 0+1 双双证负（选择在咬合预算下仍是二阶杠杆），
   选择侧以诚实负结果收尾，主力转向量化路径（乘子族扩展）——那是已验证的
   0.41 dB 杠杆所在，另立设计文档。

### 1.2 假设（每个假设对应一个判定门）

- **H1（混杂假设）**：F1/F2 的中性是 F4（预算不咬合）造成的——选择决策量太小，
  好坏信号无差别。→ Phase 0c 检验（G0b）。
- **H2（冗余假设）**：线性逐锚点打分的根本盲区是冗余（两个锚点盖同一批像素
  都得高分）。冗余感知的集合选择在咬合预算下能产生 ≥0.15 dB 增益。→ Phase 1（G1）。
- **H3（可恢复假设）**：错剪损失可通过"验证闸门 + 缓冲回补"回收 ≥50%。→ Phase 2（G2）。
- **H4（可学习假设）**：打分规则可从渲染损失学得且优于手工设计。→ Phase 3（G3）。

依赖关系：H4 依赖 H1 被证实（决策真实发生才有学习信号）；H2/H3 独立可并行。

## 3. Phase 0：协议修复——让预算真正咬合

### 3.0 任务 0.0：κ 冻结的代码级定位（先于一切改动）

复盘问题 6 目前只有锚点数经验证据。改动前必须完成：

1. 通读 `adjust_anchor` 的 κ 三分支（`gaussian_model.py` ~1617-1660）与
   `mini_splat_reinit` 的 `spa_final_n` 钉扎（`hacpp.py:905`），
   写出每步 κ 的实际取值轨迹；
2. 在 base 上加 2.2 节日志跑 400 步冒烟，用 `kappa/N/decisions` 曲线证实
   "后半程 decisions≈0"；
3. 结论写入本节附录（本文件维护），作为 3.1 改动的依据。

#
### 3.0 附录：任务 0.0 结论（2026-09-10，代码级定位）

**关键发现：后半程零选择的主因不是 κ 冻结，而是剪枝循环本身停止。**

1. **调整窗口**：`trainer.py` 的投影条件是 `update_from < iteration < update_until`
   （=15000=reinit 迭代）。reinit 在 15000 执行后，`adjust_anchor` **再也不被调用**，
   15000→30000 的整整一半训练没有任何选择决策。锚点轨迹证实：n 在 15010 = 807,634
   （803,634 + 4,000 个重初始化锚点），直到 29,990 逐点不变。
2. **κ 分支语义**（`gaussian_model.py` adjust_anchor）：非 full 模式下若 post 相位真的
   被调用，κ 会走 `spa_final_n × spa_ratio` 分支（spa_final_n 在 reinit 时被钉为重初始化
   前计数 n_before，spa_ratio=0.85）→ κ ≈ 683k，即 0.85 × 803,634。即"reinit 后
   κ=n×1.0 冻结"的旧表述只对 full 模式成立；非 full 模式的正确表述是
   **"调用停止 + 若调用则 0.85 硬底"**。
3. **增长期决策量**：κ 从 ref×1.0 ramp 到 ref×0.85（ref=首次投影时 N≈889,315），n 在
   投影间因生长反弹、每次投影被剪回 κ。净取舍 ≈ 889k−803k ≈ 86k（峰值的 ~10%），
   分布在 134 个投影周期——**每周期平均取舍数百级，选择压力确实微弱**（H1 的量化依据）。
4. **实现含义**（已按此实现）：r_post 修复 = ①扩展调整窗口进入 post 相位
   （reinit 后 `spa_post_window` 步）；②post 相位**纯选择、禁生长**（reinit 已把锚点
   铺到表面，再生长只会制造预算要删的候选）；③κ 从 post 基准（重初始化后计数）线性
   ramp 到 `post_base × spa_post_ratio`，软启动 2000 步。
5. **PruneLog 已落地**：每投影输出 cycle/step/N/kappa/decisions/engaged/
   cov_p50/p90/p99/provider_fail；provider 失败计数入累计字段。decisions = N−κ 即
   本周期真实取舍数，是 G0a 的核心观测量。

## 3.1 改动设计：post-reinit 预算比 r_post

新增配置 `spa_post_ratio`（默认 1.0 = 完全复现现状）：

```text
reinit 后：κ(t) 从 n_reinit 线性 ramp 到 n_reinit × r_post，历时 2000 步
（软启动，避免瞬时冲击；之后维持该值至训练结束）
```

- 只动 κ 调度，不动打分、不动融合、不动 reinit 本身；
- r_post 档位：{1.0（现状对照）, 0.85, 0.7, 0.55}。

## 4. Phase 1：次模覆盖选择

### 4.1 方法设计

**目标函数替换**（从逐锚点分数到集合覆盖）：

```text
现状（线性代理）：  max Σ_i∈S score_i                —— 冗余不可见
次模覆盖（v1）：    max_{|S|=κ} Σ_p max_{i∈S} c_{i,p}  —— 像素只算一次
次模覆盖（v2）：    同上，但像素权重 × 敏感度           —— 覆盖×重要性的统一
```

**数据源（关键：已存在）**：`compute_contribution_areas`（`mini_splat.py:282`）
的渲染元数据里已经 materialize 了逐像素权重（counts）与像素→锚点归属
（anchor_gids）——二部图每周期免费可得，不需要新渲染。

**工程控制（成本三件套）**：

1. **像素分箱**：8×8 block（PUP 先例），8 视角 ≈ 30 万 block/周期；
2. **候选池**：先按现行线性分数取 top-2κ 作池，贪心只在池内重排——
   "线性粗筛、次模精选"；
3. **lazy greedy**：优先队列 + 陈旧上界剪枝，近线性时间。
   耗时预算：adjust 周期 ≤ +15% 步时（超了先降频到每 2 周期一次）。

**与现有件的整合**：每周期与覆盖 EMA/视角轮换共用同一 provider 数据；
贪心选出的 z 进现有 ADMM 的 u 更新（投影算子换，ADMM 骨架不动）。
覆盖约束（每粗格≥1）默认保留——理论上次模目标自带覆盖性，约束可能冗余，
**on/off 各跑一臂作消融**（F5 的约束在次模下的行为本身是结果）。

### 4.2 实验矩阵（全部在 G0a 选定的 r_post 下）

| 臂 | 说明 | run 数（42 种子） |
| --- | --- | --- |
| A0 | base 线性（0a 已有，引用） | 0 |
| A1 | fusA 乘法调制（0c 已有，引用） | 0 |
| A2 | 次模 v1（纯覆盖贪心） | 3λ |
| A3 | 次模 v2（敏感度加权覆盖） | 3λ |
| A4 | A2 + 覆盖约束 off | λ=0.004 单点（消融） |
| A5 | 池大小敏感性 4κ | λ=0.004 单点（消融） |

### 4.3 判定门（预注册，H2）

双种子三 λ，对 A0（同尺寸匹配）：

- **G1 通过**：均值 Δ ≥ +0.15 dB 且 ≥2/3 λ 同号 → 次模采纳为期刊版核心方法，
  补 2-06/4-10 泛化 + 60k；
- **中间带 +0.05~+0.15**：逐 λ 逐区域归因（哪些区域次模选得不同、差在哪），
  决定加权方案迭代或止步；
- **证负 < +0.05**：H2 死。选择侧以"咬合预算下线性与次模等价、选择是
  二阶杠杆"的系统性负结果收尾（配 0c 结论构成完整证据链），
  **主力执行 Plan B（量化路径扩展）**。

## 5. Phase 2：恢复机制

### 5.1 触发阈值标定（先行，无 GPU 增量）

在 0a 的 base run 上叠加逐周期 holdout PSNR 日志（8 个留出视角，
复用 mini_splat_views 采样设施）：

```text
σ_cycle = 周期间 holdout PSNR 波动标准差（平滑后）
ε（触发阈值）= max(3 × σ_cycle, 0.05 dB)   —— 必须高于噪声、低于真实损伤
```

### 5.2 两档设计

**2a 宏观闸门（保险丝）**：每投影周期后测 holdout PSNR（EMA 平滑），
相对周期前基线掉点 > ε → 冻结 κ ramp（维持当前 κ）W=2 个周期；
连续触发上限 5 次（防死循环），触发全程记 `gate_fired`。

**2b 隔离缓冲（缓刑）**：每轮未进 top-κ 的候选不立即物理删除，冻结
Q=2 周期（不参与渲染、优化器状态保留）；闸门触发则按**删除前分数**回补
top-M（M = 本轮剪除量的 10%），平安到期则物理删除（进入现有 prune_anchor）。
回补判据不依赖死锚点的 u（ARGP 先例：恢复分数只对已剪部分现算）。

### 5.3 实验矩阵与判定门（H3）

在激进档 r_post=0.55（base 已知掉点的压力场景）与常规档 0.85 各跑：

| 臂 | 配置 |
| --- | --- |
| B0 | 无恢复（0a 对照） |
| B1 | 仅闸门 |
| B2 | 闸门 + 缓冲 |

- **G2 通过**：r_post=0.55 下，B1/B2 相对 B0 回收 ≥50% 质量损失
  （ΔPSNR(Bx) ≥ 0.5 × ΔPSNR(B0)），墙钟开销 ≤ +10%，size 变化 ≤ +2%；
  且 r_post=0.85 下无回归（保险不碍事）。
- 闸门触发率本身是诊断：正常档触发 >20% 周期 = ε 过敏感，回到 5.1 重标定。

## 6. Phase 3：可学习打分器（软门控）

### 6.1 前置条件

仅当 G0b（融合复活）或 G1（次模通过）之一成立——证明"决策真实发生且
信号有边际价值"——才启动。否则软门控没有可学的目标差异（考场未开考）。

### 6.2 两级设计

**3a 学标量权重**（最小可行）：软门控时代内 score = w_c·cov + w_s·sens 的
(w_c, w_s) 作为可学习参数，Adam 与模型参数同更新：

```text
软门 g_i = sigmoid((score_i − τ)/T)，乘在锚点 opacity 上（渲染路径小改）
τ = 当轮 top-κ 阈值（detach）；T 从 0.1 线性退火 → 0（硬选择接管）
软门控时代 = [reinit, reinit + 8000 步]
```

护栏：归一化统计量全部 detach（防尺度漂移）；w_s 维持 0.3 硬帽
（撞帽即护栏生效，梯度死区是特性）。

**3b MLP 打分器**（若 3a 有信号）：输入 [cov, sens, a, u, V, max_blend]，
两层 MLP 输出 logit，同软门控训练。对应设计文档
`重要感知损失与融合剪枝_实验设计.md` 中 importance_head 的完全体
（标签从"回归手工分数"改为"软门控端到端"）。

### 6.3 判定门（H4）

双种子三 λ，对 Phase 1/0c 的**最佳固定打分**：

- **G3 通过**：均值 Δ ≥ +0.10 dB 且同号 ≥2/3 λ → 采纳；
  另外无论过否，3a 学到的权重向量本身是可解释性结果（是否逼近手工 0.7/0.3），
  进论文讨论；
- 不过 → 保留固定打分（简单性优先），软门控代码归档。
