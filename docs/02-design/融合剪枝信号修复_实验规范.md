# 融合剪枝信号修复_实验规范

> 日期:2026-09-09 · 硬截止:2026-09-12 · 状态:**判定完成(2026-09-10):@0.002 过线(+0.059)、@0.004 未过线(27.371 < 27.461)→ 按协议停止,论文冻结为"安全免费"框架;修复成果归期刊版**
> 背景:6 点记分板显示真实融合 RD 中性偏负(均值 −0.06 dB)。根因分析定位到覆盖信号的
> 三个可测缺陷。本文档是实现与判定的唯一规格。

## 1. 根因(审计结论)

1. **覆盖信号稀疏且极端偏斜**:8 个固定视角 + max 归一化下,`cov_mean=0.000`(全程所有周期),
   归一化总质量 < 0.0005×N——极端偏斜,少数锚点占满归一化质量,绝大多数锚点精确为 0。
2. **尺度钉扎**:投影分数 `imp + 0.25×(a+u)` 中,第二次 max 归一化把 imp 头部钉在 1.0,而
   0.25×(a+u) 典型量级约 0.25 → 头部锚点被 imp 支配、主体锚点被 0.3·s 支配、训练出的
   ADMM 分数 a+u 被稀释成第三位信息。(注意:两次 /max 均为保序变换,罪名是尺度钉扎,不是排序破坏。)
3. **生效事实**(节流日志反推):30k 的 134 次投影中融合生效约 119 次(15 次 provider 显存
   失败),60k 的 284 次几乎全部生效 → 6 点记分板是真实测量。其中 30k 呈"低码率负
   (−0.20)、中高码率正(+0.10/+0.08)"——与"预算越紧、噪声排序执行越多"精确一致。

## 2. 修法(范围锁死,三天内唯一的代码改动)

| # | 修法 | 要点 |
| --- | --- | --- |
| a | 覆盖**视角轮换 + EMA 累积** | fusion_cams 是一次性固定采样——同一批盲区 EMA 多少遍都不增加覆盖。改为**每个投影周期轮换采 8 个不同视角**(确定性旋转窗),135 周期 × 8 ≈ 1080 个独特视角采样;EMA(decay 0.95)跨周期累积,buffer 加入锚点增删的同步维护列表 |
| b | **分位数归一化**替代 max | cov_norm = clamp(cov / p99(cov>0), 0, 1)——保序、抗单锚点支配;敏感度 s 维持 log1p+max(平滑量,无病态) |
| c | **乘法调制**替代加法稀释 | score = (a+u) × (1 + γ·imp_norm),γ=0.25 起步、硬帽 1.0;零覆盖锚点完全保留 ADMM 原排序,重要性只在 a+u 相近的锚点间做有界重排;imp 内部保持覆盖主导 0.7/0.3(eff=min(w,0.3) 不变) |
| d | 日志 | engaged 行增加 cycle 计数与 cov p50/p90/p99;provider 失败保持逐条打印 |

明确不做:其他任何改动;full 模式行为随主路径自然更新(不在判定范围)。
