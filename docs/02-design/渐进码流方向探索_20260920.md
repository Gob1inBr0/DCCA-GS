# 渐进码流方向探索（2026-09-20）

> 定位：方向三改立后的完整设计空间文档。回答三个问题：这个方向有哪些
> 可行的做法、哪些能先用现成数据验证、按什么顺序推进。
> 前置事实（全部已确证，见 `../03-reports/离线任务第二批_20260920.md`）：
> ① Morton 排序判负（字节-覆盖曲线输给随机，因字节先铺满包围盒一角）；
> ② 贡献降序拿到 80% 场景覆盖只要 21.5% 的字节（随机 79.8%）；
> ③ 逐锚点比特、覆盖面积、解码端结构统计量都有现成导出；
> ④ 码流逐字段分批存储（228 批 × 字段），截断自同步问题真实存在。
> 约束（不可违反）：解码端零边信息（一切顺序/条件信息要么在码流里、
> 要么解码端可重算）；逐位还原校验必须通过。

## 0. 问题定义

现状：码流必须完整收到才能解码。目标：**收到前 k% 字节时就能渲染出
尽可能好的画面**，k 从 0 扫到 100 得到一条"字节-画质"曲线，曲线下的
面积（AUC）就是优化目标。这是一个新能力轴，不与 RD 曲线上某一点
直接竞争——期刊版可以把它作为能力章节。

评测指标（预注册）：
- 主指标：字节-PSNR 曲线 + AUC（k = 5/10/25/50/75% 处的 PSNR 表）；
- 辅指标：首帧可用时间（拿到多少字节能渲染出 PSNR ≥ 20 dB 的图）；
- 成本指标：渐进版相对原码流的体积开销（排序元数据 + 分层开销）。

## 1. 设计空间总览

三个家族，从"不改编码器"到"重训练"：

| 家族 | 一句话 | 改动量 | 解码端顺序信息 |
| --- | --- | --- | --- |
| A 排序分组 | 定一个锚点优先级顺序，按组写入码流 | 只改打包顺序 | 元数据或可预测 |
| B 分层量化 | 每个属性先存粗版本再存细化残差（类似 JPEG 的质量分层） | 改量化与打包 | 天然分层，无需额外信息 |
| C 条件熵模型 | 熵模型的上下文包含"已经收到的部分"（自回归） | 重训练 | 解码端天然可重算 |

三个家族不互斥：A 定骨架、B 提供层内质量梯度、C 压缩层间冗余，
最终形态可能是 A+B 或 A+C 的组合。

## 2. 方向清单

### A 家族：排序分组

**A1 贡献排序 + 组号元数据（基线方案）**
- 机制：锚点按贡献（覆盖面积）降序分成 G 组（G=16/32/64），逐组
  编码；每组一个自包含的算术编码段 + 段头。解码端读组号元数据
  （G=32 时约 5 bit/锚点 ≈ 2% 载荷）。
- 可离线验证：元数据成本精算（不同 G）；分组截断曲线（已有，可细化
  到逐组边界）。
- 风险：算术编码切成 G 段有段头开销和上下文断裂损失——逐组重编码
  的总字节数会比整段编码大多少需要实测（离线可测：用现有符号分布
  模拟分段熵损失，典型量级 <1%）。
- 判定线（预注册）：总开销 ≤ +3%，且 25% 字节处 PSNR 比随机排序
  高 ≥ 0.3 dB（这条几乎必过，重点是开销测量）。

**A2 贡献的可预测性（省掉元数据）**
- 机制：解码端已有的结构统计量（锚点密度、缩放各向异性、偏移能量、
  掩码存活率——I2 的四个输入）能否预测贡献排序？能则解码端自己算
  顺序，元数据归零。
- 可离线验证（第一优先）：四个统计量对覆盖面积的秩相关，逐个和
  联合。预测排序 vs 真排序的曲线差距（用排序重叠率 + 曲线 AUC 差）。
- 判定线：预测顺序的曲线达到真顺序 AUC 的 95% 以上 → 元数据可省；
  否则回到 A1。
- 与敏感度教训的关系：这里是**预测"顺序标签"**不是预测连续信号，
  且只影响传输入顺序不影响画质，容错高——不重蹈"能预测≠有价值"的
  覆辙的结构不同，但判定线仍是硬的。

**A3 次模贪心顺序 = 最优前缀顺序（连接已有资产，本方向最强想法）**
- 机制：渐进码流的"前 k% 字节渲染质量"本质上就是"选一个大小为 k%
  的锚点子集让覆盖最大"——**这正是次模覆盖贪心解的问题，而贪心的
  恰好就是一条优先级顺序**。Phase 1 的次模实现每周期产出的选择序列
  就是现成的渐进顺序，不需要新算法。
- 与 A1 的关系：贡献降序是"每个锚点独立打分"的排序（模块化目标），
  次模顺序是"考虑重叠"的排序——前者的前缀有冗余（两个大锚点盖同
  一块区域都排前面），后者天然去冗余。离线可直接对比两条曲线。
- 可离线验证：用贪心选择顺序重算字节-覆盖曲线 vs 贡献降序。
  （注意：字节-覆盖曲线是代理指标，真正的字节-PSNR 要轻 GPU 渲染，
  见 D4。）
- 判定线：次模顺序的曲线 AUC 比贡献降序高 ≥ 5% → 采用次模顺序
  作为默认排序；否则用更简单的贡献降序。

**A4 几何先行**
- 机制：锚点坐标走独立的 GPCC 流（1.29 MB，占载荷约 6%），把它放
  在文件最前 + 属性按 A1/A3 排序。收到早期字节时解码端先有"骨架"
  （位置 + 少量属性），渲染退化模型（例如用邻居插值属性）也能出图。
- 离线可验证：不需要——这是打包顺序改动；配合 D4 渲染实验评估。

**A5 视口加权排序**
- 机制：默认视角集合下的可见贡献排序（贡献 × 视角命中）。适合
  "网页先渲染用户第一眼看到的"场景。必须存元数据（视角相关顺序
  解码端不可算）。
- 优先级：低（先做好视角无关版本）。

### B 家族：分层量化（SNR 分层）

**B1 比特平面分层**
- 机制：经典做法。每个量化符号拆成"粗比特平面 + 细比特平面"：先收
  高位（大尺度数值），后收低位（精度）。收完粗层就能用粗值渲染。
- 与 A 的正交性：A 决定"哪些锚点先来"，B 决定"每个锚点的属性以什么
  精度渐次到达"。组合形态：前几组锚点连细层一起先发（前景精渲染），
  后面的组只发粗层（背景粗渲染）——一条曲线上同时调节"谁"和"多细"。
- 离线可验证：分层开销的理论上界（每层一段的熵损失）+ 粗层量化误差
  对渲染的影响需要轻 GPU。
- 风险：比特平面重排要求重新设计打包与算术分段；逐位还原校验要
  逐层做。

**B2 两遍量化（粗层 + 残差层）**
- 机制：B1 的简化版：粗层用大步长 Q 重新量化一份，细层存
  (原符号 − 粗层×Q/Q粗) 的残差。实现比比特平面简单，两层就够。
- 离线可验证：残差分布的熵可从现符号分布推出（粗层损失 = 量化到
  Q粗 的失真，需要渲染实验定 PSNR 影响）。

### C 家族：条件熵模型（回答"渐进式的自回归？"——是的，可行，分层做）

先澄清术语：**自回归**在熵编码里指"当前符号的概率由已经解码的符号
决定"。渐进场景天然有因果结构——收到的部分就是已解码部分，拿它当
上下文不违反零边信息（解码端手里真的有这些值）。

**C1 前缀条件自回归（完整形态，重训练）**
- 机制：解码第 k 组符号时，熵模型的上下文包含第 0..k−1 组的已解码
  值（例如按 Morton 邻居取已解码锚点的属性统计量作为条件输入）。
  训练时用因果掩码（只能看"更早的组"）强制这个性质。
- 与已有负结果的关系：**必须区分**。"跨锚点邻居条件熵增益不到 1%"
> 是在无序全量设置下测的静态邻居条件；渐进场景里邻居条件只在
  "邻居已到达"时可用，且不同到达比例下上下文密度不同——机制不同，
  但那个负结果是明确的风险信号：条件增益可能本来就小。**先跑 C2 的
  离线版估收益上限，过不了就不训练。**
- 成本：重训练（改熵模型输入 + 因果掩码的训练流程）。

**C2 层间条件（C1 的离散版，离线可估）**
- 机制：B 家族的两层结构里，细层的概率模型以粗层已解码值为条件
  （粗层先到）。这是神经图像压缩里"粗层预测细层"的标准结构。
- 离线可估：从现符号分布模拟"已知粗层后细层的条件熵"——收益上限
  可直接算，不必训练。
- 判定线：条件熵比无条件低 ≥ 0.3 bit/符号 → 值得训练细化版；
  否则 C 家族整体记负结果（与旧邻居条件负结果合并成完整证据链）。

**C3 组摘要先导层（超先验类比）**
- 机制：仿照神经压缩里的超先验（hyper-prior）：文件最前面放一个
  极小的"摘要层"（每组每字段的均值/尺度参数，几 KB），主码流的
  熵模型以摘要为条件。摘要先到 = 解码端提前知道每组的统计形状。
- 成本：介于 C2 和 C1 之间；摘要是码流一部分，零边信息成立。
- 离线可估：分组后的统计量条件化收益（同 C2 方法）。

### D 家族：工程与评测（所有方向共用）

- **D1 截断自同步**：算术码切 G 段，每段独立可解 + 段头带长度校验。
  网络截断落在段中间时丢整段。开销与 G 的关系离线可测。
- **D2 渲染策略**：缺失锚点跳过（预注册基线）；进阶做"邻居属性
  插值补洞"作为对照（更好看但引入解码复杂度）。
- **D3 参照系**：和"同锚点数的重训练模型"（如 r055/基准的中间点）
  对比——渐进前缀是不重训练的降级，必须知道它比重训练差多少才有
  定位。
- **D4 轻量渲染实验**：截断解码 + 渲染若干视角 → 字节-PSNR 实测
  曲线。这是所有离线代理指标的最终校验。需要 GPU（分钟级/点），
  排在 r3 队列空隙。

## 3. 推进阶梯（预注册）

| 阶段 | 内容 | 成本 | 出口判定 |
| --- | --- | --- | --- |
| S1 离线 | A1 开销精算；A2 可预测性；A3 次模顺序曲线；C2/C3 条件熵收益上限；D1 分段损失 | 零 GPU | 各自判定线；任何一条通过即有可立项路径 |
| S2 轻渲染 | D4 字节-PSNR 实测（A1/A3 两种排序 + B2 粗层） | 分钟级 GPU | 曲线形状与离线代理一致；25% 字节 PSNR ≥ 视口无关可用线（20 dB） |
| S3 端到端 | 组合胜出方案做成真码流（改打包器）+ 逐位还原校验 | 代码工程，无训练 | 开销 ≤ +3%，曲线达标 |
| S4 重训练（可选） | 仅当 C2 上限 ≥ 0.3 bit/符号：C1/C3 训练 | 1–2 次训练 | 条件模型相对 S3 再省 ≥ 3% 体积或抬曲线 |

优先顺序：S1 全部 → S2 → S3（A3 若赢用 A3 否则 A1）→ S4 视 C2。

## 4. 与相邻工作的差异定位（立项前必做）

- PCGS（AAAI 2026 Oral，渐进 3DGS 压缩）：最近先例，必须精读并写
  差异——初判差异点在"次模贪心顺序 = 最优前缀"和"解码端可重算的
  顺序预测（A2）"。
- 可伸缩视频编码（SVC/H.265 时代）与渐进 JPEG：B 家族的经典参照，
  差异在锚点表示与熵模型是学习的。
- 神经图像压缩的渐进/局部解码（Ballé 系、CompressAI 的局部解码）：
  C 家族的参照，差异在三维锚点与覆盖目标。

## 5. 风险清单

| 风险 | 缓解 |
| --- | --- |
| 邻居条件收益本来就小（旧负结果） | C2 离线估上限先行，不过线不训练 |
| 分段开销吃掉排序收益 | D1 开销与 G 的曲线离线精算，选最小够用 G |
| 字节-覆盖代理与真实画质脱节 | S2 用实测字节-PSNR 校准代理 |
| 渐进版体积膨胀反伤 RD 主表 | 开销硬顶 +3%，超线砍 G 或砍层数 |
| 与 PCGS 撞车 | 立项前精读定位，差异写进设计 |
| 元数据违反零边信息 | 元数据是码流一部分（合法），区别于"解码端没有的外部信息"（非法）——论文措辞要写清 |
