## 3. 字节账前置测量（方案 C/D 的立项裁决，先于一切背景场实验）

**命令**（服务器，需同步 bg-feat-codebook 分支；约 2 分钟/场景）：

```bash
python scripts/anchor_byte_account.py \
  --ckpt <run>/ckpts/ckpt_30000.pth \
  --area-npz analysis/anchor_stats/<run>/anchor_stats.npz \
  --out-dir analysis/anchor_stats/<run>/byte_account --quantile 0.9
```

**读数与判读（预注册）**：`byte_account.json` 的
`bg_flags.bg_bits_share` = 背景锚点（面积 top-10%）占逐锚可归属比特的份额。

| bg_bits_share | 裁决 |
| --- | --- |
| < 5% | 方案 C/D **都缓**：复杂度乘子已把背景压平，无肉可吃；数字本身进论文分析小节 |
| 5% ~ 25% | 只跑方案 C 离线原型（§4，一天内出结果）；D 缓 |
| > 25% | C 跑 + **D 立项评审**（§5） |

同场加验（供方向 1 校准）：`headline.top_5/10/20pct_area_bits_share` 与
逐锚比特的分位比——比特分布越宽，码率感知剪枝（R1/R2）的天花板越高；
分布若近均匀，R1/R2 预期降级，判定门前移警示。

口径说明（引用脚本 docstring）：逐锚比特 = 熵模型硬判决似然，覆盖
mask_anchor 保留集 × Morton 序 × 编码器分批；xyz/hash/MLP/头为全局字段
不摊派；"exact" 仅指与码流同模型同格点，不含 q_scale/attr_ctx。

## 4. 方案 C：背景特征码本（离线原型，无需训练）

**这是全部创新点里最便宜的一个测试**：不训练，拿现成 checkpoint 做
encode/decode 对比。

**阶段 1（首验，单 checkpoint 单工作点）**：

1. 选 ph0c_base_r085_lam0004_s104（面积 dump 与 checkpoint 同源，服务器
   `/home/project2/dump_anchor_area_opacity.py` 可复跑）；确认 ckpt 在盘。
2. 同一 checkpoint 跑两次 `encode_attributes`：关/开
   `--cfg.model.bg-codebook-enabled --cfg.model.bg-flags-path <dump.npz>
   --cfg.model.bg-codebook-size 256 --cfg.model.bg-area-quantile 0.9`。
3. 两个码流各自 decode → 同一 val 集评 PSNR/SSIM/LPIPS；比 `total_MB`。

**门 G-C（预注册）**：

| 结果 | 裁决 |
| --- | --- |
| 总码流节省 ≥ 2% 且 ΔPSNR ≥ −0.05 dB | 采纳为期刊版可选组件，进 §4 阶段 2 |
| 节省 ≥ 5% 且 ΔPSNR ≥ −0.02 dB | 强结果：进主表消融行 |
| 节省 < 2% 或 ΔPSNR < −0.10 dB | 记负结果；若字节账 > 25%，失败原因写明（质量 vs 收益）再评 D |

**阶段 2（仅采纳后）**：换第二个 checkpoint（不同种子）复核 flags 身份；
K ∈ {128, 256, 512} 与 quantile ∈ {0.8, 0.9} 各一点（共 4 run，全离线）。

**注意事项**：现有 dump 缺 `anchor_sha256` → encode 会响亮告警（原型阶段
可接受，单 checkpoint 自洽；量产需重生成带哈希的 dump）；码本 payload
已计入 total_MB；`bit_exact_roundtrip` 诊断只覆盖 xyz/masks（背景行按
设计不编码，其值为 payload 质心）。

## 5. 方案 D：背景场（条件立项，门先立后做）

**立项条件（缺一不可）**：§3 判读 > 25% 且 §4 的 C 未达"强结果"档
（C 已省掉大头则 D 的边际不值一周工程）。

**实施后的判定门 G-D（预注册草案，立项评审时允许修订一次并说明理由）**：

- 同尺寸：背景字段 + 前景锚点总码流 ≤ base r085 × 1.02；
- 质量：该尺寸下 ΔPSNR ≥ +0.10 dB（对照 base r085）；或同质量下
  size ≤ base × 0.90；
- 边界检查：val 全视角无前后景接缝伪影（人工检查 + LPIPS 不回归）；
- 结构性收益必须报告：覆盖约束/硬约束开关在背景场存在下的行为变化。

成本预估：一周级（背景度分割 + 场蒸馏 + 渲染合成路径）。B（合并少而大）
作为 D 的简化备选，仅当 D 在边界质量上翻车时启用。

3. **weights 波的第二阶段**（γ ∈ {0.1, 0.5}）必须等 stage 1 的 CSV 落盘
   后选 w，不许同批发。

## 7. 执行顺序（依赖驱动）

```text
今天：A2/A3 跑完 → CSV → G1 第一对数字
同步分支到服务器（等队列空）→ 双重切片行为变更登记 → base 复跑新基线
字节账（2 分钟）→ 判读 bg_bits_share ─┬─ <5%：背景场线关闭
                                      ├─ 5-25%：方案 C 离线原型（一天）
                                      └─ >25%：C 原型 + D 立项评审
次模 G1 后续波（λ×种子，与背景场线并行，2-3 天）
rate 波（方向 1 主赌注，2 天）→ spb/fisher/gate/weights 波（各 1 天）
```

GPU 预算：背景场线全程 ≤ 0.5 GPU 天（离线为主）；次模后续 ~6 run ≈ 3 GPU 天；
方向 1/3/4 首轮 5 run ≈ 2.5 GPU 天。
