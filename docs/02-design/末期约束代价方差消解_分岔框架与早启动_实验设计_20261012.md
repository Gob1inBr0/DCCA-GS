# 末期约束代价的方差消解：存档分岔框架与早启动判定实验设计

> 预注册文档：判定标准在发车前写死，出数后不回改。数字出数后登记
> `docs/data/experiments.csv`（组名 `fork`），判定报告另写。
> 建立：2026-10-12。前身：基层渲染损失判定实验（设计 20261011 + 判定报告
> 20261012 §6）——该方向已按预先写定的标准关闭，但关闭依据被"同配置配对
> 读数跨批波动 0.45 dB"动摇（原方案组代价三批 −0.181 / −0.359 / +0.095，
> 符号反转）。

---

## 1. 判定问题

1. **框架问题（方案 4）**：从同一条无约束训练的同一存档点分岔出各实验组
   （固定相机序列），能否把"约束代价"的测量噪声从 ±0.2 dB 量级压到种子带
   （±0.1 dB）以内——使单次实验足以判定 0.05 dB 量级的标准？
2. **机制问题（方案 1+2）**：约束（代数惩罚 / 基层渲染损失各一组）从
   15000 步启动（原来 24000）、权重在 15000 步内线性爬满（原来 6000 步），
   满精度档代价能否降到 −0.05 dB 以内，同时基层档增益保持在 +0.15 dB 以上
   且不显著低于现状机制的增益？

## 2. 假设（可证伪表述）

- **H1（续跑保真）**：从存档点无约束续跑到 30000 步，其满精度档画质对
  主干（直跑到 30000 步）的偏离不超过 0.08 dB（种子带量级）。超过则说明
  续跑恢复不完整（优化器状态、统计量或重摆放相关状态丢失），框架无效，
  先修实现。
- **H2（机制）**：早启动+长爬坡组（E1/E2）的满精度档代价 ≥ −0.05 dB。
  机制依据：约束与稠密化、深度重摆放、内容自适应量化同期在场，属性在
  "知道约束存在"的前提下长到最优位置，而不是在低学习率末期被拽离最优。
- **H2 不成立的已知反面证据**：无（早启动从未测过）。
- 若 H1 成立而 H2 不成立：结论升级为"代价与启动时机、爬坡长度无关的结构
  性代价"，与三批波动的观察合并，方差问题的最终解按"同批配对 + 报告不
  确定度"处理，机制侧不再投入。

## 3. 设计总览

```
主干 spine（无约束，0 → 30000，固定相机序列，种子 42）
   ├─ 存档 @15000 ──┬─ C0'：无约束续跑 15000→30000（空对照，15000 步续跑保真检查 + E 组同管线对照）
   │                ├─ E1：代数惩罚 w0.05，start 15000，15000 步线性爬满（早启动+长爬坡，惩罚版）
   │                └─ E2：基层渲染损失 w0.05，start 15000，15000 步权重爬坡（早启动+长爬坡，渲染损失版）
   └─ 存档 @24000 ──┬─ C0：无约束续跑 24000→30000（空对照，6000 步续跑保真检查 + C 组同管线对照）
                    ├─ C1：代数惩罚 w0.05，start 24000，6000 步爬满（现状复刻，分岔下的真实代价测量）
                    └─ C2：基层渲染损失 w0.05，start 24000，恒权（现状复刻）
```

七条训练线，全部从同一条主干分岔；相机序列预生成并全程固定（主干与所有
分支用同一序列，按全局步号取相机）。

**方案对应关系**：C0/C0' 与固定相机序列合起来是方案 4（分岔框架 + 方差
隔离）；E1/E2 是方案 1+2（早启动 + 长爬坡）分别落在两个机制上；C1/C2 是
现状机制在低噪声框架下的重测（给 E 组提供"现状真实代价"参照）。

**爬坡实现**：B3 的权重爬坡公式按（步数−启动步）/（总步数−启动步）计算，
启动步改成 15000 后自动变成 15000 步爬满（惩罚版无需新代码）。渲染损失
的权重目前恒定，需新增一个"权重爬坡步数"参数（默认 0 = 维持现状恒权，
历史行为不变）。

## 5. 预先写定的判定标准（发车前写死）

**先决检查（H1，任一不过则停判修实现，不进机制判定）**：
- fork_c0_24000 满精度档对主干终端偏离 ≤ 0.08 dB；
- fork_c0_15000 满精度档对主干终端偏离 ≤ 0.08 dB。

**阶段一（C1/C2，测量记录，无通过与不通过）**：登记分岔框架下现状机制的
真实代价与基层档增益。这一步的产出同时回答"历史三批的 0.45 dB 散布里，
有多少来自分岔前的轨迹差异"——C1 的代价若与三批历史值仍差得远，说明分岔
后残余方差（torch 随机流不对齐）依然大，机制判定的解读要相应保守。

**阶段二（E1/E2 各自判定，对 fork_c0_15000）**：

| 标准 | 判据 |
| --- | --- |
| 主要标准：消除满精度档代价 | 满精度档 ≥ 对照组减 0.05 dB |
| 基层档增益 | ≥ +0.15 dB 且 ≥ 对应现状组（C1 或 C2）减 0.15 dB |
| 码流不增大 | 总字节 ≤ 主干 × 1.02 |
| 贴线条款 | 主要标准落在 [−0.08, −0.05) 时，复用主干重跑该组一次（分岔重复批），两组平均裁决 |

**汇总裁决**：E1、E2 任一组三条标准全达标 → 该机制的早启动版本提名采纳，
第二批补 λ0.002 松档与 garden 标准场景配对（对接 CVPR 剩余任务清单 #4）；
两组均未达标 → 早启动+长爬坡结论为负，与"结构性代价"证据链合并，机制侧
关闭，方差问题转回"同批配对 + 报告不确定度"的论文写法。

机制旁证（不设标准，判定时一并读）：E 组训练日志中惩罚原始值 / 基层画面
误差自启动起的变化轨迹；E 组 15000–17000 段（深度重摆放与选择窗口期）
训练损失有无异常尖峰。

## 6. 实现清单（发车前完成，默认行为不变）

1. **续跑支持**：训练入口加 `--resume <ckpt>`：恢复模型、优化器状态、
   稠密化统计量、appearance 设置，从存档步数+1 续跑；学习率调度按全局
   步号计算（现有实现已按步号，核查即可）。
2. **存档补全**：`save_checkpoint` 增加重摆放相关的三个运行时状态
   （选择窗口的锚点基数与步号、重摆放完成标志）——当前存档不含它们，
   从 15000 存档续跑会让选择窗口行为偏离主干。旧存档无这些字段时保持
   现有回退行为（向后兼容）。
3. **相机序列固定**：`--camera-schedule <npy>`：预生成 30000 步相机索引
   （一个脚本，种子 42），训练按全局步号取相机；不传该参数时维持每步
   随机选择（历史行为与可复现性完全不变）。
4. **渲染损失权重爬坡**：新参数"权重爬坡步数"（默认 0 = 恒权，现状）；
   权重 = 设定权重 × min(1, (步数−启动步)/爬坡步数)。
5. **主干存档步数**：15000 / 24000 / 30000 三点存档。
6. **测试**：pytest 全绿；续跑与相机序列各加一个单元测试（不传新参数时
   行为逐位不变）。

## 7. 冒烟测试与发车顺序（阻塞项）

1. **续跑保真冒烟**：主干跑到 15200 存档 → 从 15000 存档续跑 200 步，其
   loss 轨迹与主干 15000–15200 段应统计贴近（同相机序列下逐点差异在浮点
   噪声量级）；差异大则先修再发车。
2. **爬坡参数冒烟**：渲染损失爬坡权重在启动步为 0、爬满步为设定值（单测）。
3. 发车顺序：主干先行；15000 存档落盘后立即发 C0'/E1/E2（三张卡并行，
   不等主干跑完）；24000 存档落盘后发 C0/C1/C2。全部完成约在主干结束后
   3 小时内。
4. 发车检查：`ps` 确认无存活 train.py（双开教训）；每条线独立结果目录。

## 8. 机时、磁盘与排期

- 机时：主干 1 × 30k（约 5h）+ 两条空对照（1h + 2.5h）+ C 组两条（各约
  1.5h 含评测）+ E 组两条（各约 3h 含评测）≈ **17–19 卡·时**，七条线三天
  窗口内可排完（主干 5h 后分岔组并行）。
- 磁盘：七个结果目录约 13 GB，当前系统盘可用 7.3 GB——发车前把已判定批次
  的 checkpoint 与点云再迁一轮内存盘（判定完的组随结随迁）。
- 排期：让位 CVPR 标准基准矩阵（一票否决项）；本实验与分层评测共享
  自动收数脚本模式（14 号脚本参数化复用）。

## 9. 风险表

| 风险 | 说明 | 处置 |
| --- | --- | --- |
| 续跑状态恢复不完整 | 优化器动量、统计量、重摆放状态丢失会让分岔组偏离主干 | 先决检查 ≤0.08 dB 兜底；冒烟先行 |
| 固定相机序列是协议变化 | 覆盖特性可能不同于随机选择；与历史数字不可直接比 | 本批内所有组同序列、批内自洽；报告标注协议差异，不与历史数字混排 |
| 15000 分岔撞上深度重摆放 | E 组约束与重摆放同期，选择窗口行为需与主干一致 | 存档补全（实现清单 2）；E 组 15000–17000 段损失轨迹旁证 |
| torch 随机流不对齐 | 分岔后噪声注入与码长抽样的随机数仍各自演化，残余方差不可避免 | 阶段一的 C1 与历史值对比给出残余方差量级；结论按不确定度报告 |
| E 组约束全程在场拖累整体质量 | B3 当初选末期启动的担心 | 这正是本实验要回答的；主要标准直接检验 |
| 渲染损失已按标准关闭后再开 | 上轮结论为关闭 | 本实验是对"关闭依据（方差污染）"的修正性检验 + 机制换轨（早启动），预注册框架下重开合规；两组独立判定，互不追溯 |
