## 4. 判定

**PASS（DINOv2 最佳 r=0.6034 > 0.3）**，按设计文档 §3.2 进入阶段 B；
阶段 B 只保留 **S1 DINOv2 监督（T-A）**，S2 深度、S3 区域一致性关闭。

解读：

1. 与 I6 的敏感度目标（相关性 ≈0）不同，DINOv2 语义目标与解码端可重算的
   哈希上下文 + mlp_grid 输出显著相关，说明语义信息在锚点表示里有迹可循；
2. 公式特征（A 组）仍然预测不了任何目标——复杂度 MLP 的 4 维输入表达力不足，
   阶段 B 的语义监督应直接监督复杂度网络输出，而不是改输入；
3. depth 和 SAM2 目标不是不可用，而是解码端输入里没有它们的线索，按门关闭。

## 5. 风险与备注

- 相关性门的 train/val 按 Morton 连续区间切分（与 sens gate 同口径），
  空间自相关可能高估 r；阶段 B 训练前建议用随机切分复测一次（r 若仍 >0.3 再投训练）。
- 本门只证明“可预测”，不证明“可提升 RD”；30k 冒烟（阶段 B §4）才是真正的验收。
- 预训练模型仅离线使用，bitstream 零新增字段。
