# DCCA-GS 环境配置与交接说明

> 本文目的：让另一位 Agent/同事在一台新的 Linux + NVIDIA GPU 机器上，
> 从零配置 DCCA-GS 并完成一次“训练 → HAC++ 压缩 → 独立解码 → MLP 量化 → 评估”
> 的完整闭环。所有关键参数以 5090 上实际运行环境为准。

## 1. 适用范围

DCCA-GS 是锚点式 3D Gaussian Splatting 压缩框架，基于：

- `gsplat`（1.5.3，源码安装）
- `Scaffold-GS` / `HAC++` 锚点与哈希上下文表示
- `torch 2.7.1+cu128`
- `gridencoder` / `arithmetic` / `simple_knn` / `torch_scatter` CUDA 扩展
- MPEG-GPCC `tmc3` 几何编码器

当前论文的 **5 组件方向** 为：

1. I2 内容自适应量化；
2. I6 渲染敏感度监督；
3. SPA 训练侧 ADMM 锚点稀疏；
4. MiniSplat 深度反投影表面增密；
5. 解码 MLP 混合精度量化（`cd8/rest16`）。

ASG、GHAP、语义先验暂不入主路径。

## 2. 硬件与操作系统要求

**必须是带 NVIDIA GPU 的 Linux 机器。** 当前提供诊断信息的机器为
`ecs-89478139-001`（Ubuntu 22.04，Intel Xeon 80 逻辑核心，644 GB 内存，
KVM 虚拟机，GPU 为 Cirrus Logic GD 5446）——该机器**没有 NVIDIA GPU**，
不能完成完整训练、HAC++ CUDA 扩展编译和 GPCC/算术编码运行，只能作为
文档阅读、代码编写或打包机器。

可用于完整运行的最低建议：

| 项目 | 要求 |
| --- | --- |
| 系统 | Ubuntu 22.04（或 20.04/24.04，需支持 CUDA 12.8） |
| CPU | x86_64，8 核心以上（实测 80 逻辑核心环境可用） |
| 内存 | 64 GB 以上 |
| GPU | NVIDIA RTX 3090/4090/5090 或 A100 等；**至少 24 GB 显存**，推荐 32 GB |
| 驱动 | 支持 CUDA 12.8 的 NVIDIA 驱动（5090 实测 580.159.03） |
| 磁盘 | 150 GB 以上（4-28、Deep Blending 数据 + checkpoint + bitstream） |
| 网络 | 可访问 GitHub、PyPI、Conda 源；如离线需提前导出 wheel 和源码包 |

注意：`gridencoder`、`arithmetic`、`simple_knn` 是 **CUDA 扩展源码编译**，
不能在 CPU-only 机器上运行；`tmc3` 也需要在 Linux 上编译。

## 3. 仓库与目录约定

目标机器建议目录：

```text
<root>/
├── DCCA-GS/                  # 克隆本仓库（PHG 根目录）
├── gsplat-main/              # gsplat 源码 checkout
├── HAC-plus/                 # 仅用于安装 CUDA 扩展，可放仓库外
├── data/                     # 数据集
│   ├── playroom/
│   ├── drjohnson/
│   └── 4-28/
└── runs/                     # 训练结果
```

仓库结构：

```text
scaffold_gs/       # 本项目训练/编解码/SPA/MiniSplat/量化逻辑
hacplus/           # vendored HAC++ 核心（需要 CUDA 扩展）
scripts/           # runner、评估、量化、绘图/审计脚本
tests/             # pytest（HAC_5090_a100 环境通过 37 项）
docs/              # 设计、报告、环境说明
environment.yml    # conda 依赖
scripts/env_5090.sh
```

## 5. NVIDIA 驱动与 CUDA

先确认 GPU 可见：

```bash
nvidia-smi
```

5090 环境使用：

- Driver 580.159.03；
- CUDA 12.8（PyTorch `+cu128` 构建）；
- `tile_size=32`（RTX 5090 当前架构上限；其他卡需按架构验证）。

如果目标机器没有 GPU/驱动，请先安装 NVIDIA 驱动与 CUDA Toolkit 12.8，
或使用与目标 GPU 匹配的 PyTorch CUDA 版本，不要直接把本环境当作 CPU 环境运行。

## 6. Miniconda 与 conda 环境

```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
source ~/miniconda3/etc/profile.d/conda.sh
```

在仓库根目录：

```bash
conda env create -f environment.yml
conda activate HAC_5090_a100
```

`environment.yml` 中的关键版本：

| 包 | 版本 |
| --- | --- |
| Python | 3.10 |
| torch / torchvision | 2.7.1+cu128 / 0.22.1+cu128 |
| numpy | 1.23.5 |
| scipy | 1.15.3 |
| gsplat | 1.5.3 |
| pycolmap | 4.1.1 |
| tyro | 1.0.15 |
| lpips | 0.1.4 |
| torchmetrics | 1.9.0 |
| pytest | 9.1.1 |

安装成功后设置环境：

```bash
conda activate HAC_5090_a100
source scripts/env_5090.sh
```

`env_5090.sh` 必须做四件事：

1. 设置 `PHG_ROOT`；
2. 把仓库根目录加入 `PYTHONPATH`；
3. 设置 `PYTHONNOUSERSITE=1`；
4. 把 conda env 的 `bin/` 加入 `PATH`（供 `tmc3` 使用），并设置
   `PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True`。

## 7. gsplat

```bash
git clone --recursive https://github.com/nerfstudio-project/gsplat.git /path/to/gsplat-main
conda activate HAC_5090_a100
pip install -e /path/to/gsplat-main
```

验证：

```bash
python -c "import torch, gsplat; print(torch.__version__, gsplat.__version__, torch.cuda.is_available())"
```

## 8. HAC++ CUDA 扩展（必须源码构建）

HAC++ 核心依赖四个扩展：

- `_gridencoder`（哈希网格）
- `arithmetic`（算术编码）
- `simple_knn`（HAC 初始化）
- `torch_scatter`（仓库代码仍 import，不能当可选项）

可以从官方仓库获取源码：

```bash
git clone https://github.com/YihangChen-ee/HAC-plus.git /path/to/HAC-plus
cd /path/to/HAC-plus/submodules
unzip gridencoder.zip
unzip simple-knn.zip
unzip arithmetic.zip

conda activate HAC_5090_a100
pip install ./gridencoder
pip install ./simple-knn
pip install ./arithmetic
```

`torch_scatter`：

```bash
pip install torch-scatter -f https://data.pyg.org/whl/torch-2.7.1+cu128.html
```

如果上述 URL 不可用或版本不匹配，请安装与 `torch 2.7.1+cu128` 匹配的
PyG wheel。安装后用以下命令验证：

```bash
python -c "import _gridencoder, arithmetic, simple_knn, torch_scatter; print('HAC extensions OK')"
```

## 9. GPCC / tmc3

anchor 坐标由 `tmc3` 编码。本项目通过
`hacplus/utils/gpcc_utils.py` 在 `PATH` 中查找 `tmc3`。

```bash
# 从 MPEG-PCC-TMC13 官方仓库编译
git clone https://github.com/MPEGGroup/mpeg-pcc-tmc13.git /path/to/tmc13
cd /path/to/tmc13
mkdir -p build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j

# 放入 conda env bin
cp tmc3 $HOME/miniconda3/envs/HAC_5090_a100/bin/
chmod +x $HOME/miniconda3/envs/HAC_5090_a100/bin/tmc3
```

验证：

```bash
which tmc3
tmc3 --help
```

## 10. 数据准备

数据集目录需包含 COLMAP 结构：

```text
<scene>/
├── images/
├── sparse/
│   └── 0/
│       ├── cameras.bin
│       ├── images.bin
│       └── points3D.bin
└── ...
```

本论文使用：

| 场景 | 数据目录 |
| --- | --- |
| 4-28 UAV | `<data>/4-28` |
| DB playroom | `<data>/playroom` |
| DB drjohnson | `<data>/drjohnson` |
| Mip360 | `<data>/360_v2/<scene>` |
| T&T | `<data>/tandt/<scene>` |

训练命令固定评估口径：

```text
--data-factor 1 --max-width 1600 --test-every 8
```

不要使用全分辨率评估；两者 PSNR 差约 0.36 dB，数字不可比。

## 11. 运行前自检

```bash
conda activate HAC_5090_a100
source scripts/env_5090.sh

python -c "import torch; print('cuda', torch.cuda.is_available(), torch.cuda.get_device_name(0))"
python -c "import _gridencoder, arithmetic, simple_knn, torch_scatter; print('ext ok')"
which tmc3
pytest tests/ -q
```

预期：GPU 可见、四个扩展导入成功、`tmc3` 在 PATH 中、pytest 通过。
如果本地没有 GPU，`pytest tests/ -q` 中需要 GPU 的用例会失败，这不代表
环境配置错误；完整验证必须在 NVIDIA GPU 上做。

## 12. 5 组件默认训练协议

推荐用 `scripts/runner_phg_cell.sh` 一次跑完训练、压缩、解码和 MLP 量化：

```bash
cd <root>/DCCA-GS
conda activate HAC_5090_a100
source scripts/env_5090.sh

# 示例：playroom 30k，SPA 0.85
bash scripts/runner_phg_cell.sh 0 playroom <data>/playroom 0.004 \
  p0_playroom_5c_cell2 30000 15000 \
  --cfg.model.spa-enabled --cfg.model.spa-ratio 0.85 \
  --cfg.model.mini-splat-enabled \
  --cfg.model.mini-splat-reinit-iter 15000 \
  --cfg.model.mini-splat-max-new 4000 \
  --cfg.model.mini-splat-views 8 \
  --cfg.model.mini-splat-voxel 0.0
```

如果只想跑 SPA 基线（cell1），去掉 `--cfg.model.mini-splat-*` 参数。

该脚本默认包含：

```text
I2 + I6 + SPA + MiniSplat + MLP cd8/rest16
```

具体单步命令：

```bash
# 训练
python train.py train \
  --cfg.model.model-name hac_pp \
  --cfg.data.data-dir <DATA> --cfg.data.result-dir runs/<tag> \
  --cfg.data.data-factor 1 --cfg.data.max-width 1600 --cfg.data.test-every 8 \
  --cfg.data.no-preload-images \
  --cfg.model.voxel-size 0.001 --cfg.model.feat-dim 50 --cfg.model.n-offsets 10 \
  --cfg.model.appearance-dim 0 --cfg.model.tile-size 32 \
  --cfg.model.content-aware-quant --cfg.model.sensitivity-enabled \
  --cfg.model.spa-enabled --cfg.model.spa-ratio 0.85 \
  --cfg.model.mini-splat-enabled --cfg.model.mini-splat-reinit-iter 15000 \
  --cfg.model.mini-splat-max-new 4000 --cfg.model.mini-splat-views 8 \
  --cfg.model.mini-splat-voxel 0.0 \
  --cfg.optim.max-steps 30000 --cfg.optim.update-until 15000 \
  --cfg.optim.eval-steps 30000 --cfg.optim.save-steps 30000 \
  --cfg.optim.lambda-rate 0.004 --cfg.optim.mask-lr-final 0.002

# 压缩
python train.py compress --cfg.ckpt runs/<tag>/ckpts/ckpt_30000.pth \
  --cfg.out-dir runs/<tag>/bitstreams --cfg.codec hac_pp

# 解码评估
python scripts/eval_decoded.py \
  --artifact-dir runs/<tag>/bitstreams --data-dir <DATA> \
  --result-dir runs/<tag>/decoded_eval \
  --data-factor 1 --max-width 1600 --no-preload-images
```

MLP 量化：

```bash
python scripts/mlp_quant_sweep.py \
  --ckpt runs/<tag>/ckpts/ckpt_30000.pth \
  --data-dir <DATA> --result-dir runs/<tag>/mlp_quant_cd8_rest16 \
  --data-factor 1 --max-width 1600 --no-preload-images --skip-baseline \
  --group-bits mlp_complexity:8 mlp_deform:8 mlp_opacity:16 mlp_cov:16 \
               mlp_color:16 mlp_grid:16
```

## 13. 常见坑

1. **必须 `PYTHONNOUSERSITE=1`**：如果目标机 `~/.local` 有另一个 torch，
   不设置会优先加载并导致 torchvision 崩溃。
2. **不要 `PYTHONPATH` 写错**：仓库根目录必须是 `PHG_ROOT`。
3. **`tmc3` 必须可执行**：GPCC 在 PATH 中找不到会直接报错。
4. **HAC++ 扩展不能在 CPU-only 机器编译/运行**。
5. **大场景**：4-28 必须 `--no-preload-images`，否则显存爆。
6. **运行中的 runner 脚本不要覆盖**：bash 增量读取脚本，训练完成后重复替换
   文件会导致 compress/eval 阶段 `unexpected EOF`；新实验请放新脚本或新分支。
7. **不要用 `tile_size=64` 在 RTX 5090 上跑**，共享内存不足；30k 推荐 32。
8. **不要改变评估协议**：`data-factor=1/max-width=1600/test-every=8`。
9. **数据路径必须与用来训练/压缩/评估的路径一致**：如果 SfM 数据路径不同，
   验证集划分和位流都会改变。
10. **代码版本**：论文 5 组件主路径在 `main` 分支，ASG 在
    `codex/color-asg`；新机器环境验证请使用 `main` 或论文提交版本的 commit。

## 14. 给接手 Agent 的最小任务清单

- [ ] 确认机器有 NVIDIA GPU，`nvidia-smi` 可见；
- [ ] 安装系统包、NVIDIA 驱动/CUDA 12.8、Miniconda；
- [ ] `conda env create -f environment.yml`；
- [ ] 安装 `gsplat` 源码；
- [ ] 编译安装 `gridencoder/arithmetic/simple_knn/torch_scatter`；
- [ ] 编译并将 `tmc3` 放入 conda env `bin/`；
- [ ] 准备 COLMAP 数据目录；
- [ ] `source scripts/env_5090.sh`；
- [ ] `pytest tests/ -q`；
- [ ] 运行 30k 冒烟：train → compress → decode → eval → MLP quant；
- [ ] 检查 `codec_roundtrip_diagnostics.json` mismatch=0；
- [ ] 把结果写入 `docs/data/experiments.csv`，不要只写在日志里。
