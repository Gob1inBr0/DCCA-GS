# DCCA-GS 训练与压缩全流程说明

> 版本：v0.1（2026-09-03）
> 定位：按时间线、带公式与张量形状，严谨说明"从数据到压缩文件再到解码"的完整流程。
> 对应代码：`scaffold_gs/trainer.py`、`scaffold_gs/hacpp.py`、`hacplus/scene/gaussian_model.py`、
> `scaffold_gs/mini_splat.py`、`scaffold_gs/config.py`。

---

## 1. 总览

```text
无人机数据（4 航道照片 + 位姿）
   │
   ├─ 离线：提取语义特征（DINO，存缓存）
   ├─ 训练：渲染 → 损失 → 反传 → 累积敏感度 → (每100步)生长/剪枝 → (15000步)MiniSplat 再初始化
   │        → 优化属性 + 量化档位 Q
   ├─ 编码：把活下来的钉子(XYZ/属性/掩码/哈希网格) 打包进文件
   ├─ 解码：读坐标 → 重算哈希上下文 → 熵模型 → Q → 反量化 → 渲染
   └─ 评估：体积 vs 画质（RD / BD-rate），bit-exact roundtrip（mismatch=0）
```

## 3. 训练主循环（每步，iteration=0→30000）

### 3.1 渲染

取一张训练照片的相机 `cam`，`model.render(cam, background, is_training=True, retain_grad=True, step=iteration)`
得到 `out`（渲染图 + `out.gaussians`，其中 `pre_quant_feat/scaling/offsets` 保留梯度）。

### 3.2 损失（分解）

```text
loss =
  D                               # 重建失真
  + rate_term                     # 码率项（内容感知量化 I2/I6 影响 Q，进而影响率）
  + sensitivity_supervision       # I6：让 mlp_complexity 逼近敏感度（可选）
  + semantic_supervision          # DINO 语义监督（可选，方向一已判负）
  + spa_loss_term                 # SPA ADMM 稀疏项（把 mask 推向稀疏 z）
```

其中：

```text
D = (1 − λ_dssim)·L1(pred, gt) + λ_dssim·SSIM(pred, gt) + scale_reg_lambda·mean(prod(scales))
```

- `L1`/`SSIM` 是标准 3DGS 重建项；`scale_reg` 防钉子过大。
- 注意：**目前 D 是"逐像素等权"的**，没有按重要性加权——这是潜在的创新点（见实验设计创新 A）。
- `rate_term`：由熵模型 + `Q` 估计每颗钉子每字段的比特；`Q` 由 `mlp_grid`（基础）与
  `mlp_complexity`（I2 内容复杂度乘子）共同决定，训练/编码/解码三端共用同一路径。

### 3.3 反向传播

`loss.backward()`。`pre_quant_*` 用 `retain_grad=True`，故其 `.grad` 在反传后仍可取到。

### 3.4 累积敏感度（关键信号来源）

当 `iteration >= sensitivity_start_iter`：

```python
model.accumulate_sensitivity(out.gaussians)
```

读 `pre_quant_feat/scaling/offsets.grad` 的范数 `g = ||∂L/∂a||_2`，逐锚点做 EMA：

```text
EMA ← α·EMA + (1−α)·g            # α = sensitivity_ema（默认 0.99），按 anchor 可见索引 index_add
```

得到 `core.sensitivity_feat / scaling / offsets`（各 `[N,1]`）。这就是"这根钉子一动，画面变化多大"。

### 3.5 生长 + 剪枝（每 100 步，1500→15000）

条件：`update_from < iteration < update_until 且 iteration % update_interval == 0` → `model.adjust_anchor(...)`。
见 §4。

### 3.6 MiniSplat 再初始化（第 15000 步，一次）

条件：`iteration == mini_splat_reinit_iter 且未做过` → `model.mini_splat_reinit(dataset, background)`。见 §5。

### 3.7 参更新

`optimizer.step(); optimizer.zero_grad()`，换下一张照片。

## 4. adjust_anchor：生长 + 剪枝（严格版）

函数：`GaussianModel.adjust_anchor(check_interval=100, success_threshold=0.8, grad_threshold=0.0002, min_opacity=0.005)`。

### 4.1 生长（加钉子）

```python
grads = offset_gradient_accum / offset_denom         # [N*K, 1] 平均梯度范数
grads_norm = ||grads||                               # 每个 offset 的梯度
offset_mask = (offset_denom > check_interval*0.5*success_threshold).squeeze(1)   # [N]
anchor_growing(grads_norm, grad_threshold, offset_mask)   # 梯度大处补钉子
```

生长后把统计重置/补齐（`pad` 到新长度），保证新钉子有对应统计。

### 4.2 剪枝（选留）

**A. 计算分数（现状 = mask + 对偶）**：

```python
a = self.get_mask.mean(dim=1).detach()      # get_mask [N,K,1] → mean over K → [N,1]（撑得实不实）
scores = (a + self.spa_u).squeeze(-1)       # [N]；spa_u 为 [N,1] ADMM 对偶
```

> 方向二改成融合重要性（见实验设计）：`scores = 归一化加权和(mask, spa_u, 敏感度, 覆盖面积, 哈希上下文, 语义)`。

**B. 定预算 kappa**：

```python
# 在 spa_update_until=15000 之后（锁存）
if current_step >= spa_update_until:
    if spa_final_n == 0: spa_final_n = n
    kappa = max(1, round(spa_final_n * spa_ratio))
else:   # 15000 之前，平滑衰减
    spa_ref_n = max(spa_ref_n, n)
    progress = clamp((current_step - spa_start_iter) / (spa_update_until - spa_start_iter), 0, 1)
    ratio_t = 1 - (1 - spa_ratio) * progress
    kappa = max(1, round(spa_ref_n * ratio_t))
kappa = min(kappa, scores.shape[0])
```

**C. topk 选留 & 得到剪枝掩码**：

```python
z = torch.zeros([N], dtype=bool)
if kappa > 0:
    keep = torch.topk(scores, kappa).indices
    z[keep] = True
self.spa_z = z.float().unsqueeze(-1)          # 硬稀疏指示
self.spa_u = (self.spa_u + a - self.spa_z).clamp(-spa_u_clamp, spa_u_clamp)  # 对偶更新
prune_mask = ~z                               # True = 要拔
```

**D. 状态张量按位置切片（一一对应）**：

```python
offset_denom             = offset_denom.view(-1, K)[~prune_mask].reshape(-1,1)
offset_gradient_accum    = offset_gradient_accum.view(-1, K)[~prune_mask].reshape(-1,1)
opacity_accum            = opacity_accum[~prune_mask]
anchor_demon             = anchor_demon[~prune_mask]
for name in ("sensitivity_feat", "sensitivity_scaling", "sensitivity_offsets",
             "spa_z", "spa_u"):
    t = getattr(self, name)
    if t.numel() > 0:
        setattr(self, name, t[~prune_mask])
```

> 若新增融合所需的 per-anchor 状态（如 importance），须一并加入此切片清单，否则长度错位。

## 5. MiniSplat 再初始化（第 15000 步）

```python
# depth-reinit：深度反投影得到候选锚点，体素去重，append
candidates = collect_depth_surface_anchors(...)
added = cores.append_depth_anchors(candidates, voxel)

# （full 模式再加 blur split）
area = compute_contribution_areas(self, cams, background, device)   # 逐锚点覆盖像素/(H*W)
blur_candidates = collect_blur_split_anchors(..., area, blur_threshold, blur_budget)

# 加完再算一次面积，按面积定预算砍到固定 kappa
area = compute_contribution_areas(...)
scores = area.squeeze(-1)                    # 现状；方向二换成融合重要性
kappa = round(n_before * spa_ratio) if spa_enabled else n_before
keep = torch.topk(scores, min(kappa, n_after)).indices
prune_mask[keep]=False
cores.prune_anchor(prune_mask)
cores.mini_splat_importance = scores[keep].unsqueeze(-1)   # 存贡献面积作后续状态
```

## 6. 编码打包（体积口径）

```text
total_MB =
  G-PCC 锚点几何(XYZ)      # 坐标编码
  + feat / scaling / offsets / masks   # 属性，均按 Q 量化 + 算术编码
  + hash（哈希网格参数）
  + header + xyz bounds
  + MLP 权重（float32，32 bit/参数）
  + attr_ctx 预测器 / 背景码本载荷（可选启用，未启用计 0）
```

`Q` 路径（训练/编码/解码三端共用）：

```text
ctx    = hash_grid_interp(anchor)              # 坐标→哈希上下文（可重算）
[mean,scale,prob, qa,qs,qo] = mlp_grid(ctx)   # 熵参数 + 基础 Q 调整
Q      = Q0 × (1 + tanh(q_adj)) × m            # m 来自 mlp_complexity（I2 内容复杂度乘子）
Q0 = {feat:1.0, scaling:0.001, offsets:0.2}
m  = 1 + tanh(mlp_complexity(formula)) × α
```

关键（bit-exact）：编码端先 `round(anchor/voxel)*voxel` 网格化，Morton 排序后，用同一
`ctx→mlp_grid→Q` 路径算出和训练一致的 Q；解码端用同一套重算 Q，保证 roundtrip mismatch=0。

---

## 7. 解码

解码端只有：坐标（GPCC 解出）、哈希网格参数（码流）、MLP 权重（码流）、已解码属性。它：

```text
坐标 → 哈希上下文 → mlp_grid → 熵模型(算术解码) → Q → 反量化 → 写回属性 → 渲染
```

无需任何预训练模型；语义/敏感度/重要性等**训练期信号**在此全部不存在/无需重算（剪枝结果已固化在坐标里）。

---

## 8. 评估

- RD 曲线：多 λ（0.0005 / 0.002 / 0.004）画 PSNR/SSIM/LPIPS vs total_MB。
- BD-rate：相对参考点（如 dim50 / 基线），正值=变差、负值=变好。
- bit-exact：`codec_roundtrip_diagnostics.json` 必须 `mismatch=0`。
- 体积口径统一：MLP 权重一律按 float32（32 bit/参数）计，跨方法可比。
