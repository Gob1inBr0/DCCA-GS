## 1. 项目背景与定位

- **方法**：锚点式三维高斯泼溅压缩。用"锚点"作为控制点，每个锚点携带 K=10 颗神经高斯，由解码器（`mlp_grid` + 颜色 MLP）根据锚点特征生成子高斯的颜色/形态，再光栅化成图。锚点是压缩的最小单元（逐锚点量化 + 逐锚点剪枝）。
- **零侧信息**：解码端只靠锚点坐标、哈希网格、已解码属性重算；任何进 Q/熵路径的信号必须解码端可重算。
- **四个既有组件**：I2（内容复杂度量化）、I6（渲染敏感度监督）、SPA（训练侧 ADMM 剪枝）、Mini-Splatting depth-reinit。

## 4. 语义先验复盘：为什么"没用"

### 4.1 验证过程（阶段 A gate）

用 DINOv2 语义特征做监督目标，检验"解码端可重算输入能否预测它"：

| 输入集 | DINO 最佳 r | 含义 |
| --- | ---: | --- |
| A（4 维公式，mlp_complexity 真实输入） | nan（常数预测） | 输入不可达 |
| B（公式 + 哈希上下文 + mlp_grid 输出 + Q 提示） | **0.6034** | 可达 |

### 4.2 失败的两个根因

1. **门在错误的输入集上通过**：门用集合 B（r=0.60）通过，但真正被监督的 `mlp_complexity` 只拿到集合 A（4 维公式），A 对 DINO 是常数预测（r=nan）→ **目标实际够不着**，监督等于空转。
2. **目标错位**：DINO 描述"是什么"（物体类别/部位），不是"该不该细量化"（重要性）。即便可达也不对应 Q 正确性。

### 4.3 阶段 B 实测

| 场景 | 结果 |
| --- | --- |
| playroom | +0.125 dB，但体积 **+28.6%**（锚点 161k→204k，是"沿曲线挪贵点"） |
| 4-28 | −0.04 dB，中性偏负 |

### 4.4 结论

量化 Q 路径上：**DINO 语义可预测（r=0.60）但目标不对；渲染敏感度目标对但不可预测（r≈0.29）。** 在"零侧信息"约束下，Q 路径缺一个"既=重要性、又=可重算"的目标。

## 5. 方向一：空间上下文是否进 Q 预测 —— 关闭

引入"四航道（远近×高低）"空间特征（归一化半径 r_norm、高度 h_norm），判断能否提升对敏感度的可预测性。

> 修正：四航道对单锚点不是"属于第几条"标签，而是**连续空间场**（半径/高度），它决定锚点"被怎么拍的平均状态"。且每个锚点通常被四条航道都照到。

### 5.1 相关门结果（drjohnson / tandt_train，随机切分）

| 集合 | drjohnson 均值 r | tandt_train 均值 r | 说明 |
| --- | ---: | ---: | --- |
| A（4 维公式） | 0.016 | 0.091 | 无预测力 |
| B（富上下文） | 0.281 | 0.287 | 中等 |
| D（B + r_norm/h_norm） | 0.280 | 0.287 | **Δr≈0（−0.001/+0.0015）** |

- 空间特征 **Δr≈0**：全局"远近/高低"已被哈希上下文 + 局部密度吸收；
- 敏感度目标本身 mean r 仅 **0.28–0.29（<0.3）**——"对的"目标也不可达。
- **结论：方向一关闭。**

## 9. 创新 A：重要感知损失 —— 负结果

### 9.1 实现
- **方法**：重建损失 L1 用逐像素重要性图加权（`Σ w·|pred−gt| / Σ w`），`w` 来自**渲染不透明度 alpha**（前景/高占位区域权重高），clamp `[0.2, 1.0]`。
- **三种候选权重来源**（设计文档，未单独测）：DINO 语义显著性 / 渲染敏感度 / 前景遮挡（深度/SAM2）。最终用 **alpha**（DINO 缓存不在 LYH）。

### 9.2 结果

| λ | impA_s0 | 对照 base_s0 | 增量 |
| --- | ---: | ---: | ---: |
| 0.002 | 27.740 | 27.750 | −0.010 dB |
| 0.004 | 26.937 | 27.511 | **−0.57** |
| 0.0005 | 27.470 | 27.953 | **−0.48** |

### 9.3 结论

**创新 A（alpha 加权）为负结果**，多 λ 变差。且**三种权重（DINO 语义 / 敏感度 / 前景遮挡）没有单独跑对照**——只测了 alpha 版。结合 A 整体为负，保留价值低；若坚持，需先解决 DINO 缓存 / 敏感度图的在线可获取性，并预期收益有限。

## 10. 创新 B：融合剪枝 —— 中高码率小幅正，低码率崩溃

### 10.1 实现
- 在 SPA 剪枝分数里，把"重要性（覆盖面积 + 敏感度）"混入 `score = importance + weight·(mask+dual)`（`fusion_prune`）。
- 新增 `fusion_sensitivity_weight=0.5` 等开关。

### 10.2 结果

| λ | fusion_s0 | 对照 base_s0 | 增量 |
| --- | ---: | ---: | ---: |
| 0.002 | 27.817 | 27.750 | **+0.067** / +0.25 MB |
| 0.0005 | 28.069 | 27.953 | **+0.116** / **更小** |
| 0.004 | **25.950** | 27.511 | **−1.56（崩）** |

跨数据集 2-06 @0.002：base 28.09 / 16.43；fusion 28.06 / 16.22（略低质但更小，混合）。

### 10.3 崩溃根因分析

- 锚点数几乎相同（fusion 507,813 vs base 505,992），**不是剪多了，而是留错了**；
- 训练期 eval PSNR（25.97）≈ decoded（25.95），`bit_exact` 正常，**非解码假象**；无 NaN/inf；
- **根因**：低码率（锚点稀缺）下，融合分数让**敏感度压过覆盖**——高敏感"细节/前景"锚点被留下来，低敏感"背景/大面积覆盖"锚点被删 → **覆盖空洞** → 重建崩（27.5→25.95）。
- **本质**：静态独立打分 + 贪婪 top-k，**不感知"这块区域谁来盖"**；预算越紧，"独立打分"的盲区被放得越大。

### 10.4 修复（进行中）

1. **覆盖主导融合**（治疗 w_sens 偏置）：把敏感度**封顶 0.3**（`imp = 0.7·覆盖 + 0.3·敏感度`），覆盖永远占主导；
2. **ADMM 覆盖约束**：SPA 硬投影处"每个粗格至少保留 1 颗锚点"，从结构上杜绝空洞（兜底；实测在 507k 锚点下偏弱，故主修是封顶）。

已实现 + 同步 LYH + 排队 λ=0.004 验证（判据：25.95 → 恢复 ≥27.4）。

## 11. ADMM 本质与"覆盖约束"设计

### 11.1 ADMM 是什么 / 本质

ADMM（交替方向乘子法）解 `min f(x)+g(z)，s.t. Ax+Bz=c`：把"连续可训练（软）"与"硬性稀疏（0/1）"拆成两个子问题**交替解**，用**对偶变量 u** 把二者拧在一起。

SPA 已是 ADMM：`loss = ρ/2·||a − z + u||²`；步1 优化软掩码 `a`；步2 硬投影 `z = topk(a+u, κ)`；步3 对偶 `u += a − z`。

### 11.2 覆盖约束改法（你已确认）

```python
# 步2（保留决策）改：
1) 粗 3D 网格：cell = anchor / cell_size
2) 每占用 cell 必保 1 颗（coverage 兜底）
3) 其余预算按 (a+u) 敏感度补满
```

**为什么能治**：结构上保证每个空间区域留锚点，无论敏感度怎么偏，管大面的锚点都不被删。ADMM 擅长约束，用约束而非软权重更本质。

> 但实现中发现：**min-1-per-cell 在锚点很多（λ=0.004 还留 507k）时偏弱**（无粗格空洞），所以真正的修复是**分数里的覆盖主导封顶**，覆盖约束作安全网。
