# DCCA-GS 组会汇报（2026-09-06）

主题：feat_dim 切换、基线公平比较、创新点重新定位、语义先验复盘、创新 A/B、低码率崩溃与修复、MLP 量化移除、仓库清理与复现性。

## 事实与结论

- 创新点重新定位为三层：主创新（唯一）= 渲染敏感度损失的复杂度乘子（I2 × I6，共享同一 MLP，零侧信息）；工程实现 = feat_dim 泛化、哈希/条件熵模型/G-PCC/算术编码（MLP 量化已移除）；基础措施 = SPA、Mini-Splatting。
- 语义先验复盘：DINO 监督验证，输入集 A（4 维公式）r=nan（常数预测）、集合 B（富上下文）r=0.6034；被监督的 `mlp_complexity` 只拿到集合 A。阶段 B 实测：playroom +0.125 dB 但体积 +28.6%（锚点 161k→204k）；4-28 −0.04 dB。结论：DINO 可预测（r=0.60）但目标不对；渲染敏感度目标对但不可预测（r≈0.29）。

- 方向一（空间上下文进 Q 预测）关闭：加 r_norm/h_norm 后 Δr≈0（−0.001/+0.0015）。
- feat_dim 切换：**改用 32**；后续统一 feat_dim=32、30k、data_factor=1、max_width=1600、test_every=8。

- 基线公平比较（1-78 · 30k · 32-dim vs HAC++，fp32 体积）：基线未胜过 HAC++——体积约为 HAC++ 的 59%，PSNR 低 0.42–0.70 dB；窄重叠区（20.0–23.7 MB）BD-rate +2.79%、BD-PSNR −0.041 dB；`bit_exact_roundtrip=True` 三档均通过。RD 图：`docs/figures/rd_1-78_30k_32dim_vs_hacpp.png`。

- 主创新（复杂度乘子）正向证据：λ0.002 +0.41 dB（27.338→27.750）、λ0.0005 +0.14 dB（27.810→27.953）。`i6off_s0`（I2 开、I6 关）：λ0.002 −0.07 dB、0.004 −0.17 dB、0.0005 +0.05 dB。
- 创新 A（alpha 加权重要感知损失）负结果：λ0.002 −0.010 dB、λ0.004 −0.57 dB、λ0.0005 −0.48 dB；三种权重来源（DINO 语义/敏感度/前景遮挡）未单独跑对照，只测了 alpha 版。不合并。
- 创新 B（融合剪枝）：λ0.002 +0.067 dB / +0.25 MB；λ0.0005 +0.116 dB / 更小；λ0.004 **−1.56 dB（崩，27.511→25.950）**。2-06 @0.002：base 28.09/16.43 MB，fusion 28.06/16.22 MB。崩溃根因：低码率下敏感度压过覆盖，背景/大面积覆盖锚点被删造成覆盖空洞（锚点数几乎相同：507,813 vs 505,992；训练期 eval ≈ decoded，非解码假象）。修复（已实现 + 同步 LYH + 排队 λ0.004 验证，判据 25.95 → 恢复 ≥27.4）：敏感度封顶 0.3（`imp = 0.7·覆盖 + 0.3·敏感度`）为主，ADMM 覆盖约束（每占用粗格必保 1 颗）作安全网（507k 锚点下偏弱）。
- 背景表示 4 方案（用户允许背景走侧信息）：主推 D 背景场（背景用低分辨辐射/颜色场，锚点只留前景）；B 背景少而大、C 区域共享特征、A 尺度自适应依次为备选。
- MLP 权重量化删除：实测只省 ~0.5%（0.16 MB MLP / ~15 MB 总量），且原实现"decode 后再量化、只换体积那一行"口径不自洽；决策：不作为贡献点，源头取消，统一 fp32 口径，README 已注明。
- 工程与仓库：main 已删除 `scaffold_gs/mlp_quant.py`、`scripts/mlp_quant_sweep.py` 及 runner 的 MLP_QUANT 步骤；复现性缺口（仓库训练代码落后 LYH 运行时，缺 `mini_splat_importance`、融合剪枝、重要感知损失、32-dim runner）已通过把 LYH 运行时代码同步进 `codex/importance-experiment` 分支修复。分支状态：`main` 干净框架基线；`codex/importance-experiment` 实验代码；`codex/clean-main` MLP 移除+README 重写（未合并）。合并规则：验证通过才合并 main。
- 跨数据集：2-06 base@0.002 28.09 / 16.43 MB，fusion@0.002 28.06 / 16.22 MB，base@0.0005 28.38 / 24.08 MB；4-10 多数在训；B/C/D 矩阵约 21/24 出结果。
- 关键决策：主创新保留为唯一主创新；创新 A 不合并；创新 B 修复后视验证结果定；MLP 量化/语义先验/空间上下文按负结果或弱证据关闭或移除。
