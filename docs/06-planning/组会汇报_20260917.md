## 3. 方法论沉淀

1. **冒烟纪律两次兑现**：调度器重启后重发了已完成的 s104r（重复 run，
   已按复制组处理）；新分支训练路径首跑前 300 步冒烟拦下 TypeError。
2. **新教训——新分支的第一次发射必须先冒烟**：git 分支的 model.py 来自
   另一条工作线，缺渲染路径必需字段，训练启动即崩。冒烟 + 逐层探针
   （bash -x）定位。
3. **调度器三个 ops bug 修复**：①gpu_busy 查错日志文件（train log 而非
   launch log）导致锁永不过期、队列空转 10h——根因一行修复；②nvidia-smi
   无超时被驱动挂死——加 timeout 20；③双实例竞态——重启前必杀旧实例。
4. **pkill 自匹配三次杀死自己会话**：模式串一律加 [x] 括号技巧或改走
   服务器侧脚本文件。
