## 1. TL;DR

DCCA-GS 是基于 HAC++ + Scaffold-GS + gsplat 的锚点式 3DGS 压缩框架。当前已完成：

- MLP 混合精度量化（cd8/rest16）；
- SPA 训练侧 ADMM 锚点稀疏；

lambda 点（DCCA 新计划）：

```text
0.004, 0.002, 0.0005
```

```text
train → HAC++ compress → standalone decode → eval_decoded → MLP quant
```

体积口径：

```text
total_MB = G-PCC anchor + feat/scaling/offsets/masks/hash
         + header + xyz bounds + MLP payload
```

## 9. 关键实现与修复

### 9.1 I2/I6

- 公式输入严格是 **4D**：`local_density / scale_anisotropy / offset_energy / active_mask_ratio`；
- `mlp_complexity`：`Linear(4→hidden) ReLU Linear(hidden→3)`；
- I6 只训练监督，不参与编码/解码；
- 公式 Q 在训练、编码、解码、率估计四端共用。

### 9.2 MiniSplat

- depth-reinit：深度反投影 → 体素去重 → `append_depth_anchors`；
- 完整版：贡献面积 + blur split + intersection-preserving simplification；
- SPA 预算钉在增密前；
- 统计张量同步：`offset_gradient_accum / offset_denom / opacity_accum / anchor_demon / spa_z / spa_u / mini_splat_importance / semantic_target`。

### 9.3 已修复的坑

| 问题 | 修复 |
| --- | --- |
| HAC++ 1200 张图 `Too many open files` | `ulimit -n 65536` |
| HAC++ 官方 checkpoint `denom` 缺失 | 不传 `--checkpoint_iterations` |
| MiniSplat append 后 offset 统计不同步 | `append_depth_anchors` 扩展 N*K |
| MiniSplat full 直接 prune 后统计未裁剪 | `prune_anchor` 条件裁剪 |
| `adjust_anchor` 二次裁剪统计 | v3 按实际锚点数判断 |
| `max_radii2D` 被误裁剪 | v4 从 `prune_anchor` 移除 |
| 排队器目录不存在 | `mkdir -p $runroot` + 4-10 数据等待 |
