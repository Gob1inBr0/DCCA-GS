## 3. 判定：字面结论与数据结论的冲突（本报告的核心）

**按预先写定的字面**：主要标准未达到（−0.070，标准是 −0.05），决策树里"主要标准未达"的分支触发 → 方向因结果为负而关闭。

**但同一组实验的数据直接反驳"主要标准未达"分支预设的升级结论**（"末期任何把符号搬离渲染最优解的约束都付满精度代价，与代理还是真实目标无关"）：

1. 同批同种子下，渲染损失的满精度代价是代数惩罚的 **1/5**（−0.070 对 −0.359）；
2. A2 的 P1 层**高于** A0（+0.129），A1 的 P1/P2 全线 −0.4 左右——惩罚方案的基层增益是从上面每一档收税换的，渲染损失方案不是；
3. A2 以 1/5 的代价拿到惩罚方案 89% 的基层增益（+0.736 对 +0.829），且码流更小。

**跨批次波动测量（新证据，动摇 0.02 dB 量级的单次实验判定力）**：A1 与 fam_b3_l0004_w005_s42 同配置同种子，满精度代价却从 −0.176（fam，10-02）变为 −0.359（本批）——同一配对读数的跨批差异 ±0.18 dB，是主门差距（0.023）的 **8 倍**。两次训练之间代码从 e47e7af 前进到 f72af1c（GPU 每步税合并等；解码侧声明逐位一致，训练轨迹无此声明）。结论：**单次实验、单一种子分辨不了 0.02 dB 量级的标准差距**。

### 6.3 裁决与两点如实记录

**方向按预先写定的标准关闭**：两种子平均满精度档代价 −0.163，远超 −0.05 的标准。

**记录一（预注册措辞歧义）**：§11 的加注条款写的是"关闭且平均代价 ≤ 同批原方案组平均代价的二分之一"。按写定原意（代价量级减半）不满足——新方案平均代价 0.163 比原方案 0.132 还大；若按带符号字面读（−0.163 ≤ −0.066）会得出"代价更大却加注'以显著更小代价'"的荒谬结论。按原意执行：**不加注**。此歧义系预注册措辞瑕疵，如实留痕。

**记录二（测量方法学发现，比方向结论更有价值）**：原方案组同一个配对读数（满精度档代价）在三次实验中分别是 −0.181（fam 批）、−0.359（种子 42 批）、**+0.095（本批）**——范围 0.45 dB，且本批符号反转（开惩罚反而高于对照组）。这类训练末期附加约束的代价读数方差极大，单次配对的 0.1~0.3 dB 读数不可作为机制属性的结论；论文中相关对比必须同批内配对，跨批引用需标注批次。B3 现行论文写法（紧预算档专用、代价按 fam 批数字如实报告）不受影响，但建议表 2 的代价数字标注"单批配对读数，跨批复现偏差可达 ±0.28 dB"。
