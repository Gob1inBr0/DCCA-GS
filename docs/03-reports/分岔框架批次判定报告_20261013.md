## 3. 三个结论

**一、分岔框架成功，测量精度从 ±0.2~0.45 dB 提升到 ±0.02~0.04 dB。** 两条空续跑对照与主干终端的偏离（+0.035 / +0.019）比历史三批的同配置读数散布小一个数量级——续跑恢复机制（优化器动量、稠密化统计、重摆放运行时状态、固定相机序列）工作正常。此框架是可复用的测量基础设施：今后任何末期机制的"真实代价"都可以用同一条主干分岔测出，单次实验即可判定 0.05 dB 量级的差别。

**二、历史 0.45 dB 的读数散布被解释：波动来自训练轨迹差异，不是机制本身。** 分岔低噪声测量给出的现状机制真实代价：惩罚 −0.137 dB、渲染损失 −0.312 dB。之前三批的 −0.181 / −0.359 / +0.095 全部散布在这两个真值之间的轨迹噪声里（+0.095 那次是轨迹差异碰巧盖过了机制代价）。

**三、早启动假设被证伪，且两种机制方向相反。** 惩罚早启动灾难性变差（−0.137 → −0.702）：约束在场于增长与重摆放窗口期会直接破坏增长过程——当初 B3 选末期启动的担心实测成立。渲染损失早启动有实质改善（−0.312 → −0.124，代价减半，图像域目标与增长过程兼容性好得多），但仍未达到 −0.05 的主要标准。基层档增益在所有变体中都稳健（+0.56 ~ +1.14）。

## 4. 处置

- **机制侧关闭**（早启动 + 长爬坡两条路都未达主要标准；结合此前两种子批复现批，末期约束代价的"结构性"结论现在有低噪声测量的直接支撑：不是方差，是真实代价）。
- **方差问题的最终答案**：论文写法按预注册回退为"同批配对 + 报告不确定度"；同时分岔框架作为测量方法入库存档（实现已合入主线，提交 78aee41），后续任何需要精测 0.1 dB 内差别的实验优先用它。
- **对 CVPR 论文的直接影响**：表 2 的 B3 代价数字可用本批 C1 的低噪声读数（−0.137，紧档 w0.05 现状配置），标注"分岔框架单次测量，精度 ±0.04"；"以显著更小代价保留基层增益"的渲染损失表述不写进论文（两种子判定已关闭方向，本轮早启动也未达标）。
- 基层档增益现象三批次、六种配置全部稳健（+0.56 ~ +1.14），机制侧关闭不影响它作为"已观察现象"被如实报告。
