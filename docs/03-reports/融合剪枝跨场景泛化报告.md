# 融合剪枝跨场景泛化报告（2-06 / 4-10 · 30k · 32-dim）

> 日期：2026-09-07
> 目的：验证 1-78 上成立的两个结论是否泛化——①融合剪枝在低码率（λ=0.004）的覆盖修复（covfix）
> 不再崩溃且不劣于基线；②修复后融合曲线整体 ≥ 基线。
> 数字唯一事实源：`docs/data/experiments.csv` 的 `gen_matrix` 组（12 行）。

## 1. 协议

与 1-78 曲线完全同构：30k 步、feat_dim=32、n_offsets=10、seed 42、sensitivity-start-iter 0、
SPA 0.85、MiniSplat reinit@15k、fp32 解码口径、`bit_exact_roundtrip=true`（12/12 通过）。

- **covfix**（只用于 λ=0.004）：`fusion-prune + fusion-sensitivity-weight 0.5
  + spa-coverage-constraint（cell 0.05, min-per-cell 1）`，即 1-78 修复验证的同款配方；
- **fusion 普通版**（λ=0.002/0.0005）：`fusion-prune + fusion-sensitivity-weight 0.5`；
- λ=0.002 两场景的 base/fusion 与 λ=0.0005 的 base 来自 `bcd_queue2`（此前已完成），
  λ=0.004 的 base/covfix 与 λ=0.0005 的 fusion 为本轮 `lyh_gen_matrix.sh` 新跑（LYH，GPU 0–5）。

## 3. 判读

1. **低码率修复泛化成立**：covfix 在三个场景的 λ=0.004 全部 ≥ base
   （+0.062 / +0.007 / +0.072 dB），1-78 的崩溃（25.95）没有在任何一个新场景复现。
   覆盖约束几乎不改变锚点数（4-10：671,570 vs 671,497），起作用的是"留哪些"而非"留多少"。
2. **融合 ≥ 基线在 9/9 个点成立**（把 covfix 计入 λ=0.004）：增益 +0.007 ~ +0.116 dB，
   体积代价 −0.5% ~ +3.7%。方向一致、幅度小——定位为"小而稳的正收益"，与 1-78 结论一致。
3. **唯一负点**：2-06 @0.002（−0.035 dB / −0.21 MB），属于沿 RD 曲线挪点的中性波动，
   不构成反向证据（同场景另两档均为正）。
4. **主创新（I2+I6 基线）本身跨场景稳定**：三场景 base 曲线单调、无异常
   （2-06：27.65→28.38；4-10：28.25→29.01），可作为论文跨场景主表。

## 4. 局限

- 2-06 / 4-10 暂无同协议 HAC++ 原生参考点，跨场景的"vs HAC++"比较只能引用
  未对齐口径的《全数据集上各方案结果.csv》，仅作位置参考；
- 每场景仅单 seed（42）；1-78 上 seed 2026 的双 seed 佐证未在新场景重复。
