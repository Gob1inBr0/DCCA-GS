## 2. 假设与判别实验

**H1（B/E 的主嫌疑）：固定 κ 调度在松档过紧。** 决策曲线已证三档 λ 咬合率
相同（post 全部 0.81%，与 λ 无关）——调度 λ 不变，但**最优锚点数随 λ 变松
而增大**；λ=0.0005 被 κ 压在与 0.002 相同的锚点数上，多给的比特只能加到
幸存锚点（每锚比特膨胀）而不是换成新锚点 → 花体积不涨质量。
判别 1（离线，5 分钟）：对 λ=0.0005 base ckpt 跑 `anchor_byte_account`，
对比 λ=0.002 的每锚比特分布（若 +40% 级膨胀 → 证实）。
判别 2（GPU，12h）：λ=0.0005 + 预算放宽臂（r_post=1.0 或 ratio 0.95），
若 ≥27.8 → 证实并即修复。

**H2（A 的主嫌疑）：敏感度加权在"预算咬合 × 敏感度已分化"区失真。**
A3 的边权 ×(1+sens) 在 λ=0.002（咬合中等）把贪心拉向高敏感聚簇，
覆盖目标被扭曲；λ=0.004 咬合更深但预算更紧反而压制了权重的自由度；
λ=0.0005 松、错选可被体积冗余吸收。
判别 3（离线）：对 A2/A3@0.002 两个 ckpt 各跑复杂度 logits/敏感度代理
分布对比（`anchor_byte_account` + `sensitivity_gt` 同款离线）。
判别 4（GPU）：A3@0.002 + 延迟敏感累积（sensitivity-start-iter 20000）
判别臂，若恢复 ≥27.6 → 证实"早期敏感度信号误导选择"。

**H3（C 的定性）：λ=0.002 档次模的真实增益 ≈ 0，属条件性结论而非噪声。**
s42 +0.076 / s104 −0.019 都在 ±0.1 噪声带内且方向相反 → 该档无增益是
区间事实；与 λ=0.004 的 +0.47 合并读：**次模的适用域 = 深剪枝紧预算**。
无需再烧种子。

**H4（D 不是异常）**：方向 1/3 为真实负结果，机制已证生效；按预注册记
负并关闭（模式四复盘见 99 文档 §6）。

## 5. 一页结论

- **位置性负增益的三个来源分别对应三个不同层**：A 是"选择规则 × 预算区"
  的交互（换规则或延迟信号可修）；B 是"预算调度 × λ"的失配（λ 自适应或
  放宽可修，修好 RD 右端预计抬到 27.8+）；C 是条件性区间的真实无增益
  （如实写，不是 bug）。D 已按负结果关闭。
- 排查成本：两个离线任务（<30 分钟）+ 两个 GPU 判别臂（24 GPU 小时，
  走排队）。
- **离线判别补充（2026-09-17，详见 §6）**：判别 1 证实 B 的逐锚比特膨胀
  （中位 +39%、可见人群均值 +52%；膨胀主要落 offsets，其次 feat），且
  发现码流人群本身 +21%、其中约 1/4 编码锚点不被采样视角覆盖——"多给的
  比特既加粗了码又买了盲锚点"。判别 3 显示 A2/A3 最终敏感度地形几乎相
  同、A3 的分歧挑选并不更敏感——离线证据**不支持**"加权拉向高敏感锚点"
  的字面机制，H2 的裁决交给判别 4（延迟臂）。

| 指标 | λ0005 | λ002 | 比值 |

### 6.2 判别 3（离线）：A2/A3@0.002 敏感度代理与选择差异

对两个 ckpt 各跑 `sensitivity_groundtruth.py` 同款流程（16 视角重放，
repo 3e095a7），另从两 ckpt dump 锚点位置 + mask_anchor 做位置配对。

- **最终敏感度地形几乎相同**：零敏感度率 25.6% vs 25.3%；
  spearman(s_gt, logit_l1) −0.546 vs −0.529；s_gt top-10% 质量份额
  0.588 vs 0.571。崩塌不体现在地形差异上。
- **选择差异体现在布局**：训练集位置重合仅 46.3%；编码集合中约 47% 的
  锚点在对方模型布局中无对应位置；在位置配对的子集内编码身份高度一致
  （Jaccard 0.881）。
- **分歧挑选不更敏感**：A3 独有挑选的 s_gt 中位数 = 共享挑选的 0.812
  倍，A2 独有为 0.825 倍（均值 1.413 vs 1.544，A3 甚至略低）——
  **离线证据不支持"×(1+sens) 把贪心拉向高敏感锚点"的字面机制**。
- **信号正交是真实的机制张力**：真敏感度排名与复杂度网络幅度排名几乎
  不相交（top-5/10/20% Jaccard 0.030/0.063/0.130 @A2，
  0.027/0.058/0.121 @A3；spearman(logit_l1, s_gt) ≈ −0.54，与 a1 组
  base 行 −0.22…−0.30 同号、更强）。选择侧若同时消费这两个信号，
  覆盖目标确实会被重排。
- **keep 重合率**：PruneLog 每周期只有数量（submod_keep=κ、decisions、
  fail），无 keep 身份明细，按任务书预案跳过、注明。

**结论**：判别 3 未能在最终选择中找到"高敏感偏好"签名；A3 崩塌若为
H2（早期信号误导），更可能通过训练期 EMA 与最终重放之间的漂移起作用，
离线重放无法检验该时序。**裁决交给判别 4**（延迟臂 ≥27.60 → H2 证实；
<27.60 则 H2 亦不成立，A3 在 0.002 的崩塌按"条件性失配"如实记负）。
数字已登记 experiments.csv a1 组两行。
