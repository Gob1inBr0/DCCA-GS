### 0.1 关键解读（供论文/汇报使用）

- r=0.6034 → R²≈0.364：哈希上下文 + mlp_grid 输出只能解释 DINO 目标 36% 的方差，
  其余 64% 是哈希网格没有的语义信息（物体类别、显著性、边界）；
- 因此这不是“信息冗余”，而是“可学习的新颖性”：r 太低学不到，r 太高（>0.9）
  纯冗余；**0.3~0.9 是理想窗口**；
- 深度/SAM2 的 r≈0 说明解码端可重算输入里没有它们的线索，强行监督只会
  让编码端和解码端失配，关闭是正确决策；
- 与 I6 的对比：I6 敏感度目标 r≈0（不可达），DINO 目标是第一个 r>0.3 的
  监督信号，值得投入训练验证。

## 1. 背景与目标

### 1.1 动机

- I6 用渲染损失梯度 EMA 监督 `mlp_complexity`，但之前的替换/相关性门显示：
  解码端可重算输入（公式特征、哈希上下文、邻居属性）与渲染敏感度相关性 ≈0，
  所以监督目标基本不可达，I6 只能带来约 0.1 dB 的小增益。
- 哈希网格与点云几何模型只提供“坐标 → 几何特征”，缺少外观、遮挡、语义信息。
- 假设：预训练模型的语义特征（DINOv2）、几何先验（深度）、区域分组（SAM2）
  可能比渲染损失梯度更“可被解码端重算的输入预测”，从而让 `mlp_complexity`
  学到更接近真实重要性的量化分配。Stage A 已证实 DINO 成立。

### 1.2 目标与成功标准

1. 30k 冒烟：任一信号在 4-28 或 playroom 上 PSNR 提升 ≥0.05 dB 且体积不增，
   或同质量体积减少 ≥2%；
2. 110k 完整验证不劣化，RD 曲线有可量化增益；
3. bitstream 零新增字段，解码端不依赖任何预训练模型；
4. 训练成本可控：预训练模型只离线跑一次，训练每步只读缓存。

### 1.3 硬约束

- 解码端只能重算：锚点坐标、哈希网格参数、mlp_grid 输出、已解码属性、掩码。
- 语义先验只能以“训练期监督/正则”形式存在，不能进码流，不能进解码路径。
- 不做：解码端加载预训练模型、把语义特征写入 bitstream、任何新侧信息。

## 2. 候选信号与用途

| 编号 | 信号 | 预训练模型 | 提取内容 | 优先级（v0.2 状态） |
| --- | --- | --- | --- | --- |
| S1 | DINOv2 语义特征 | DINOv2（ViT 系列） | 每训练视角 patch 级特征，聚合为逐锚点语义目标 | ✅ 通过，唯一保留 |
| S2 | 深度先验 | Depth Anything V2 | 稠密深度 → 逐锚点深度均值/方差 | ❌ 关闭（r≈0） |
| S3 | 区域分组 | SAM2 | 逐锚点区域 id + 区域一致性 | ❌ 关闭（r≈0） |
| S4 | 开放词汇语义 | OpenScene / ConceptGraphs | 建筑/地面/植被等语义标签 | 低（最后做） |

### 2.1 逐锚点信号聚合方式（S1 已实现）

1. 离线对全部训练视角跑预训练模型，保存视角级特征缓存（npz/pth）；
2. 训练期复用现有可见性聚合逻辑（参考 I6 `accumulate_sensitivity` 的视角聚合），
   把图像 patch 特征投影聚合到锚点；
3. 聚合时要求锚点至少被 N_min=3 个视角看到，否则标记为低置信度；
4. 全局做 z-score 归一化后作为监督目标，避免尺度影响 MSE。

实现细节（Stage A 已验证）：用渲染器的 `meta["means2d"]` + `gaussians.anchor_indices`
做最近邻采样，再按锚点求可见视角均值；DINO 目标先 PCA 到 8 维再 z-score。

### 2.2 信号用途

- **主线 T-A（监督式，v0.2 采用）**：DINO 目标作为 `mlp_complexity` 输出的
  监督信号，完全复用 I6 的机制（目标 → MSE → 同一个 MLP），零侧信息；
- **可选 T-A2（辅助投影头，v0.2 新增对照）**：训练期在 `mlp_complexity`
  的 hidden 上接一个投影头回归 DINO PCA 特征，投影头只在训练期存在、
  推理时丢弃，零侧信息；用于回答“直接监督 3 个输出 vs 监督更丰富的隐表示
  哪个更好”；
- ~~T-B（区域正则）~~：S3 已关闭，不再实现。

## 3. 阶段 A：离线信号构建 + 相关性门（已完成）

### 3.1 交付物（已交付）

- `scripts/extract_semantic_priors.py`：离线提取 DINOv2/深度/SAM2 并缓存；

### 3.2 决策规则（实测结果）

| 相关性 | 决策 | Stage A 实测 |
| --- | --- | --- |
| 任一信号最佳 r > 0.3 | 通过，进入阶段 B | DINO 0.6034 ✅ |
| 0.15 ≤ r ≤ 0.3 | 只保留最有希望的一个信号 | — |
| 全部 r < 0.15 | 关闭整个方向 | depth/SAM2 ≈0 ❌ |

### 3.3 阶段 A.5：随机切分复测（v0.2 新增，阶段 B 前置）

Stage A 的验证集按 Morton 连续区间切分，空间自相关可能高估 r。投入训练前
必须用**随机锚点切分**（80/20）重跑一次相关性门：

- 通过线：随机切分下 DINO 最佳 r 仍 >0.3；
- 若掉到 0.15~0.3：只保留 B 输入集 + 调大 `mlp_complexity` hidden 再复测一次；
- 若 <0.15：回到“不可重算”结论，关闭方向。

实现：给 `semantic_gate.py` 加 `--shuffle-split`（按随机置换切分 train/val），
其余口径不变。

## 4. 阶段 B：30k 冒烟训练（v0.2 修订）

### 4.1 配置新增（`scaffold_gs/config.py` ModelConfig）

```text
semantic_enabled: bool = False
semantic_signal: str = "dino"        # 只保留 dino
semantic_weight: float = 1e-3
semantic_start_iter: int = 20_000
semantic_ramp_iters: int = 10_000
semantic_min_visible_views: int = 3
semantic_proj_head: bool = False     # T-A2 辅助投影头
```

校验规则（与 `sensitivity_enabled` 一致）：
`semantic_enabled=True` 时 `weight>0`、`content_aware_quant=True`，
否则直接抛 `ValueError`。

### 4.2 数据流与实现位置

- 训练启动时加载语义缓存（CPU 只读，不进 CUDA；预训练模型只在离线提取时使用）；
- `scaffold_gs/hacpp.py`：新增 `semantic_supervision(gaussians) -> loss`，
  与 `sensitivity_supervision` 并列，按 `getattr` 方式接入；
- `scaffold_gs/trainer.py`：在 loss 组装处加入
  `loss = loss + model.semantic_supervision(out.gaussians)`（可选开关）；
- 逐锚点语义目标作为训练状态，随生长/剪枝同步：
  - 新锚点初始化目标为全局均值（或 0）；
  - 剪枝按索引同步裁剪；
  - 同步位置：`adjust_anchor` / `growth.py`（与 `sensitivity_*` 状态同路径）；
- T-A2：投影头 `Linear(hidden, 8)` 挂在 `mlp_complexity` hidden 之后，
  训练期优化、推理期丢弃；投影头参数不计入码流，但要计入训练开销；
- 编码/解码路径零改动；bitstream 不新增任何字段。

### 4.3 对照矩阵（v0.2 修订：先 playroom 快测，再 4-28）

**第一步：playroom 30k 冒烟（快、省资源）**

| 组 | 配置 |
| --- | --- |
| 1 | 基线 I2 + I6（当前 best） |
| 2 | + DINO 监督（T-A，3 维目标） |
| 3 | + DINO 监督（T-A2，8 维投影头） |
| 4 | I2 + DINO 监督（T-A，去掉 I6） |
| 5 | I2 + I6 + DINO（T-A 叠加） |

指标：PSNR / SSIM / LPIPS、total_MB（float32 与 MLP 量化双口径）、
训练时间、显存峰值；decode 后指标必须来自真实 bitstream。

**第二步：4-28 30k 复验**（只跑第一轮最优的 2 组）

### 4.4 停止条件（v0.2 修订）

- T-A 与 T-A2 任一相对基线：PSNR 提升 ≥0.05 dB 且体积不增，
  或同质量体积减少 ≥2% → 进入阶段 C；
- 若 T-A 无效但 T-A2 有效：保留 T-A2，并在阶段 C 补“投影头蒸馏”的消融；
- 若两者都无效：检查训练是否真的收到目标（目标 std、监督 loss 曲线），
  确认后关闭方向。

## 7. 风险与边界（v0.2 修订）

- 最大风险已部分排除：Stage A 证明 DINO 目标可被解码端输入预测（r=0.60），
  不再是 I6 式“不可达”；但仍需随机切分复测排除空间自相关高估；
- 预训练模型有域偏差（无人机航拍 vs 室内手持），playroom 与 4-28 互相验证；
- 离线缓存体积：DINO 特征 1050 视角约 11 GB（fp16），SAM2 仅采样 1/4 视角；
- 锚点只被少数视角看到时目标噪声大：用 EMA + 最少可见视角数阈值处理；
- 训练开销：预训练模型不参与每步训练，语义监督只是读缓存 + 一个 MSE，
  预计额外开销 <5%；
- 可学习新颖性窗口：阶段 C 复盘时检查监督 loss 是否真的把
  mlp_complexity 的输出分布推向与哈希输入不同（对比监督前后输出方差）。
