# gsplat 上手指南（最清晰路径）

> 本指南面向“零基础想快速上手 gsplat”的读者，按 **最短依赖顺序** 组织：
> 先跑起来 → 再理解 → 再改代码 → 再深入内核。
> 仓库内核心代码的注释与文档字符串已翻译为中文，读代码时可对照本指南。

---

## 0. 一句话理解 gsplat 是什么

- **3D Gaussian Splatting（3DGS）**：用上百万个 3D 高斯“小椭圆”表示一个场景，通过把它们投影到图像平面上并做 alpha 混合，实时渲染出新视角图像。
- **gsplat**：3DGS 的开源实现库，核心是 **CUDA 加速的光栅化**（含反向传播），比原版（Inria）更快、更省显存，且 API 高度可微，方便和 PyTorch 生态（NeRF、扩散模型等）结合。
- 你训练出的“模型”就是一个 `.ply` / `.pt` 文件，里面存着所有高斯的位置、旋转、尺度、不透明度、颜色（SH 系数）。

**核心数据流（全程记住这条链）**：

```
高斯参数 (means/quats/scales/opacities/colors)
   │  投影 (projection)
   ▼
2D 高斯 (means2d/covars2d/conics/radii)
   │  tile 相交 (isect) + 按深度排序
   ▼
逐像素 alpha 混合 (compositing)
   │
   ▼
渲染图像 (render_colors) + 透明度 (render_alphas)
```

## 1. 安装（10 分钟）

### 1.1 前置条件

- NVIDIA GPU（CUDA 11.8+），Linux / Windows / macOS(仅 CPU)。
- Python 3.9+，先装好 PyTorch（按 [pytorch.org](https://pytorch.org/get-started/locally/) 选 CUDA 版本）。

### 1.2 安装 gsplat（推荐源码安装，方便读代码）

```bash
git clone https://github.com/nerfstudio-project/gsplat.git
cd gsplat
pip install -e .            # 构建 CUDA 扩展
pip install -r examples/requirements.txt   # 训练/查看器示例的依赖
```

> 若只想当库用：`pip install gsplat`（首次运行时 JIT 编译 CUDA 代码）。

### 1.3 验证安装

```bash
python -c "
import torch, gsplat
print(gsplat.__version__)

print('3DGS kernel:', gsplat.has_3dgs)
"
```

## 2. 路径一：先跑一个最小 demo（30 行代码理解渲染）

不用任何数据，直接渲染 100 个随机高斯。打开 `python` 交互环境：

```python
import torch
from gsplat import rasterization

device = "cuda"

# 定义高斯：位置 / 四元数(wxyz) / 尺度 / 不透明度 / 颜色（后激活值）
means    = torch.randn((100, 3), device=device)
quats    = torch.randn((100, 4), device=device)
scales   = torch.rand((100, 3), device=device) * 0.1
opacities = torch.rand((100,), device=device)
colors   = torch.rand((100, 3), device=device)

# 定义一台相机：世界→相机矩阵 viewmat + 内参 K
viewmats = torch.eye(4, device=device)[None]          # [1, 4, 4]
Ks       = torch.tensor([[300., 0, 150.], [0, 300., 100.], [0, 0, 1.]],
                        device=device)[None]          # [1, 3, 3]
width, height = 300, 200

# 渲染！返回 (颜色, alpha, 中间结果字典)
render_colors, render_alphas, meta = rasterization(
    means, quats, scales, opacities, colors,
    viewmats, Ks, width, height,
)
print(render_colors.shape)   # [1, 200, 300, 3]
print(meta.keys())           # 中间结果，训练策略会用到
```

**看完这段代码，你已掌握 gsplat 的 80% API**：`rasterization()` 就是唯一核心入口（支持批量相机、SH 颜色、深度、抗锯齿、分布式……详见其 docstring，已翻译成中文）。

## 3. 路径二：训练一个真实场景（simple_trainer）

### 3.1 准备数据

用 [Mip-NeRF 360](https://jonbarron.info/mipnerf360/) 的 garden 场景（COLMAP 格式）：

```bash
cd examples
# 交互式下载（也可手动下载后解压到 examples/data/360_v2/garden）
python datasets/download_dataset.py
```

### 3.2 训练

```bash
# 单 GPU 训练 3 万步
CUDA_VISIBLE_DEVICES=0 python simple_trainer.py default --data_dir data/360_v2/garden --result_dir results/garden
```

常用参数（`examples/simple_trainer.py` 的 `Config`，注释已中文化）：

| 参数 | 默认值 | 含义 |
|---|---|---|
| `--data_factor 4` | 4 | 图像下采样因子（显存不够就调大） |
| `--max_steps 30000` | 30000 | 训练步数 |
| `--strategy` | default | `default`（原版 3DGS 稠密化）或 `mcmc` |
| `--antialiased` | False | 抗锯齿渲染（Mip-Splatting） |
| `--sh_degree 3` | 3 | 球谐阶数 |
| `--disable_viewer` | False | 关闭网页查看器 |
| `--save_ply` | False | 额外保存 .ply |

训练期间打开浏览器访问 `http://localhost:8080`，可实时看训练效果（viser 查看器）。

### 3.3 评估 / 渲染轨迹 / 导出

```bash
# 只做评估（加载 checkpoint，跳过训练）
python simple_trainer.py default --data_dir data/360_v2/garden \
    --result_dir results/garden --ckpt results/garden/ckpts/ckpt_30000.pt

# 查看训练好的模型（网页查看器）
python simple_viewer.py --ckpt results/garden/ckpts/ckpt_30000.pt
```

### 3.4 训练循环长什么样（读懂这段 = 读懂训练）

在 `examples/simple_trainer.py` 的 `Runner.train()` 中，每步迭代就是：

```python
# 1. 选一张训练图，取对应相机
camera = cameras[rand_idx]
# 2. 用当前高斯渲染（返回图像 + 中间信息）
render, alpha, info = rasterization(
    splats["means"], splats["quats"], splats["scales"],
    splats["opacities"], colors, viewmats, Ks, width, height, ...)
# 3. 计算损失：L1 + SSIM（+ 可选的深度/不透明度/尺度正则）
loss = l1_loss(render, gt_image) + ssim_lambda * ssim_loss(render, gt_image)
# 4. 反向传播前通知策略（保留 2D 均值梯度）
strategy.step_pre_backward(params, optimizers, state, step, info)
loss.backward()
# 5. 反向传播后由策略决定：复制/分裂/剪枝高斯（即“稠密化”）
strategy.step_post_backward(params, optimizers, state, step, info)
# 6. 更新参数（各参数独立学习率）
for optimizer in optimizers.values(): optimizer.step()
```

## 4. 代码阅读地图（按此顺序读，效率最高）

| 顺序 | 文件 | 内容 | 学习价值 |
|---|---|---|---|
| 1 | `gsplat/rendering.py` | `rasterization()` 及其 docstring | ★★★★★ 核心 API，全库最重要的一篇文档 |
| 2 | `gsplat/strategy/default.py` | `DefaultStrategy`：稠密化策略 | ★★★★★ 训练的核心机制（复制/分裂/剪枝/重置不透明度） |
| 3 | `gsplat/strategy/ops.py` | duplicate/split/remove/reset_opa 的实现 | ★★★★ 具体怎么改高斯张量 |
| 4 | `gsplat/cuda/_wrapper.py` | 底层算子：proj、isect_tiles、rasterize_to_pixels | ★★★★ 光栅化流水线的四个阶段 |
| 5 | `examples/simple_trainer.py` | 完整训练/评估流程 + 全部超参 | ★★★★ 抄作业式学习 |
| 6 | `gsplat/losses.py` | L1/SSIM/深度/正则损失 | ★★★ 训练损失全在这 |
| 7 | `gsplat/optimizers/selective_adam.py` | SelectiveAdam（Taming3DGS） | ★★★ 选择性稀疏优化器 |
| 8 | `gsplat/cuda/csrc/*.cu` | CUDA 内核（C++） | ★★ 深入性能优化才需要 |

**关键概念速查**：

- **packed 模式**：光栅化中间结果用稀疏张量存储（每个相机只见场景一小部分时省显存）。`packed=True` 时 `meta["gaussian_ids"]` 给出被激活的高斯索引，策略据此做稠密化。
- **策略（Strategy）三件套**：`initialize_state()` 建运行状态 → `step_pre_backward()`（留梯度）→ `step_post_backward()`（复制/分裂/剪枝）。想自定义“自适应稠密化”，继承 `Strategy` 实现这三个方法即可。
- **`meta` 字典**：`means2d`（2D 均值，含 `.grad` / `.absgrad`）、`radii`（像素半径）、`gaussian_ids`、`isect_offsets`（tile 偏移）等，是策略和调试的数据来源。
- **SH 颜色**：`colors` 传 `[N, K, D]` 的 SH 系数（`sh_degree` 非 None）时，库内部按视线方向求值；传 `[..., N, D]` 后激活颜色时直接混合。

## 5. 常用调参速查（DefaultStrategy）

| 参数 | 默认 | 含义 | 典型调整 |
|---|---|---|---|
| `grow_grad2d` | 0.0002 | 2D 梯度超过它 → 分裂/复制 | 梯度不足时调低（如 5e-5） |
| `grow_scale3d` | 0.01 | 3D 尺度小于它 → 复制（补细节） | 大场景调小 |
| `grow_scale2d` | 0.05 | 2D 尺度大于它 → 分裂 | 画面有“大色块”时调低 |
| `prune_opa` | 0.005 | 不透明度低于它 → 剪枝 | 透明飘絮多时调高 |
| `refine_start_iter` | 500 | 开始稠密化 | — |
| `refine_stop_iter` | 15000 | 停止稠密化 | 训练不收敛可延后 |
| `reset_every` | 3000 | 每 N 步重置不透明度 | — |
| `absgrad` | False | 用绝对梯度（AbsGS） | 想要更细的几何细节，配合 `rasterization(absgrad=True)` 与更高的 `grow_grad2d` |
| `revised_opacity` | False | 修正不透明度公式 | 实验性 |

> 想跑 MCMC 变体（原版 3DGS 的替代稠密化）：
> `python simple_trainer.py mcmc --data_dir data/360_v2/garden --result_dir results/garden`

## 6. 进阶路线（按需选择）

1. **2D 高斯（2DGS）**：`rasterization_2dgs`，表面重建用途，示例 `simple_trainer_2dgs.py`。
2. **3DGUT（NVIDIA）**：无迹变换投影 + 3D 世界空间求值，支持畸变相机与卷帘快门；示例在 `examples/AV_TRAINER.md`，阅读 `docs/3dgut.md`。
3. **分布式训练**：`rasterization(distributed=True)` + 多卡启动（`simple_trainer.py` 的 main 用法注释里有示例）。
4. **批量/混合场景**：多场景多视角任意批处理，看 `docs/batch.md`。
5. **推理渲染（HiGS）**：`gsplat.experimental` 的宏 tile 融合光栅化，低延迟推理路径。
6. **模型导出/压缩**：`export_splats()`（导出 .ply）、`PngCompression`、`--compression png`。
7. **自定义 CUDA 算子**：参照 `gsplat/cuda/csrc/` 下的内核结构与 `_wrapper.py` 的注册方式（autograd 钩子已迁移到 Python）。

## 7. 疑难速查

| 现象 | 排查 |
|---|---|
| 安装时 CUDA 编译失败 | 检查 `nvcc`/`torch.cuda` 版本一致；`pip install ninja`；换预编译 wheel（见 README） |
| 显存不足 | `--data_factor 4` → 8；`--packed`；降 `max_steps` 前的 `eval_steps` |
| 画面模糊 | 调低 `grow_grad2d`、调高 `refine_stop_iter`、开 `--antialiased`（注意会轻微掉指标） |
| 画面有漂浮透明物 | 调高 `prune_opa`、开 `--random_bkgd` |
| 训练发散（NaN） | 检查学习率；`--normalize_world_space` 保持 True；降低 `--init_opa` |
