## 1. 设计模式：这批论文反复用的招

### 模式一：上下文建模——把结构关系变成概率
- **谁在用**：HAC（哈希网格当上下文，Eq 3–6）、HAC++（哈希上下文 + 通道自回归 + GMM 融合，Eq 6–8）、ContextGS（锚点分级自回归，式 7–8）、CompGS/CompGS++（锚点基元预测耦合基元残差，式 2、9–12）、Smol-GS（哈希上下文挂到每高斯坐标）。
- **效果证据**：HAC++ Table III——去掉哈希上下文 BD-rate +63.3%，是最大单项；ContextGS Table 2 的 2×2 开关——强熵编码基线上只加锚点级上下文 18.67→15.03MB（−19.5%）。
- **在我们的框架里**：底座已用（HAC++ 哈希上下文）。可升级项是 ContextGS 式"粗层已解码锚点特征当细层上下文"——它的上下文全部由已解码量现算，**解码端可重算成立**；但完整版带超先验 ẑ（新增码流字段，违反契约），零新增字段的嫁接版只能取式 8 的细层分支，且 SPA 动态增删锚点会破坏一次性分级（解法：SPA 删净后冻结→重分级→熵模型微调，见落地清单 B1）。收益预期要打折：HAC++ 上下文已比 HAC 强，且 SPA 已把锚点间冗余压掉一截。

### 模式二：训练期塑造可压表示（率失真/正则进训练，而不是训后补压缩）
- **谁在用**：CompGS（熵约束正则端到端，式 1、6–13）、CompGS++（率约束优化模块）、SOG（2D 平滑正则 + 训练期排序）、EAGLES（量化感知训练，量化台阶兼做 opacity 正则，Fig 3）、Mini-Splatting（增密阶段关 SH）、GaussianSpa（预算约束写进训练目标，式 5–6）。
- **效果证据**：SOG Table 3——同一套压缩管线，不排序直接压 21.98dB/71.7MB，排序+平滑训练后 25.37dB/34.3MB：**排布（可压性）是训练出来的，不是压缩器给的**。EAGLES Table 2：量化感知训练让 Deep Blending 反超 3DGS（29.86 对 29.55）。
- **在我们的框架里**：I2/I6 本来就属于这个家族（训练期监督），这是我们叙事上的正确归类。可直接学的是 SOG 的两级对照：**同一量化/熵编码管线，开/关 I6 监督各训一次**——证明 I6 训出来的参数分布更可压，而不只是最终 Q 不同。

### 模式三：重要性/敏感度信号驱动的分级预算
- **谁在用**（两条信号路线，写相关工作时的分类轴）：
  - 前向贡献类：LightGaussian global significance（Eq 3：命中×不透明度×透过率×体积归一）、EAGLES influence（Eq 7：α·T，零开销顺带统计）、Mini-Splatting 重要性采样（附录 E）、GaussianSpa 不透明度 a（+乘子 λ）、Compact3DGS 可学习掩码激活（Eq 5–8）；
  - 反向梯度类：Niedermayr 敏感度（式 3：图像能量对参数的梯度幅值）、Speedy-Splat Ũ=(∇g I)²（式 20–21，Hessian 的标量重参数化）、我们的 I6（渲染损失梯度 EMA）。
- **效果证据**：Niedermayr Table 5——去掉 SH 敏感度豁免阈值掉 1.47dB，敏感度信号对"保护谁"有真实价值；Speedy-Splat Table 4——同管线同终数只换分数 +0.65dB，证明分数本身值钱；LightGaussian Table 3——分数三因子逐项加回 28.16→30.67，逐项都有增量。
- **在我们的框架里**：I6 属于反向梯度类，与 Niedermayr 最像（同为一阶梯度），但有一个他们没有的矛盾：梯度信号解码端算不到，所以我们必须蒸馏进解码端可重算的 MLP（I2）。这份"信号家族对照表"（前向/反向 × 训练期/编码期 × 进不进码流）本身就是论文里一张现成的定位表。落地见 A1/A2。

### 模式四：控制量直接进码率项，不加额外 loss
- **谁在用**：HAC++（掩码乘进码率 Eq 11，对照"额外 mask loss"）。
- **效果证据**：HAC++ Table III——换成额外 mask loss 要多花 9.6% BD-rate，且权重要逐码率点手调。
- **在我们的框架里**：SPA 目前按固定比例调度；若需要 finer 控制（比如让剪枝率随 λ 自适应），把掩码/预算项乘进码率是已验证更好的做法。

### 模式五：选择性压缩——压最不敏感的，保护高敏感的
- **谁在用**：LightGaussian（只对显著性最低 60% 的 SH 做 VQ）、Niedermayr（高敏感向量豁免聚类，式 5–6）、Compact3DGS（残差 VQ 只在最后 1K 迭代启用控成本）、Papantonakis（20 个码本 + half-float，位置不量化）。
- **效果证据**：LightGaussian Table 4——全属性 VQ 崩到 23.11dB，仅 SH×显著性选择后 31.16dB：选择比量化本身更重要。
- **在我们的框架里**：我们的对应物是"每锚点 Q 乘子"（连续版的选择性精度）。可校准的点：对极敏感锚点，AQM+乘子应收敛到"接近不量化"的步长下界（Niedermayr 的豁免原则），而不是均匀缩小——值得加一个 Q 乘子下界与敏感度的关系检查。

### 模式六：渐进调度——什么时候动什么，和动什么一样重要
- **谁在用**：HAC/HAC++（3k 稳定→3k–10k 加噪→10k 上哈希网格；每步只采 5% 锚点做熵训练）、EAGLES（分辨率 0.3→1.0 余弦爬升占前 70%）、Smol-GS（五阶段，率损失 20k 后才开）、Speedy-Splat（Soft 在 opacity reset 前、Hard 在增密后）、GaussianSpa（15k 开始/25k 删净/light tuning）、Papantonakis（SH 降阶在 15k，留半程补偿）、Mini-Splatting（15k/20k 两次简化）。
- **效果证据**：HAC++ Table XII——训练 40k/50k/60k BD-rate −17.5%/−25.6%/−32.9%，时间点本身就是变量；Speedy-Splat Fig 7——剪枝比例是全网格扫出来的（Soft 80%/Hard 30%），不是拍的。
- **在我们的框架里**：我们已有 I2 的 ramp；两个没做的调度：I6 目前全程开启（可试"压缩阶段再开"，学 Smol-GS），SPA 大步收缩可改成踩训练稳定点（学 Speedy-Splat）。落地见 B1。

### 模式七：锚点重排与复用——placement 和 reuse
- **谁在用**：Mini-Splatting（blur split + depth reinit 先铺好再删，Fig 2 诊断 + Fig 7 同数量曲线）、ContextGS（分级 + anchor forward 复用，Table 3：只分层不复用 15.54MB 反而比不分层 14.73MB 差，复用后 13.80MB）、Octree-GS（LOD，粗层锚点是细层子集，天然多档预算）。
- **效果证据**：Mini-Splatting Table 1——0.49M 高斯对 3DGS* 3.35M 画质持平（27.34 对 27.47）。
- **在我们的框架里**：depth-reinit 已移植并拿到 BD-rate −8.6%（我们自己的 SPA 预算曲线）；blur split（S_i 判据，前向顺带可算）还没用，是成本最低的补充。ContextGS 的"结构必须和复用绑在一起消融"是对我们将来做任何分组的提醒。

### 模式八：换表示 vs 表示内修补——路线之争要有正面回应
- **谁在用**：Smol-GS 对锚点系（含 HAC++）的四条批评：透明 offset 浪费、三因子坐标合成太绕、坐标普遍不压、特征 50 维过高渲染慢；它的答案是换表示（Table 2：Mip360 27.76dB/5.860MB 对 HAC++ 27.60dB/8.742MB；Table 4 消融显示属性量化贡献约 4 倍、坐标量化约 1.8 倍）。
- **在我们的框架里**：这四条是论文 related work 里最锋利的靶子，可以正面回应而不必换表示：mask 关闭的锚点/offset 比例、offset 能量分布这两个统计恰好是我们 I2 的公式特征，顺手就能算——"锚点框架内用每锚点步长分配消化同类冗余"是一个有数据支撑的回答。坐标不压也有背书：ContextGS Table 4/5（位置熵编码时间翻倍、高码率反而变大）、Niedermayr 第 6.5 节（位置量化失败）、Papantonakis（量化后位置占 28% 成为新瓶颈）。

## 2. 证明模式：最值得抄的三种实验/消融设计

### 证明模式 A：同预算、只换一个变量的对照（证明"信号/分数本身有价值"）
- 范本：Speedy-Splat Table 4——固定 PUP 管线、固定最终 0.34M 高斯，只换剪枝分数，+0.65dB；GaussianSpa 第 5.1 节——把 LightGaussian 的准则塞进自己的稀疏投影，其余不动，仍 +0.4dB（证明增益来自框架不是分数）；Mini-Splatting Fig 7——调采样比例扫出整条"数量-画质"曲线，在同数量处逐点压过对手。
- 我们怎么用：① SPA 分数 s=mean(mask) 对照 s=mean(mask)+β·f(I2 特征)，同锚点数比 PSNR；② I6 对照"随机信号/无监督"，同一 AQM 结构只换监督信号（学 Papantonakis Table 3 的"同候选集换挑选策略"）；③ 复杂度乘子对照"全局常数标量"（学 HAC++ Table III 的替换设计），排除"增益来自额外参数"。

### 证明模式 B：增量瀑布消融，每级同时报体积/质量/速度
- 范本：Niedermayr Table 3（garden：1379.99→…→46.57MB，每级报 ΔPSNR，还展示"聚类丢分、微调找回"的补偿关系）；Compact3DGS Table VI/VII（每步三轴）；HAC++ Table III（消融行里混排"去掉掉点"和"换方案对照"两种）；Speedy-Splat Table 1/2/3 共用同一行结构各看一个侧面。
- 我们怎么用：主消融表一行结构固定为「HAC++ → +I2 → +I6 → +SPA → +MiniSplat」，每行报 total_MB/PSNR/SSIM/LPIPS/训练时间；I2 内部再做四公式特征逐项开（学 LightGaussian Table 3）。反向消融也照抄 HAC++：证明"intra 只该用在 feat"那种"证明设计选择"的行（我们把乘子只乘在 feat/scaling/offsets、不乘 masks 的选择也补一行）。

### 证明模式 C：动机先行——信号存在性证据 + 失败实验
- 范本：HAC Fig 3 右（f_a 直接换 f_h 只掉 0.56dB，一张图证明互信息存在，Table I 同款）；LightGaussian Fig 3（opacity 剪枝掉 1.9dB 的反例逼出显著性设计）；GaussianSpa Fig 2（一次性剪 85% 永久掉点、长训不恢复）；Mini-Splatting Fig 2（四种删法全失败的诊断图）；Niedermayr Fig 3（敏感度直方图：<5% 极敏感）。
- 我们怎么用：我们的"信号存在性"问题是——公式特征和渲染敏感度相关性弱（内部实测 |r|<0.005）。该补的图：① 敏感度直方图（学 Niedermayr，证明锚点间敏感度差异大、值得分级）；② 每锚点 Q 乘子/每锚点比特的渲染图叠加可视化（学 HAC Fig 9 的比特分配图，证明乘子真的学到空间结构）；③ 一个反例图：均匀 Q 下最伤的区域 vs 乘子救回的区域。

### 其他值得学的细节（一句话版）
- 强基线上的 2×2 消融（ContextGS Table 2）：先声明"熵编码本身不算贡献"，增益全部在强基线之上量——和我们"SPA/MiniSplat 是基础措施"的口径同思路。
- 机制可视化（GaussianSpa Fig 5：不透明度两极化 + PSNR 同涨）：给"信息在转移"一个看得见的证据。
- 口径说明表（Papantonakis 附录批评 Niedermayr 的 DEFLATE≈2x；SOG 承认改了致密化超参；Speedy-Splat 的"压缩比"是高斯数不是 MB）：我们报告对比时附一张"是否含解码器/是否含熵编码/位置精度/基元数口径"表，防审稿人挑口径。

## 3. 表述模式：怎么讲故事、贡献句怎么写

### 最会讲的三篇
1. **HAC（ECCV 2024）**——"一图立论"：Fig 3 左证属性分布可建模、右表证互信息存在，一张图完成"这个问题有解"；然后 Table 1 五数据集×九方法×两码率收尾。主线一句话：「别只压数值，要压结构——互信息变概率，概率变省下的比特。」
2. **GaussianSpa（CVPR 2025）**——"失败实验开局"：Fig 2 先给一次性剪枝永久掉点、训练救不回来，把"现有路走不通"钉死；Fig 5 给"我的路在正常工作"的机制可视化（不透明度两极化的同时 PSNR 上涨）；Table 1 的"+0.4~0.9dB 且高斯少一个量级"收束。
3. **Mini-Splatting（ECCV 2024）**——"诊断图 + 口号级主张"：Fig 2 把高斯中心投影到渲染图，扎堆和空洞一眼可见，配四种删法全失败；主张压缩成一句"reorganize rather than prune"。

（Speedy-Splat 的 Table 4 是"最干净的单一证据"典范，做补充材料或 rebuttal 弹药。）

### 贡献句式的四种模板（从笔记原文提炼）
1. **首创句**（HAC #1）："To our knowledge, we are the first to …, i.e., using X to exploit Y." —— 只在确实首创时用。
2. **机制枚举句**（HAC++ #2）："we propose to use A to predict B, as well as C. The D is further utilized to … We also incorporate E to …, further slimming the model." —— 一句话把多个组件串成一条因果链。
3. **结果句**（HAC++ #3）："achieves an average … of over 100× … while maintaining or even improving fidelity." —— 大数字 + 不损伤从句。
4. **重构句**（GaussianSpa #1）："formulates the … objective as an optimization problem and solves it in the training process … smoothly transfer the information." —— 把工程改动包装成问题重定义。

### 我们主创新一句话的改写建议
现有表述：「解码端可重算的内容复杂度量化 × 训练期渲染敏感度监督，共享一个小 MLP，零侧信息地做内容自适应量化。」——机制准确，但听不出"它解决了什么别人解决不了的问题"。

推荐改写（学 GaussianSpa 的重构句 + HAC 的"信号存在→机制"逻辑）：

> 「自适应量化让 HAC++ 给每个锚点自己的量化步长，但"哪里值得更细"仍由几何上下文猜测。我们注意到真正想要的信号——渲染敏感度——在训练期免费可得：我们用它监督一个只依赖解码端可重算特征的复杂度 MLP，让量化步长按内容自适应，而码流里一个字段都不加。」

短版（摘要/海报用）：「把每锚点量化步长从几何猜测变成内容自适应：训练期渲染敏感度当老师，解码端可重算特征当学生，零侧信息。」

两个候选的共同结构：**基线的残余问题 → 信号存在且免费 → 蒸馏进可重算 MLP → 零侧信息收尾**。零侧信息放最后一句收口，是这批论文"结果句"的标准做法（大数字/硬约束放句尾）。

## 4. 落地清单

### 主创新（I2×I6）的 3 条

**A1. 敏感度真值标定，决定 I2 的论文定位**
- 学的谁：Niedermayr 式(3)（敏感度=图像能量对参数的梯度幅值，收敛场景、全训练集逐图一次 backward；附录 E 警告：颜色 clamp 会把低激活系数的敏感度错误置零）。
- 动作：离线脚本，在训好的场景上按式(3)算"真值敏感度"，分别测它与 I2 四个公式特征、与 I6 EMA 的相关性；顺带排查我们的渲染损失反传是否经过 clamp 置零路径（若有，I6 的 EMA 在低激活区被系统性低估——这可能是 |r|<0.005 的一部分原因）。
- 预期收益：两种结果都能写——相关则 I2 拿到"敏感度代理"的实证；不相关则把 I2 定位改为"独立复杂度信号"，并用此实验做边界分析，堵住审稿人。
- 验证实验：纯离线诊断，不动训练和码流；DB playroom + Mip360 各一景。

**A2. 给 I6 信号加第二个去处：喂分配，不止喂步长**
- 学的谁：Niedermayr（敏感度直接决定码本豁免/加权，Table 5 证其值 1.47dB——分配类用法对敏感度信号的兑现比步长类更直接）；Speedy-Splat Table 4（同预算只换信号的对照口径）。
- 动作：I6 的 EMA 除监督 mlp_complexity 外，再调制 offset 残差保留策略，或直接并入 SPA 分数 s = mean(mask) + β·norm(EMA)。信号只活在训练期，码流零改动。
- 预期收益：同 total_MB 下 PSNR 提升；同时把 I6 从"只影响 Q"扩成"影响 Q + 影响谁活下来"，创新点更立体。
- 验证实验：三个操作点同预算对照——基线 AQM / +I6(只监督Q) / +I6(Q+分配)，DB playroom + 一个 Mip360 室外场景，报 PSNR/SSIM/LPIPS/total_MB。

**A3. 消融与证据包：逐特征增量 + 分布可视化 + 退化锚点行**
- 学的谁：LightGaussian Table 3（分数逐项加回）、Niedermayr Fig 3（敏感度直方图）、HAC Fig 9（每锚点比特分配图）、HAC++ Table III（替换对照 + 退化行）。
- 动作：① I2 四特征逐项开关出增量表；② 每锚点 Q 乘子随内容的分布直方图 + 渲染图叠加可视化；③ 三行锚点：乘子恒 1（=HAC++ 原版）/ 乘子换全局常数标量 / 完整 I2——证明增益来自信号不是参数。
- 预期收益：主创新的消融表和动机图一次做齐；③是审稿人必问的"额外参数"质疑的标准答案。
- 验证实验：已有 30k 闭环 runner 上加开关即可，单场景先跑。

### 基础措施（SPA / MiniSplat）的 3 条

**B1. SPA 收尾阶段：删净 → 冻结 → light tuning**
- 学的谁：GaussianSpa 第 3.4 节（25K 删零高斯后专门 light tuning，最终质量反超原版；Fig 5 两极化即收敛信号）。
- 动作：最后一次投影后删除 z=0 锚点、停止投影，集中微调若干步；若将来引入锚点分级上下文，重分级也挂在这个冻结点上（学 ContextGS 的一次性分级）。
- 预期收益：补回阶段 A 中相对基线 −1.23dB 的一部分（我们的同锚点数对照已证 topk 差 SPA 5.52dB，剩余差距可能就在"删后没有再适应收尾"）。
- 验证实验：DB playroom 30k，删后微调 0/3k/5k 三档对照。

**B2. 把 §3.7 的单点对照升级成同预算曲线 + 准则替换**
- 学的谁：GaussianSpa Fig 7/14（削减率-PSNR 曲线；准则替换仍 +0.4dB）、Speedy-Splat Table 4（同终数只换分数 +0.65dB）、Mini-Splatting Fig 7（同数量扫整条曲线）。
- 动作：SPA ratio 扫 {0.2, 0.35, 0.5, 0.65, 0.8}，每个点对"编码端 topk 同锚点数"对照，画 PSNR–锚点数曲线；加一组分数替换（s=mean(mask) vs +I2 特征项，联动 A2）。
- 预期收益：剪枝章节的主图；"增益来自训练期 ADMM 框架而非某个分数"的证据链。
- 验证实验：复用现有 runner，批量排队即可；这是五条里工作量最大的一条，但直接产出论文主图。

**B3. blur split 补进增密——placement 那一半还没用满**
- 学的谁：Mini-Splatting 式(2)（S_i = 以最大贡献者身份覆盖的像素面积，阈值 θ_blur·H·W=2×10⁻⁴·H·W；Table 3 单组件 PSNR 持平 27.47、LPIPS 0.216→0.195）。
- 动作：在生长停止点前，对 S_i 超阈值的派生高斯做 split（前向光栅化的 argmax 索引图顺带可算，成本极低）；与现有 depth-reinit 形成"oversized 高斯 + 表面欠覆盖"两手抓。
- 预期收益：depth-reinit 管不到的 oversized 高斯是 LPIPS/细节损失的一个来源；Mini-Splatting 单组件量级可作参照。注意我们完整版跨场景实验里 blur-split 的增益不稳定（playroom 换 seed 后波动），所以目标是"同 total_MB 下 LPIPS 改善"这个保守结论。
- 验证实验：playroom + 一个 Mip360 室外场景，depth-reinit-only vs depth-reinit+blur-split 同 total_MB 对照。

## 5. 口径警示（写论文对比时的坑）

- **各家 MB 不可直接比**：SOG 大改了致密化超参（压缩倍数混入高斯减少的贡献）；Niedermayr 含 DEFLATE（约 2x）且位置只压到 16-bit；Papantonakis 无熵编码无解码器网络（27x 全靠结构）；Speedy-Splat 的"压缩比"是高斯数不是 MB；Smol-GS 按 3DGS.zip 口径含 MLP 与哈希表。HAC++ 码流五项 vs 我们多 bit_bounds/header_bits——引它论文数字时别把我们自己的工程项算进去。
- **两条信号分类轴**（related work 定位表用）：训练期 vs 编码期；前向贡献 vs 反向梯度。I6 在"训练期 × 反向梯度"格子里，独一份的是"解码端可重算蒸馏"这一步。
