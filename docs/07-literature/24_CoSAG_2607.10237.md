> 一句话定位：给一个冻结的 3DGS 叠加可开放词表文本查询的语义场，全程不做逐场景训练——用闭式的透射率加权平均把 CLIP 特征提到每个高斯上，再把语义场拆成"小锚点表 + 每高斯到锚点的绑定"，对绑定沿 Morton 空间曲线做免学习熵编码。存储从 GB 量级压到个位数 MB、多数场景 1 MB 上下（表 1：LERF-OVS 四场景 0.9–1.8 MB；表 2：3D-OVS 0.7 MB），同时语义精度达到或超过现有最好方法。

## 一学：问题与洞察（创新从哪来）

### 它认定的主要矛盾

摘要原话：把 CLIP 这类二维视觉-语言特征贴到 3DGS 场景上做成可文本查询的语义场之后，"attaching a high-dimensional feature to each of millions of Gaussians inflates a single scene to gigabytes"（数百万个高斯每个挂一个高维特征，单个场景就到 GB 量级），存储和部署成了这类语义场真正的瓶颈。

它对现有压缩路线的批评分三类（第 1 节、图 1）：

1. 自编码器路线（LangSplat 等）：每个场景学一个自编码器，高斯上只存低维隐码。瓶颈层丢细节，每次查询都要跑解码网络。
2. 码本路线（LEGaussians、LangSplatV2）：学一个共享字典，每高斯存索引。优化字典拖长训练，语义压进字典有精度损失。
3. 独立语义场路线（CF3、DF-3DGS）：在另一组高斯上单独蒸馏一个语义场。精度回来了，但外观场和语义场是两套不相交的高斯，需要两者一起用的任务（3D 选择、场景编辑）做起来麻烦。

它把三条路线的共同病根归结为两条（第 1 节）：一是"压缩靠优化"，构造慢，而且每个场景都要在场景旁边存一个解码器、码本或特征场；二是"每个高斯独立压缩"，忽略了同一物体上相邻高斯几乎总是同一种语义——原话是 "a large and obvious redundancy left untouched"（一大块明摆着没人动的冗余）。它的判断是：这两条来自同一个混淆——把"场的构造"和"场的存储"塞进了同一个训练出来的模块；把这两件事拆开，两个问题同时消解。

### 支撑观察（直觉 / 数据 / 失败实验）

- 构造可以闭式解（第 3.3 节）：把逐高斯重建误差目标里的合成加权从求和外侧挪到内侧，原来经正规方程把 N 个高斯通过合成权重的 Gram 矩阵耦合在一起的目标，就变成每个高斯各自独立的加权最小二乘，有唯一闭式解——透射率加权平均。这是数学观察，不需要实验。
- 绑定高度可压（第 3.3 节末 + 表 7）：因为锚点带 3D 位置，相邻高斯几乎总共享同一锚点，绑定沿空间是分片常数——第 3.3 节末原话 "aℓ is piecewise constant over 3D regions, which Sec. 3.5 exploits"。数据支撑是表 7：绑定按原始 int16 编码是 48.0 比特/高斯，Morton 重排后降到 11.0，再加跨层父指针共享降到 4.05。
- 反面证据一（第 3.4 节）：把三个语义层级平均成一场会掉精度，原话解释是 "their relevancy scales are uncalibrated and noisy fine levels inject spurious peaks"（各层级相关度的量纲没有互相校准，细层的伪峰会冒出来）。这句话没有单独的消融表支撑，属于带方法动机的直觉陈述。
- 反面证据二（表 6）：只用空间近邻绑定掉 19.8 mIoU，只用语义绑定掉 4.3 mIoU，去掉多视角平均再掉 1.4 mIoU——支撑"空间 + 语义联合绑定 + 多视角去噪"三个设计各自都有用。
- 反面证据三（图 4、第 4.6 节）：统一投影维度 D 在 64 附近饱和、再低就崩，说明整物体级的粗层语义更丰富、需要更多维度，按层分维才对。

### 显然的路为什么没走

- 显然的路一：也学一个熵模型/上下文模型（HAC、ContextGS 那套）。它没走，因为全文的立身之本是免训练、零学习模块、超参全场景固定（第 4.1 节）。它先试了通用字节压缩器 LZMA，发现绑定是"语义信号而不是平滑信号"，直接压收益有限（表 7：48.0→31.4 比特/高斯）；但把高斯沿 Morton 空间曲线重新编号后长游程自然出现，LZMA 就能逼近该排序诱导的一阶条件熵 H(aᵢ|aᵢ₋₁)（第 3.5 节）。用排序把结构暴露出来，而不是用网络学上下文。
- 显然的路二：把每高斯 512 维特征做有损量化。它没走，而是把存储对象从"特征值"换成"绑定符号"（第 3.2 节把问题重写成"对锚点表 Bℓ 和绑定 aℓ 做率失真编码"）：绑定是 1-of-K 的整数、空间分片常数，熵远低于连续特征；失真只发生在 K 个锚点上，量化损失被集中到一张小表里。
- 显然的路三：像码本路线那样优化字典。它的"字典"（锚点表）是闭式构造的：每个 SAM 区域在多视角下平均后直接种一个锚点（第 3.3 节），不需要训练字典，也就没有码本路线的训练代价和量化损失。
- 显然的路四：三个粒度取平均，或固定用一个粒度。它没走，把粒度选择推迟到查询时刻，按"峰值减中位数"的对比度逐查询选层（式 6，第 3.4 节）。

## 二学：机制（洞察怎么变成方法）

### 核心流程

前置（一次性，不训练）：输入一组带位姿的图像和一个冻结的 30k 迭代 3DGS 模型（第 4.1 节）。按 LangSplat 的做法对每个视角跑 SAM 的三个粒度（L=3：整物体、部件、子部件），每个掩码区域用 OpenCLIP ViT-B/16 编码，把 ℓ2 归一化后的嵌入铺到区域内像素，重叠处取更小的掩码，得到每层每视角的稠密特征图 Φ^{v,ℓ}（第 3.1 节）。同时把每个高斯在每个像素的 alpha 合成权重 w 预计算好（式 1）——几何冻结，权重只算一次，这是它从渲染借用的全部东西。

阶段一：免训练锚点构造（第 3.3 节）

1. 闭式透射率加权提升：对每个高斯 i、每个层级 ℓ，按式 (3) 计算——它渲染到的所有像素特征的透射率加权平均，再归一化。输入是预计算权重和特征图，输出是每高斯特征 f̂ᵢ，同时顺带得到逐高斯的透射率加权方差 sᵢ。一次免梯度的遍历所有视角完成，没有逐场景训练。
2. 播种锚点：每个 SAM 区域在它出现的视角上平均，种一个锚点，带种子特征 b_{k,seed}；用从 G 渲染出的深度把区域像素反投影到 3D 给锚点定位；同一反投影作用在一张带步长的网格上生成采样点，每个采样点标上锚点标签。没有 CLIP 响应的区域产生零特征行，充当背景锚点。
3. 单例锚点：方差 sᵢ 最大的 ρ=10⁻⁴ 那部分高斯跨视角太不一致，任何区域嵌入都代表不了，各给自己开一个只服务自己的单例锚点，位置在自己的中心 µᵢ、种子是自己的 f̂ᵢ（第 3.3 节）。它们只增加 ρN 行，但最稀有的基元原样保留。
4. 联合空间-语义绑定：对剩余每个高斯，先做 3D 近邻查询，取 κ=2000 个最近采样点的标签作为候选集；再用余弦阈值过滤（第 3.3 节把这个阈值记作 θ，第 4.1 节实现细节写作"余弦门 τ=0.7"，两处记号不一致，应为同一个量）；在通过过滤的候选里取与该高斯特征余弦最大的锚点（式 4）；候选集为空时退回最近背景采样点的锚点。输出：每层每高斯的绑定 aℓ。

阶段二：层级锚点去噪（第 3.4 节）

5. 多视角锚点特征：把每个锚点的种子替换成它名下全部高斯提升特征的散布平均，再归一化到单位球面（式 5）；名下为空时退回种子。多视角多高斯平均抵消了单视角区域嵌入的噪声，且不引入任何学习参数、不改变锚点表的大小。输入是绑定和 f̂，输出是去噪后的锚点表 Bℓ。
6. 查询时选层：每个层级栅格化成相关度图，与自己的 29×29 盒式平均（局部求和取平均）对半混合，然后选"峰值减中位数"对比度最大的层级（式 6）。用中位数不用均值，是为了让背景估计不被查询物体自己的像素带偏，一个只冒出一个假热点像素的细层会被拒绝。

阶段三：率失真绑定压缩（第 3.5 节）

7. 锚点表的共享基编码：对每层的 B（K×512）去均值、对 XᵀX 做对称特征分解、保留前 D 个特征向量，存系数 Z、基 U_D 和均值 m（式 7）。Z 按列做对称缩放、量化到 int8；U_D 和 m 每层只存一份。D 按语义丰富度分档：整物体层 128，两个细层 32 和 16（第 3.5 节、第 4.1 节）。因为解码映射是仿射的，可以等价地在 D 维上直接栅格化渲染——这是它查询速度 30.2 FPS 的来源之一（表 5、第 4.5 节）。
8. 绑定的空间预测编码：把高斯沿 3D Morton（Z 序）空间填充曲线重新编号，相邻符号大量相同，码流形成长低熵游程，用 LZMA 无损编码，逼近该排序诱导的一阶条件熵（第 3.5 节）。单层级场到这一步就够了。
9. 跨层父指针共享：只熵编码最细层绑定 a_L，粗层绑定用锚点级父指针表恢复——parℓ(k) 等于"绑定到细层锚点 k 的高斯在 ℓ−1 层的绑定"的众数（众数并列时取最小锚点索引，脚注 1），只对少数父指针不同的边界高斯不精确。父指针表每层只有 Kℓ 个 int16 条目。

最终码流内容：每层的（int8 系数 Z、基 U_D、均值 m）+ 最细层绑定的熵编码流 + 各层父指针表（第 3.5 节）。解码 = 熵解码 + 一串查表 + 一次仿射映射 + 按绑定取锚点特征，没有任何按场景保存或执行的网络。

### 关键公式（按原文抄，注明编号）

以下按 txt 抄录，数学符号排版以 PDF 为准。

式 (1)（第 3.1 节）：`w^v_{i,p} = α^v_{i,p} Π_{j≺p_i} (1 − α^v_{j,p})，α^v_{i,p} = o_i N_i(p; π_v)`

- w^v_{i,p}：视角 v 下高斯 i 在像素 p 的 alpha 合成权重；α^v_{i,p} 是该高斯在该像素的不透明度贡献（o_i 为高斯不透明度，N_i 为投影到 2D 的高斯）；j ≺ p_i 表示像素 p 内按前后排序。

式 (2)（第 3.1 节）：`R^ℓ_q(p) = min_j exp(⟨φ̂^ℓ_p, τ_q⟩/T) / (exp(⟨φ̂^ℓ_p, τ_q⟩/T) + exp(⟨φ̂^ℓ_p, ν_j⟩/T))`

- R^ℓ_q(p)：像素 p 在层级 ℓ 上对查询 q 的相关度；φ̂^ℓ_p 是该像素渲染出的特征，τ_q 是查询的 CLIP 嵌入，{ν_j} 是一组固定的负查询，T 是温度。对每个负例取最小值，查询压过所有负例才得高分。txt 中该项的下标写法前后略不一致（φ̂ℓp 与 φ̂ℓ_p 混用），原文公式以 PDF 为准。

式 (3)（第 3.3 节）：`f^ℓ_i = (Σ_v Σ_p w^v_{i,p} Φ^{v,ℓ}_p) / (Σ_v Σ_p w^v_{i,p} + ε)，f̂^ℓ_i = f^ℓ_i / (‖f^ℓ_i‖ + ε)`

- 分子是高斯 i 渲染到的像素特征的透射率加权求和，分母是权重和加防零项 ε；再 ℓ2 归一化。"闭式提升"的本体。

式 (4)（第 3.3 节）：`a^ℓ_i = arg max_{k∈A^θ_κ(i)} ⟨f̂^ℓ_i, b^ℓ,seed_k⟩`

- 绑定规则：在同时通过空间近邻（κ 个最近采样点的标签集合）和余弦门 θ 双重限制的候选集里，取与该高斯特征余弦最大的锚点。

式 (5)（第 3.4 节）：`b^ℓ_k = normalize( |C^ℓ_k|^{-1} Σ_{i∈C^ℓ_k} f̂^ℓ_i )`

- 锚点 k 的去噪特征 = 其名下全部高斯特征的散布平均再归一化；C^ℓ_k = {i : a^ℓ_i = k}。

式 (6)（第 3.4 节）：`ℓ★_q = arg max_ℓ ( max_p R̄^ℓ_q(p) − median_p R̄^ℓ_q(p) )`

- 查询级的粒度选择：选"峰值减中位数"对比度最大的层级；R̄ 是相关度图与自身 29×29 盒式平均的对半混合，R̄^ℓ_q = ½(box ∗ R^ℓ_q + R^ℓ_q)。

式 (7)（第 3.5 节）：`Z = X U_D，B̂ = normalize(Z U_Dᵀ + 1 mᵀ)`

- X = B − 1mᵀ 是去均值后的锚点表；U_D 是 XᵀX 对称特征分解的前 D 个特征向量；存的是系数 Z（int8）、基 U_D、均值 m；B̂ 是解码端恢复的锚点表（归一化还原单位长度）。

另有一条正文公式（第 3.5 节，链式法则）：`H(a_1,…,a_L) = H(a_L) + Σ_{ℓ<L} H(a^ℓ | a^{>ℓ})`，及父指针定义 `par^ℓ(k) = mode{ a^{ℓ−1}_i : a^ℓ_i = k }`（mode 即众数）。嵌套粒度让每个条件项趋近于零，所以只需编码最细层绑定。

说明：第 4.1 节给出了"一致性指数 γ=2"，但全文方法节没有任何公式使用 γ（在 PDF 全文检索只此一处出现），它进入哪个计算式论文未说明。

### 信号设计（重点）

| 问题 | 答案 |
| --- | --- |
| 信号是什么（重要性/复杂度/敏感度/显著度…） | 两个：①每层锚点表 Bℓ（K×512 的语义原型表）；②每高斯绑定 aℓ（1..K 的整数，即"这个高斯属于哪个语义锚点"的分配信号）。体积大头是② |
| 哪一端算得出（编码端/解码端/仅训练期） | 构造与全部编码所需统计（Morton 序、父指针众数、PCA 基）都在编码端一次算出；解码端不做任何重算，只做熵解码→逐级查父指针→一次仿射映射→按绑定取锚点特征 |
| 有无侧信息 | 没有学习型解码器、没有任何网络随码流走；但每层的共享基 U_D 和均值 m 写进码流（每层一份，确定性数据，体积极小）。比"带网络解码器"严格，比"解码端重算一切"宽松 |
| 训练期还是编码期 | 没有训练期。3DGS 几何是现成的（别人的 30k 迭代训练成果），语义场构造、去噪、编码全部在编码期一次完成（0.7 小时，表 5） |
| 和渲染质量的距离（直接测质量还是代理量） | 不测渲染质量。语义场质量用下游任务量：2D 分割 mIoU/mAcc（表 1、表 2）、3D 选择 mAcc@0.25（表 3）、LSeg 协议分割（表 4）。相关度图是查询响应的代理量，全文没有 PSNR 类指标——它压的是语义正确性，不是像素 |

### 与码流组织相关的细节

- 渐进层怎么划分：没有渐进。它的"层级"是语义粒度（整物体/部件/子部件三层），不是画质档；码流是单一固定流，没有"任意档都是文件连续字节前缀"的结构，截断无定义。
- 文件布局：每层存（int8 系数 Z、PCA 基 U_D、均值 m）+ 最细层绑定的熵编码流 + 每层一张父指针表（Kℓ 个 int16，第 3.5 节）。
- 解码端重算哪些量：不重算量化步长、不重算编码上下文。解码就是查表和仿射映射，第 3.5 节末原话 "decoding is an entropy decode, a chain of lookups, and one affine map before a gather"（gather 即按索引查表取数）。
- 侧信息：共享基和均值写码流；无解码网络。"ships no decoder"（不随场携带解码器）的准确含义是不装学出来的解码器，不是不装任何辅助数据。
- 多协议复用与存储的统计范围：完整三层场服务 2D 渲染协议（表 1 的 Overall 存储为 1.4 MB）；3D 选择协议只用最粗层，第 4.3 节原话 "the stored field records a single level"（存储的场只记录一个层级），表 3 的存储 1.35 MB 只统计这一层。也就是说论文对两种协议分别报了两种内容不同的场的存储。
- 论文未报告的项：锚点数 Kℓ 全文没有数值，只有定性说法"几百到几千个锚点"（第 4.3 节）；最终 1.4 MB 里锚点表、基、绑定各占多少没有分项表（表 7 只给出三层绑定合计 0.72 MB，约占一半）。

## 三学：证明与包装（创新怎么立住）

### 实验的统计方式与协议

- 体积怎么算：只统计语义场（语言场）的 MB；几何 3DGS 冻结不动、不计入。这与 DCCA-GS 的 total_MB（模型本体各字段比特数之和，与 HAC++ 同一种算法）完全不同，两边数字不可直接比。

## 四学：原文关键段翻译（深读层必填）

### 方法节核心段一（第 3.3 节，闭式提升）

> **原文（第 3.3 节）**："Optimization-based fields recover {f_i} from the rendering objective ∑_{v,p} ‖∑_i w^v_{i,p} f_i − Φ^{v,ℓ}_p‖²₂ with thousands of differentiable-rendering steps, since its normal equations couple all N Gaussians through the Gram matrix of the compositing weights. We instead minimize the decoupled surrogate ∑_{v,p} ∑_i w^v_{i,p} ‖f_i − Φ^{v,ℓ}_p‖²₂, which removes that coupling and admits, for each Gaussian independently, a unique closed-form minimizer, the transmittance-weighted average of the pixels it renders to: [式 3] where ε > 0 guards Gaussians with empty support. Both sums accumulate in a single gradient-free pass over the views, removing the per-scene training that Q1 otherwise demands."
>
> **译文**：基于优化的语义场从渲染目标——所有视角、所有像素上（合成特征与目标特征之差的平方和）——恢复每个高斯的特征 f_i，需要几千步可微渲染，因为它的正规方程通过合成权重的 Gram 矩阵把全部 N 个高斯耦合在一起。我们改为最小化一个解耦的替代目标：对每个高斯各自按权重求它到自己渲染到的像素特征的平方误差。这个替代目标去掉了耦合，对每个高斯独立地存在唯一闭式最小解——它渲染到的那些像素特征的透射率加权平均（式 3），其中 ε>0 用来保护没有支撑的高斯。两个求和都能在一次免梯度的遍历所有视角中累加完成，这就去掉了 Q1 原本需要的逐场景训练。

### 方法节核心段二（第 3.5 节，跨层父指针共享）

> **原文（第 3.5 节）**："Coding the L bindings independently would multiply this cost, yet a Gaussian's coarse anchor is nearly determined by its fine one, since the SAM granularities are nested and a fine region lies inside one coarse region. The chain rule makes the redundancy explicit, H(a_1,…,a_L) = H(a_L) + ∑_{ℓ<L} H(a^ℓ | a^{>ℓ}), where nesting drives every conditional term to nearly zero. We thus code only the finest binding a_L and replace each residual term by an anchor-level parent table par^ℓ(k) = mode{a^{ℓ−1}_i : a^ℓ_i = k}, exact but for the few boundary Gaussians whose parent differs. A parent table holds only K^ℓ int16 entries, and a coarser binding follows by the chained lookup a^{ℓ−1}_i = par^ℓ(a^ℓ_i), so the full hierarchy costs little more than one binding."
>
> **译文**：把 L 个绑定各自独立编码会让开销成倍增长，但一个高斯的粗层锚点几乎被它的细层锚点决定，因为 SAM 的粒度是嵌套的，一个细区域总落在一个粗区域之内。链式法则把这份冗余写成了显式形式：H(a_1,…,a_L) = H(a_L) + Σ_{ℓ<L} H(a^ℓ | a^{>ℓ})，嵌套性让每个条件项都趋近于零。于是我们只编码最细层绑定 a_L，把每个剩余条件项替换成一张锚点级父指针表：par^ℓ(k) 等于"绑定到细层锚点 k 的高斯在 ℓ−1 层的绑定"的众数，只对少数父指针不同的边界高斯不精确。一张父指针表只有 K^ℓ 个 int16 条目，粗层绑定沿 a^{ℓ−1}_i = par^ℓ(a^ℓ_i) 逐级查出来，所以整个层级结构的花费只比一个绑定多一点。

### 主结果表述段（第 4.2 节第一段）

> **原文（第 4.2 节）**："Table 1 evaluates CoSAG on LERF-OVS against eight methods that span the autoencoder, codebook, and distilled-feature paradigms, including the recent state of the art SCOUP (Budimir et al. 2026). Without any per-scene training, CoSAG attains the best overall mIoU of 66.9 and surpasses SCOUP by 2.5, and its mAcc of 86.1 is second only to SCOUP. Its three levels together occupy 1.4 MB, over 37× smaller than LangSplatV2 (Li et al. 2026b) and below the compact CF3 (Lee, Min, and Park 2025). Table 2 shows the same pattern on 3D-OVS, where CoSAG ties LangSplatV2 for the best mIoU of 94.6 while storing its field in 0.7 MB, about 76× smaller than LangSplatV2. The margin comes from feature sharing: each anchor represents hundreds of Gaussians, so storage scales with the few thousand anchors rather than the millions of primitives."
>
> **译文**：表 1 在 LERF-OVS 上把 CoSAG 与八个方法比较，这些方法横跨自编码器、码本和蒸馏特征三种路线，其中包括最新的最优方法 SCOUP。在不做任何逐场景训练的条件下，CoSAG 取得全场最好的总 mIoU 66.9，比 SCOUP 高 2.5；mAcc 86.1 仅次于 SCOUP。它的三个层级合计只占 1.4 MB，比 LangSplatV2 小 37 倍以上，也低于以紧凑著称的 CF3。表 2 在 3D-OVS 上呈现同样的格局：CoSAG 与 LangSplatV2 并列最高 mIoU 94.6，而语义场只存 0.7 MB，约为 LangSplatV2 的 1/76。差距来自特征共享：每个锚点代表几百个高斯，所以存储随几千个锚点伸缩，而不是随数百万个基元伸缩。

## 免训练路线是否绕开了我们暂停的语义先验实验（专门回答）

结论：没有绕开，因为两个问题错位；但它给了一条方向性的旁证。

1. 我们的负结果是什么：在 DCCA-GS 的几何/外观压缩管线里引入学习式语义先验，增益为零，方向已暂停（项目明确负结果清单里的一项，见 AGENT_SPEC.md 第一节）。
2. CoSAG 做的不是这件事。它的"免训练"说的是：构造语义场不做逐场景优化（闭式提升替代可微渲染训练），压缩不用任何学习模块（PCA、Morton 加 LZMA、父指针，全确定性）。语义特征在它那里是被压缩的对象，不是帮助压缩几何的辅助信号。它全文没有"用语义先验改进几何压缩"的实验，所以它的正结果既不支撑也不反驳我们的负结果——两者不在同一条对比线上。
3. 值得记下的一条旁证：CoSAG 的全部增益来自确定性编码而非学习模块。表 7 显示 Morton 重排加父指针就把绑定压到 4.05 比特/高斯，它连学习式熵模型都没试就停手了，并明确论证"绑定是语义信号不是平滑信号，通用压缩器收益小、空间重排收益大"（第 3.5 节）。这与我们"学习式概率熵模型零增益、确定性手段够用"的经验方向一致：在空间结构强的符号流上，先把排序和条件结构吃干净，可能比上网络更划算。
4. 对将来的含义：如果重启语义方向（例如给锚点场加语义辅助字段或语义引导的码率分配），更可能走通的形态是 CoSAG 这类免训练、确定性、免学习编码的路线，而不是我们试过的学习式先验。换句话说，该暂停的判断不需要因这篇论文翻案，但它提示了语义信息进入压缩管线的另一种低成本入口。

## 对 DCCA-GS 的可借鉴点

1. Morton 空间曲线重排作为零成本码率手段（第 3.5 节、表 7）：在我们锚点属性的熵编码之前，测试按 Morton 曲线（或按锚点坐标的空间排序）重排锚点及符号顺序，看区间编码码率下降多少。它与现有复合条件表正交——排序改变的是符号流的游程结构，不改条件模型——且与零侧信息契约兼容（排序规则解码端可重算）。实验：同参数下开/关重排各跑一遍，比较各字段码率；预期在量化值游程长的粗层收益最大。
2. "几乎被决定的符号不编码，改查表"的思想（第 3.5 节父指针）：它把"粗层符号几乎等于细层符号的众数"写成一张 Kℓ×int16 小表，只编码例外。直接移植到我们的质量阶梯行不通（我们基层先编、增强层后编，方向相反：知道细值才能算粗值，而粗值解码时已经有了）。但它提示了一个未试过的变体：对掩码（masks）这类二值字段，用确定性规则"本锚点标志 = 已解码空间邻居标志的众数"做预测、只编码例外，替代部分二值分解编码——注意这是确定性查表，与我们已证伪的"标志 MLP"（学习式）不同类。先离线统计邻居众数预测的命中率，低于九成就不做。
3. 确定性 PCA 投影 + int8 每列对称量化（式 7）用于特征字段：我们的 feat 字段是每锚点特征，若各维强相关，先做确定性主成分投影再量化，可能在不加学习模块、不违反零侧信息契约（基随码流携带，每层一份，代价很小）的前提下省码率。前置检查：离线算 feat 的特征值衰减，衰减快才值得做；同时注意投影会改变特征统计，可能影响现有小 MLP 熵模型从哈希网格取上下文的收益，需要联调评估而不是只看单字段码率。
4. "统一参数扫描 vs 按需分档"的消融展示方式（图 4）：我们已有分字段粗化档位，可补一张同款图——统一粗化步长扫描出饱和-崩塌曲线，再把分字段方案画成帕累托点，把"按字段分配档位"的收益从表格数字升级成一张更有说服力的曲线图。这不改方法，只补实验展示。
