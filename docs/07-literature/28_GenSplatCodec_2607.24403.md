> 一句话定位：把前馈 3DGS 压缩的解码端从"确定性恢复"换成"几何引导的一步扩散生成"——码流里传一条紧凑高斯结构流加一条很小的参考外观流，解码时用生成模型补回被丢掉的高频细节，靠"结构流压到 0.2-0.8 MB 仍能打平基线"省体积。

## 方法要点

- 动机（第 I 节）：码率压到一定程度，高频纹理、视角相关外观、弱观测细节必然从码流里被丢掉，确定性渲染救不回；外挂生成式后处理不参与表示设计、码率分配和结构感知解码，还常要多步采样，跨视角细节不一致。解法：低码率编码只保住可靠结构和紧凑外观证据，缺失细节由几何引导的生成来补，生成模型成为编解码器内部的解码变换。
- 输入是稀疏视角图像加相机参数（式 1）。双流架构、三阶段训练。前馈高斯预测网络直接预测可渲染高斯集，每个高斯带中心、尺度、旋转四元数、不透明度、RGB 颜色；预测用两条特征路：结构路用局部-全局注意力骨干做跨视角聚合、只负责预测中心；细节路把预训练 DINO 特征过一层小 MLP、只注入属性预测头（两路不对称融合，细节特征不干扰中心估计）。颜色用零阶球谐，即每高斯一个视角无关 RGB 向量，不带高阶球谐系数。
- 率失真引导剪枝：对每个高斯按"视觉贡献 ÷ 属性编码代价"排序（式 6：分子 v_j 由不透明度和空间覆盖估计，分母 b_j^a 由学习式熵模型给出，几何码长无法分解到基元、用属性码长当代理），给定保留率截取头部；保留率取值论文未报告。剪枝只在编码端执行，解码端拿到的就是剪完的高斯。
- 几何/属性分离编码：中心量化后用 G-PCC 压成几何流 B_μ；属性按中心 Morton 码排序（空间相近的基元在序列里也相近），属性向量变换到 11 维编码域（颜色 3 维 + 不透明度 1 维 + 尺度 3 维 + 四元数 4 维），经"超先验 + 已解码 Morton 邻居空间上下文 + 通道自回归（CARM）"的分层熵模型编码成主属性流 B_m 和超先验流 B_h。结构流 B_G={B_μ, B_m, B_h}（式 7）。
- 参考外观流 B_R：从预定义候选视角集按相机距离挑一张参考图，VAE 编码到 latent、量化、按字节平面重排后熵编码（式 8）。该流显式传输并计费（占总码率 0.65%-2.20%，Table VI），不依赖未传输的原图；四条流（几何/属性/超先验/参考）全部计入总码率（式 23）。
- 解码（第 III-C 节）：解出紧凑高斯和参考 latent；在查询视角渲染低码率 RGB 锚和几何图，在参考视角渲染几何图；两个视角的深度图归一化、缩放到 VAE latent 分辨率后，经轻量几何控制器生成注入各层级的控制信号；查询、参考两个 latent 作为共享一步多视角生成 U-Net 的两个耦合分支，注意力层里两支 token 拼成共享序列做跨视角交互，一步输出合成查询 latent，VAE 解码出最终图。生成底座是预训练 Stable Diffusion 类先验（消融表行名"+Naive One-Step SD"）。解码依赖完整模型权重（熵模型、VAE、几何控制器、生成 U-Net 全在解码端）；论文没有解码端重算量化步长/编码上下文的设计。
- 三阶段训练（第 III-D 节）：阶段 1 前馈高斯预训练，损失 = 渲染 MSE + LPIPS + 不透明度 ℓ1 稀疏正则；阶段 2 冻结预测器，训练剪枝、属性量化、分层熵模型，损失 = 保真（MSE+SSIM）+ λ_rate·归一化码率——G-PCC 不可导，几何流码长不进损失，靠剪枝间接压；参考流不进这个阶段的替代码率，评测时四条流全部计入。阶段 3 冻结高斯编码路径，生成解码器在"真实码流解出来的条件"（而非理想未压缩输入）上训练，损失 = MSE + LPIPS。
- 码流组织：无渐进层，Ours-Low/Mid/High 三个档是不同 λ_rate 的三次独立编码（Table VI 给出 λ_rate=1.000/0.100/0.002 对应 0.206/0.376/0.830 MB，大小与 Table I 三档一一对应），论文没有单文件多档、前缀可截断的设计。运行时间分析提到"独立编码的高斯分块支持多设备并行、块内保留上下文依赖"（第 IV-C 节），块大小与划分规则论文未报告。

## 实验口径

- 体积 = 每场景平均总码流 MB，含高斯结构流和参考外观流（第 IV-A 节）。
- 数据集：DL3DV（224×224 和 518×518 两档分辨率，2/4/6 上下文视角）和 RealEstate10K（224×224，标准 2 视角协议），官方或通用测试划分，无逐场景优化。
- 基线两组：DepthSplat、AnySplat、YoNoSplat 三个前馈重建方法当未压缩参照；它们的全量高斯输出再接 FCGS（λ_FCGS=0.0001）或 SOGS（默认配置）构成级联压缩基线。没有和逐场景优化的压缩器（HAC++/ContextGS 等，仅第 II 节引作相关）直接比。
- 指标：PSNR/SSIM/LPIPS/FID/MUSIQ/MANIQA；一致性另用 SIFT 对应点、CLIP、跨视角 LPIPS、VBench 三项（MS/BC/SC）。
- 训练配置（学习率、轮数、硬件、生成先验具体版本、保留率取值）：论文未报告。
- 运行时间：编码 1.58 s、解码 1.80 s 每场景，生成步仅 0.12 s（第 IV-C 节）。
- 跨视角一致性（Table III）：与 MVSplat360、LatentSplat 比较全部指标最优，SIFT 对应点 90.88，比最强基线高 15.2%。
- 码率分配（Table VI）：主属性流占 67.59%-76.47%，几何流 21.31%-29.35%，超先验+参考流合计不超过 3.06%。

## 关键数字

- DL3DV 上 Ours-Mid 对 YoNoSplat 存储 6.508→0.376 MB，17.3 倍缩减；RE10K 上 Ours-High 对 YoNoSplat 6.508→0.748 MB，降 88.5%（第 IV-B 节）。
- Ours-Low 用每场景仅 0.206 MB 达到 19.21 dB，约用 DepthSplat（20.500 MB、19.35 dB）1% 的存储；Ours-Mid 与 YoNoSplat+SOGS PSNR 相近（20.02 对 20.04 dB）时少用 68.6% 存储，同时 SSIM、LPIPS、FID 更好；Ours-High 在 DL3DV 报告的全部六项质量指标最优：20.76 dB PSNR、0.638 SSIM、0.184 LPIPS、50.51 FID、0.830 MB（第 IV-B 节）。
- 518×518 档（Table IV）：Ours 18.71 dB / 0.332 LPIPS / 67.95 FID / 0.577 MB，对 DepthSplat+SOGS 为 34.2 倍缩减。
- 输入稀疏性（Table II）：4/6 视角下分别用 0.989/1.089 MB 拿到全部报告指标最优。
