> 一句话定位：把 3DGS 每个高斯的视角相关外观从 3 阶球谐（每高斯 192 字节）换成 8 维潜码加一个全场景共享的小 MLP 解码器（每高斯 28 字节），并把球谐、球面 Voronoi、NASG、NASGabor 和这个神经模型放进同一条优化管线里做受控比较，覆盖质量、显存、训练速度和桌面/移动端渲染。

## 方法要点

- 动机：3 阶球谐每高斯 48 个系数，占每高斯参数大头（引 [3]）；高斯数多时仅更新球谐系数就占优化时间最多 50%（引 Faster-GS [22]）；球谐"系数主导每个图元的存储和内存流量，而其带限基底限制了角度细节"（摘要原文："SH coefficients dominate per-primitive storage and memory traffic, while their band-limited basis restricts angular detail"）。作者立场（第 2 节）："Our work instead studies which appearance parametrization should be used in the first place"——先问该用什么表示，再谈压缩表示。
- 共同接口（第 3.1 节，公式 2）：所有外观模型写成 c(d) = φ(c0 + Aψ(d))，c0 是每高斯 3 个基色值，Aψ 是视角相关外观模型，φ 是颜色激活（默认 ReLU）；基色初始化、致密化处理全部照抄 3DGS 基线，各模型只替换 Aψ（保留标准 3DGS 的每高斯表示、只替换视角相关颜色，与 Scaffold-GS 从潜特征解码图元属性的做法划清界限）。对照模型（第 3.2 节）：球面 Voronoi（SV）软插值、每站点 7 参数（实验用 7 站点）；NASG 归一化各向异性球面高斯核加权和、每叶 8 参数（实验用 1 叶）；NASGabor 再加一个余弦载波频率参数。SV 的基色可从站点值里折出（A.2 节，softmax 权重和为 1），故能写成共同接口形式。
- 神经模型（第 4 节）：每高斯存 8 维特征向量 f；视角方向 d 用 0-3 阶球谐基底编码成 16 维（零存储），特征逐分量频率编码（k=1，8 维变 16 维），拼成 32 维输入 x。共享 MLP 两层隐藏层各 16 神经元、3 输出、隐藏层 ReLU、无偏置，共 816 参数（全场景一份，fp16 约 1.6 KB）；输出残差用 tanh 截断 Aψ(d) = tanh(MLP_θ(x))，防止解码器无界补偿基色偏移。渐进调度：残差先禁用，方向编码频带按球谐的调度每 1000 迭代激活一档，未激活输入置零、无梯度。前向反向全部半精度，每高斯外观占用 = 3×4 + 8×2 = 28 字节。
- CUDA 实现（第 4 节、B.2 节）：各模型的前向/反向设备函数内联进可微光栅化器，用 tiny-cuda-nn 的运行时代码生成（NVRTC）按模型配置即时编译；外观只对通过剔除的图元在预处理核里求值，无独立 pass、无全局内存往返；方向梯度传回高斯位置，保留外观依赖的致密化梯度。神经模型按 tiny-cuda-nn 全融合方式在 Tensor Cores 上半精度求值，一个 warp 处理 32 个高斯；权重由 Adam 以单精度保存和更新，每次迭代前拷贝半精度副本，梯度用 128 的损失缩放累加。
- 编码/码流：本文没有独立的编码阶段——无熵编码、无码率分配，训练结束即得最终模型。部署导出（第 4 节 WebGL 部分、B.3 节）：视角无关量（参数激活、归一化常数、第一层权重矩阵中视角无关 17 列对应的预激活）在导出时预先算好，每帧只算视角相关部分；几何统一按 Spark 布局压到每高斯 16 字节（fp16 均值、8 位对数尺度码、24 位八面体折叠四元数、8 位基色和不透明度）；每高斯外观载荷（表 6）：SH 40 字节（45 个系数按 7/8/6 位打包，每阶一个共享尺度存每场景一份）、SV 112 字节（7 站点×7 个 fp16）、NASG 32 字节、NASGabor 32 字节、Neural 32 字节（16 个 fp16 预激活，替代原特征存储）。
- WebGL 端（第 4 节、B.3 节）：Three.js 自建查看器，逐帧先用片元着色器 prepass 算每个高斯的视角相关颜色写入纹理，再做泼溅合成；深度排序在 CPU 异步做；特征与权重按原生半精度存储求值；第一层的视角无关贡献按高斯预计算成 16 个 fp16 预激活，每高斯乘加次数从 816 降到 560，省 31%。

## 实验口径

- 数据与协议（第 5.1 节）：21 个场景（Mip-NeRF 360、Tanks & Temples、Deep Blending、NeRF Synthetic），分辨率和训练/测试划分照抄 3DGS 原论文；全部用 Faster-GS [22] 优化、MCMC 致密化 [32]、场景专属高斯预算 [36]；除外观模型外超参完全一致，无外观专属调参；真实场景启用 PPISP [13] 处理光度差异，防止表达力强的模型把光度变化当成视角依赖学走。
- 体积口径（第 4 节、表 1）：Bytes/G 只计每高斯外观参数的部署字节数（None 12 = 3 个 fp32 基色；SH 192 = 48 个 fp32 系数；Neural 28 = 12 字节基色 + 16 字节 fp16 潜码），是存储占用、不是熵编码后的码率；共享 MLP 的 816 参数不计入 Bytes/G。
- 训练配置（B.1 节、表 5）：30k 迭代；SH 系数学习率 0.000125 恒定，Neural 特征 0.008 余弦、共享权重 0.003 预热；神经模型 Adam 第二动量对共享权重 β2=0.99（A.4 节）。
- 测量（C 节、5.1 节）：表 1 及逐场景表为 5 次运行平均；计时和显存只在第一次运行测，硬件 RTX 4090；表 2 覆盖 RTX 5090/4090/3090 和 WebGL 端 RTX 4090、MacBook M1 Pro、iPad M2、iPhone A18 Pro。
- 对比对象：无外观（None）、SH、SV、NASG、NASGabor、Neural，共 6 行。

## 关键数字

- 正文读法（第 5.2 节）：各模型质量差异基本在运行间波动之内；神经表示以 28 字节对 192 字节持平或超过 3 阶球谐，训练更快、峰值显存更低、渲染更快（参数更新的内存流量变小）；摘要给出的加速倍数是 1.3×。
- 表 2 摘录（720p 平均帧时间，毫秒；Bicycle 场景，6M 高斯）：CUDA RTX 4090 上 SH 2.75 / SV 2.80 / NASG 2.25 / NASGabor 2.26 / Neural 2.38，NASG 系比 SH 快最多 18%（第 5.2 节）；WebGL iPhone A18 Pro 上 SH 45.0 / SV 溢出（OOM）/ NASG 44.3 / NASGabor 44.3 / Neural 45.1；iPad M2 上 SH 35.9、Neural 38.1；WebGL 端除 SV 外各模型差距缩到几个百分点内。
- 表 8 摘录（神经结构消融，Mip-NeRF 360）：默认（2 隐层×16 神经元，F=8）PSNR 28.53 / 4m17s / 443.6 FPS / 28 字节 / 560 MAC；1 隐层 28.39 / 304 MAC；3 隐层 28.57 / 816 MAC；32 神经元 28.62 / 2144 MAC / 449.0 FPS；F=16 无频率编码 28.56 / 44 字节；默认走非融合路径 28.56 / 16m08s / 112.1 FPS（融合为 4m17s / 443.6 FPS）。
- 表 4（颜色激活 ReLU/Softplus/Hardsigmoid/Sigmoid × 不透明度学习率 0.05/0.025 + lr=auto 的两因素对照）：激活函数与不透明度参数化在优化中互相影响，最优配置逐场景差异很大；Sigmoid 的 SSIM 最好，有界取值防止"低不透明度+超界颜色"拟合白色不透明区域的退化解。
- 表 7（致密化策略消融）：MCMC 对 3DGS 的 ADC，再加两个低预算变体（MCMC 0.1× 预算；ADC+Speedy-Splat 剪枝）；高预算两组、低预算两组的可见高斯数几乎相同（近似等模型尺寸比较）；外观模型排序不随致密化策略变，MCMC 在等尺寸下全面胜过 ADC。
- 表 8 关键发现：加共享解码器容量在存储和内存流量上免费，加每高斯特征则每个高斯都要付钱；最宽的解码器在 CUDA 上反而渲染最快（作者作为假设提出：更表达的外观让几何不必代偿，图元更紧凑、混合操作更少）。
- 表 3 定性排名（训练时间/渲染时间/角度分辨率/鲁棒性/简单性/紧凑性，++ 到 −−）：球谐过拟合最少但角度分辨率最差；SV 鲁棒性最差；NASG(abor) 质量速度比最好；神经模型最紧凑、但"按场景正则化难"。
- 论文分析（第 6 节，图 4、图 5）：真实采集里视角相关残差常常不是反射，而是采集期间场景变化的记录——bonsai 场景最上面的书在拍摄中移动了（图 4），garden 场景拍摄者踩过草地（图 5）；表达力强的模型（NASGabor）会把这类不一致吸收成视角相关效果，球谐表达力不够只能让几何去补偿。
