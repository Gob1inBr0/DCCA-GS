> （另注："CompGS"这个名字至少被两篇论文用过：本篇前作 Liu 等 ACM MM 2024，以及 Navaneet 等 Compact3D 的 ECCV 2025 版本，见本文参考文献 [22]，引用时需区分。）

> 一句话定位：CompGS 的加强版——静态部分给预测和熵模型都补上哈希特征网格空间先验、残差嵌入从 8 维减到 4 维，把 T&T/Deep Blending 各场景最低码率点压到 1.48–3.91 MB；再把同一套"预测 + 残差"思路沿时间轴铺开，用 I/P 场景流式框架压缩动态场景，每帧只要 0.05 MB。

## 一学：问题与洞察（创新从哪来）

### 它认定的主要矛盾

第 1 节，四层递进：

1. 基础方法剪枝太粗："such rudimentary pruning strategies risk over-aggressive primitive removal"——启发式剪枝可能删过头，伤建模精度。
2. 逐基元量化忽略基元间冗余："quantization on individual 3D Gaussians ignores inter-primitive redundancy"。
3. 已有预测式方法（含前作 CompGS [26] 与 HAC [27]）对空间相关性挖掘不足："the spatial correlations among 3D Gaussians remain insufficiently explored, suggesting considerable potential for improvement"。
4. 主战场：动态场景压缩没人做——"existing compression methods only focus on static scenes, leaving the compression challenge in dynamic scenes unresolved"。

### 支撑观察（直觉 / 数据 / 失败实验）

- 图 1、图 2（第 1 节）：与前作同口径的空间相关性统计（20 近邻平均余弦距离），各属性显著相关。
- 图 3（第 1 节）：相邻 P 场景同一动态区域的高斯分布可视化，运动模式一致、连续且有局部性（continuity and locality），是时间预测可行的证据。
- 图 4（第 1 节）：静态区域在相邻时刻存在环境光照的细微漂移——支撑"静态基元只补颜色、不动几何"的设计。
- 第 3.3 节的实验观察："we experimentally observe that hyperpriors cannot substantially benefit the probability estimation of Σ̄ω"——超先验对协方差的概率建模帮助不大，所以协方差只用空间先验建模。

### 显然的路为什么没走

- 动态的显然路 A：非流式 4DGS（正则空间模型加形变场，一次建完）。第 2.B 节指出这类方法不能增量构建、不能渐进传输，所以选流式 I/P 框架。
- 动态的显然路 B：像 3DGStream/HiCoM 那样对所有基元一律加运动偏移。第 5.C 节明确批评"indiscriminately apply motion offsets to all primitives"会在静态区造成伪影；消融 Table X 显示全按动态处理的变体在 Coffee Martini 只有 18.78 dB，比完整方法低 9.59 dB。所以先做动静解耦，静态基元只补颜色。
- 静态的显然路 C：像 Scaffold-GS 纯派生、不存残差。Table VI 显示去掉残差嵌入 Train 掉 0.57 dB，继承前作结论。

## 二学：机制（洞察怎么变成方法）

### 核心流程

静态（第 3 节，图 5–7）：

1. 结构沿用前作：锚点基元（位置、协方差、32 维参考嵌入）加每锚点 K=10 个耦合基元（4 维残差嵌入，前作 8 维；第 5.A 节）。
2. 预测升级：预测特征从"fω 拼残差嵌入"扩为 ζ = fω ⊕ fγk ⊕ ϵω（式 2），其中空间上下文 ϵω 用锚点位置到可学习特征网格查询（引 HAC [27] 的哈希编码性质，捕获相邻锚点间的相关性）。几何仍走仿射变换（式 3–5），外观走视角嵌入加线性层（式 6）。
3. 熵模型升级（图 7）：量化近似仍用均匀噪声（式 8），量化步长由先验特征自适应预测（第 5.A 节；前作是固定步长加单参数可学习）；概率建模改成"空间先验 ϱ（特征网格上下文，三个参数共享）+ 超先验（f 与 fγ 用，Σ 不用）"双先验（式 9–12）。
4. 训练目标（式 1）：arg min D(x, x̃) + λR(Ω, Γ)，λ ∈ {0.0001, 0.0005, 0.001}（第 5.A 节）。

动态（第 4 节，图 8–9）：

1. 场景序列 b1…bT 按流式 I/P 处理：I 场景（b1）用静态方法压缩；每个 P 场景 bt 从前一场景继承基元 {Ωt−1, Γt−1}。
2. 动静解耦（式 14）：在 bt 的 V 个训练视图上跑 2D 运动检测得掩码，把继承基元投影到各视图，与掩码相交则该视图运动置信度 ϖv=1，取平均得 ϖ；锚点 ϖ 低于阈值进静态集，其余进动态集。
3. 动态基元：运动残差 ρd 存特征网格，与残差嵌入拼成 ζd，预测形变场（平移/缩放/旋转，式 15），仿射得新几何（式 16），外观做偏移（式 17）。
4. 静态基元：补偿残差 ρs 只调颜色（式 18；实验发现调不透明度没收益）。
5. 时间自适应控制（第 4.C 节，式 19–21）：静态转动态看基元产生的高斯位置梯度累积（超阈值 τs→d 判为漏判运动）；动态转静态看形变幅度 ϑ（平移/缩放取 L1 范数，旋转与单位四元数的余弦相似度，式 20；低于 τd→s 判为误判运动）；新物体由位置梯度触发创建新基元，且创建阈值故意设得比静态转动态更高，优先用编码效率更高的动态基元。

编码期（第 5.A 节）：锚点位置走 G-PCC，其余参数按估计分布用 torchAC 算术编码。解码期：熵解码加前向预测，无额外模块。

### 关键公式（按原文抄，注明编号）

优化目标（式 1）：

> Ω⋆, Γ⋆ = arg min_{Ω,Γ} D(x, x̃) + λR(Ω, Γ)

率项分解（式 7）：

> R(Ω, Γ) = H(Ω, Γ) + KL[p_g(Ω,Γ) ∥ p_e(Ω,Γ)] = E_{p_g}[−log p_e(Ω, Γ)]

真实分布未知，率项 = 熵加估计偏差——把"熵模型估得准就等于省码率"写成了显式公式。（原注脚：为书写简便，分布 p_g(·) 缩写为 p(·)。）

量化近似（式 8）：

> f̄ω = fω/πfω + U(−πfω/2, πfω/2)

πfω 为量化步长，U 为均匀噪声；fγk、Σω 同样处理得 {f̄γk, Σ̄ω}。

概率建模与码率（式 9–12）：

> p_e(f̄ω) = N(εf, βf), with εf, βf = Ef(ηω ⊕ ϱ)
> R(f̄ω) = E_{p_g}[−log p_e(f̄ω) − log p_e(ηω)]
> R(f̄γk) = E_{p_g}[−log p_e(f̄γk) − log p_e(ηγk)]
> R(Σ̄ω) = E_{p_g}[−log p_e(Σ̄ω)], with p_e(Σ̄ω) = N(εΣ, βΣ), εΣ, βΣ = EΣ(ϱ)

ϱ 为特征网格空间先验，η 为超先验；协方差只条件在空间先验上。总码率（式 13）为三个 R 在全体基元上求和。

运动置信度（式 14）：

> ϖv = 1, if O(ω, γ) ∩ ev ≠ ∅;  0, otherwise

O(ω,γ) 为投影到视图 v 的高斯，ev 为该视图的 2D 运动掩码；总置信度 ϖ 取各视图平均。

动静转换（式 19–21）：静态转动态 {Ωs→d, Γs→d} = {ωs, γs | ▽g(ωs) > τs→d}，▽g 为基元产生的全部高斯的位置梯度累积；形变显著度

> ϑ = ∥ψt∥1 + ∥ψs∥1 + 1 − q(ψR)·qi / (∥q(ψR)∥2 ∥qi∥2)

q(ψR) 为旋转矩阵对应的四元数，qi 为单位四元数；ϑ(ωd) < τd→s 的动态基元转静态。

### 信号设计（重点）

| 问题 | 答案 |
| --- | --- |
| 信号是什么（重要性/复杂度/敏感度/显著度…） | 静态：熵模型码率估计（正则信号）+ 特征网格空间先验；动态：2D 运动掩码推出的运动置信度 ϖ（动静分类）、高斯位置梯度累积（漏判运动的代理）、形变幅度 ϑ（误判运动的代理） |
| 哪一端算得出（编码端/解码端/仅训练期） | 静态部分：空间先验由码流内位置查询同一特征网格，解码端可重算；超先验需随码流传输。动态部分：运动掩码、位置梯度、形变幅度都只在训练/编码端可得，决策结果通过码流组织方式（哪些残差被编）间接传给解码端 |
| 有无侧信息 | 超先验 η 是侧信息（码率计入式 10–11）；运动置信度与梯度信号本身不进码流 |
| 训练期还是编码期 | 全部在训练期/编码端；解码期只做熵解码加前向预测 |
| 和渲染质量的距离（直接测质量还是代理量） | 码率项是代理量；位置梯度被明确当作渲染误差的代理（第 4.C 节："use the positional gradients [1] of 3D Gaussians ... as a surrogate measure for rendering error"）；失真项 D 直接用渲染损失 |

## 三学：证明与包装（创新怎么立住）

### 实验口径

- 静态：T&T、Deep Blending、Mip-NeRF 360，严格按 3DGS 协议（同训练/测试划分、相机位姿、初始点云，第 5.B 节）；对比 3DGS 加六个压缩方法 [22–27]（含 HAC 与前作 CompGS；支持多码率的方法取三个码率点）。
- 动态：Neural 3D Video，按 HiCoM 协议取前 300 帧、中间视图测试；流式方法报每帧模型大小；3DGStream 与 HiCoM 的数字直接引 HiCoM 论文（实验设置与其严格一致，第 5.C 节）。
- 体积：静态报模型大小 MB；动态报总大小与每帧大小（Table IV）。

### 主结果（注明表号）

- T&T Train：最低 3.91 MB / 22.44 dB（3DGS 257.44 MB，65.84×）；中间码率点 22.56 dB / 4.92 MB，比当时最强的 HAC [27] 同档 8.58 MB 再省超 50%（Table I、第 5.B 节）。Truck 最低 3.09 MB（197.83×）（Table I）。
- Deep Blending：DrJohnson 782.10→2.12 MB（368.92×）、Playroom 549.88→1.48 MB（371.54×）（Table II、第 5.B 节）。
- Mip-NeRF 360：室外场景平均压缩 80.36×、室内 94.83×；对比方法只有 8.73×–68.03×（室外）、8.56×–69.99×（室内）（Table III、第 5.B 节；txt 中 Table III 与图 10 文字交错，逐场景数字只归图 10，此处只引正文确认的均值口径）。
- 动态 Coffee Martini：28.37 dB / 每帧 0.05 MB；3DGStream 26.73 dB / 每帧 7.6 MB，HiCoM 28.19 dB / 每帧 0.8 MB（Table IV、第 5.C 节）——体积与质量两个维度同时压过流式对手，且与非流式方法 [15][18][19] 质量相当（拿不到未来时间戳的前提下）。
- 复杂度：训练 28.40 min、编码 4.35 s、解码 3.87 s、渲染 5.86 ms（Table XI），全面快于前作的 37.83 min / 6.27 s / 4.46 s，归因于精简熵模型的条件依赖。

- 框架级渐进叠加：Table V——3DGS 加空间预测（Train 257.44→79.88 MB）再加率失真优化（→3.91 MB）；Truck 611.31→47.34→3.09 MB。

- 动态三连：Table IX 渐进加时间预测（Coffee 24.86→28.67 dB，+3.51 dB；Sear Steak +5.09 dB）与自适应控制（20.45→13.79 MB）；Table X 拆解耦与光照补偿——全按动态处理掉 9.59/14.57 dB，去光照补偿掉 0.56/0.53 dB。

### 贡献列表（原文照抄 + 逐条标注）

1. "We propose a holistic compression framework, namely CompGS++, to furnish compact 3D representations for both static and dynamic scenes. By exploiting redundancy-eliminated primitives to characterize 3D scenes, CompGS++ achieves superior compression performance across leading static and dynamic benchmarks." —— [框架] 静态加动态的统一框架声明。
2. "We develop a novel spatial primitive prediction module for static scenes that effectively minimizes inter-primitive redundancy. Additionally, we propose a rate-constrained optimization module that utilizes rate costs as regularization to enhance the compactness of primitive parameters." —— [机制] 静态升级：空间上下文增强的预测 + 加强熵模型的率失真正则。
3. "We design a compact representation paradigm for dynamic scenes, incorporating a temporal primitive prediction module to efficiently eliminate primitive redundancy between consecutive scenes. Furthermore, we propose a temporal adaptive control mechanism to improve the efficacy of dynamic modeling, thereby yielding accurate and compact scene representations." —— [机制] 全新的动态压缩路线：时间预测加时间自适应控制。

三条都是实条目，无凑数。

### 讲故事方式

主线一句话："空间上靠预测消冗余（静态），时间上也靠预测消冗余（动态），参数内冗余统一交给率失真正则。"最有力的是 Table IV：每帧 0.05 MB 对 3DGStream 的 7.6 MB、HiCoM 的 0.8 MB，质量还更高——一个数量级以上的差距，配上"首个动态 3DGS 压缩框架"的占位，说服力极强。静态部分最有力的是 Table V 的 257.44→3.91 MB 两步分解。

### 相对 CompGS（前作）改了什么（任务特别要求，按 txt 归纳）

1. 静态预测加空间上下文：预测特征从"fω 拼残差嵌入"（前作第 3.2 节）扩为 fω ⊕ fγk ⊕ ϵω（式 2），ϵω 由锚点位置查 HAC 式特征网格。
2. 熵模型双先验：前作只拿 f̃ω 当上下文；++ 版加特征网格空间先验 ϱ（三参数共享），并实验发现协方差不需要超先验（第 3.3 节），条件依赖更少、编解码更快（Table XI）。
3. 量化步长：前作 sf=sg=1 固定、sΣ 单参数可学习（前作第 3.4 节）；++ 版由先验特征自适应预测（第 5.A 节）。
4. 残差嵌入 8 维减到 4 维；λ 档位整体下移一个量级（{0.001, 0.005, 0.01} → {0.0001, 0.0005, 0.001}），主打更低码率区间。
5. 新增动态场景整条流水线（I/P 场景 + 时间预测 + 时间自适应控制），前作完全没有。
6. 静态数字大幅进步：Train 最低 5.51→3.91 MB、Truck 6.27→3.09 MB（Table I 对前作 Table 8），训练与编解码时间同时下降。

## 对 DCCA-GS 的可借鉴点

1. 位置梯度当渲染误差代理（第 4.C 节式 19）→ 直接对应我们机制 B（I6 渲染损失梯度 EMA 监督）：它用累积位置梯度决定基元动静转换，我们用渲染梯度 EMA 监督 AQM，同一信号家族。写作时可引它作"梯度信号能驱动压缩决策"的独立证据；实验上可对照两种梯度聚合（位置梯度累积 vs 渲染损失梯度 EMA）给 AQM 供信号的差异。
2. 量化步长由先验特征自适应预测（第 5.A 节）→ 与我们 AQM 的 Q = Q0×(1+tanh(q_AQM))×(1+tanh(mlp_complexity)×α) 同方向，说明"逐基元步长自适应"在多个框架下都有效。差异点：它的步长条件在熵模型先验上（部分是侧信息），我们硬约束零侧信息、只用解码端可重算特征——这是相关工作对比里的差异化卖点。
3. 熵模型消融结论可白拿（Table VIII 加第 3.3 节观察）：空间先验与超先验互补，协方差不需要超先验。我们的底座 HAC++ 熵模型同属"哈希网格上下文 + 超先验"一族，这份证据支持我们在 AQM 里不给熵模型增加新的条件依赖，保住零侧信息和解码端复杂度。
4. 动态部分对我们参考有限（DCCA-GS 是静态压缩框架），但其消融矩阵的组织方式（框架叠加 → 组件开关 → 超参扫描，静态动态各跑一轮）可直接套进我们的主实验章节。
