## 0. 调研方法与证据分级

- 每篇条目固定包含 7 个字段：出处、一句话创新点、核心方法、报告效果、证据分级、批判性评估、与 3DGS 相关性。
- 效果数字均来自论文摘要/正文/项目页，未查到的数字明确标注，不猜测。
- 证据分级：
  - **A**：有官方代码，且关键数字可从论文/仓库复核；
  - **B**：会议页/期刊页/摘要给出数字或可获取全文，但无代码或细节不全；
  - **C**：仅能获取元数据/摘要片段，或无法核实具体数字。
- 批判性评估关注：基线公平性、适用范围、可复现性、结论是否超出证据、术语是否“新瓶旧酒”。
- 链接核验（2026-08-11 以 HTTP 状态码抽查全部外链）：arXiv、GitHub、期刊 DOI 等绝大多数返回 200/202；IEEE/Wiley/INFORMS/ScienceDirect/bioRxiv 对自动化请求返回 403/429 属反爬保护，浏览器可正常访问；《智能系统学报》官网偶发超时，已补充 DOI 链接（10.11992/tis.202306042）。

## 1. 术语澄清：清单里其实混了三种任务

“神经压缩（Neural Compression）”在文献中有两个既有联系又不同的含义，加上本清单实际包含的第三类，共三类：

1. **神经网络模型压缩（Model Compression）**：把训练好的 DNN 本身变小、变快（剪枝、量化、低秩、蒸馏）。清单中的 MCNC、TropNNC、近似微分等价、滤波器剪枝、三篇模型压缩综述属于此类。
2. **神经数据压缩（Neural Signal/Data Compression）**：用压缩算法处理脑电/神经信号这类“神经数据”。清单中的 STCR、皮层病灶检测、超高密度神经记录属于此类，与“压缩神经网络”无关，只是中文翻译上容易混淆。
3. **神经压缩编码（Neural Data/Image/Video Compression）**：用神经网络（含 INR、VQ、熵模型）压缩图像、视频、地理空间等信号。清单中的 RDP 最优压缩、超高效解码、ANI、SFNIC、MSDSDC、非对称自编码器、COLI、压缩潜空间适配 MLLM、显微成像 VQ-VAE，以及地理空间/视频 INR 综述属于此类。

本调研沿用你给出的六类分组，但请以上述三种任务划分理解每篇的定位。

## 2. 结论摘要

- **最成熟的方向**：DNN 模型压缩（剪枝/量化/蒸馏，综述最多、工程落地最成熟）；神经图像压缩（Ballé 系端到端编码 + 轻量化/解码加速是当前热点）。
- **增长最快的方向**：INR/Neural Field 压缩（视频 INR、图像 INR、4-bit 极压缩），与 3DGS 的“把场景压进网络/码本”思路同构。
- **与 3DGS 量化压缩关系最近的 5 篇**：
  1. *Optimal Neural Compressors for the RDP Tradeoff*：格点编码 + 共享抖动，直接给上一轮调研的 LVQ/抖动量化提供理论支撑；
  2. *Ultra-Efficient Decoding*：低秩表示 + VQ 消除解码端瓶颈，可迁移到 3DGS 属性解码；
  3. *Extreme Compression of Adaptive Neural Images*：把 INR 权重压到 4-bit，与 3DGS 权重/属性低位量化同构；
  4. *COLI*：INR 压缩的预训练-微调、混合精度与后训练超压缩流水线，几乎就是 3DGS v3 路线的模板；
  5. *Bridging Compressed Image Latents and MLLMs*：压缩潜空间直接面向下游任务优化，提示 3DGS 量化失真目标可以换成渲染/任务损失而不是参数 MSE。
- **对现有 v1.1 基线的影响**：没有证据表明需要推翻“均匀 8-bit 标量量化”基线；反而多篇论文（RDP、Ultra-Efficient、ANI）支持下一步把 VQ/格点/低秩/后训练微调加入 v2/v3。

## 3. 综述类

### 3.1 《Lossy Neural Compression for Geospatial Analytics: A Review》

- 出处：IEEE Geoscience and Remote Sensing Magazine, 13(3), 2025, pp. 97–135（开放获取）· [DOI](https://doi.org/10.1109/MGRS.2025.3546527)
- 一句话创新点：第一份系统梳理“神经压缩用于地理空间分析”的综述，把神经压缩基础与 EO/ESM 数据特性打通。
- 核心方法：介绍 NC 基础（有损压缩、熵模型、自监督/基础模型蒸馏），对比地球观测/地球系统模型数据与自然图像的差异，梳理各模态应用，展望压缩特征表示用于机器间通信。
- 报告效果：综述类，无单一效果数字；贡献在于问题框架与未来方向。
- 证据分级：B（开放获取全文可查，无代码/实验）。
- 批判性评估：覆盖面广但以归纳为主；未对 NC 方法在 EO 上的增益做统一基准，横向比较需回到原始论文；部分“机会”属于推测。
- 与 3DGS 相关性：间接。信息论压缩与表示蒸馏的框架与 3DGS 压缩同源，但无直接可搬方法。

### 3.2 《神经网络压缩联合优化方法的研究综述》

- 出处：宁欣 等，《智能系统学报》，2024, 19(1): 36–57 · [DOI](https://doi.org/10.11992/tis.202306042) · [期刊页](https://tis.hrbeu.edu.cn/oa/darticle.aspx?type=view&id=202306042)
- 一句话创新点：系统归纳剪枝、量化、知识蒸馏的**联合优化**组合，而非单方法。
- 核心方法：综述“知识蒸馏+剪枝”“知识蒸馏+量化”“剪枝+量化”三类组合压缩算法，讨论优势互补与部署约束。
- 报告效果：综述类，无统一效果数字；给出组合方法相对单方法的定性增益与适用范围。
- 证据分级：B（期刊全文可查，无代码）。
- 批判性评估：以定性归纳为主，缺少统一实验对照；组合方法增益高度依赖模型/任务，不能外推为普适结论。
- 与 3DGS 相关性：间接。v3 的“RDO 训练=剪枝+量化+恢复训练”正是这篇综述讨论的组合思路。

### 3.3 《A survey of implicit neural representations for video compression》

- 出处：Multimedia Tools and Applications, 85(8), 2026 · [DOI](https://doi.org/10.1007/s11042-026-21822-5)
- 一句话创新点：面向视频压缩的 INR/NVR 系统综述，明确把 NVR 与大型共享编解码器路线区分开。
- 核心方法：梳理 NVR 码率改进工作（码率设计、参数高效架构、权重剪枝/量化/熵最小化），讨论视频流部署的弱点与机会。
- 报告效果：综述类，无单一数字；结论是 NVR 解码复杂度低、视频专属模型无需大数据集，但压缩性能仍不如传统/学习型码率。
- 证据分级：B（期刊全文开放获取可查）。
- 批判性评估：覆盖较新但领域仍在快速变化，部分对比依赖各论文自报数字；对“能否实际流媒体部署”只给定性判断。
- 与 3DGS 相关性：直接（思路层面）。INR 权重剪枝/量化/熵最小化与 3DGS 属性压缩完全同构，v3 可参考其做法。

### 3.4 《A Survey of Deep Model Compression and Acceleration》

- 出处：GPC 2024 会议论文（LNCS 15225, pp. 86–106，2026 年出版）· [出版页](https://scholar.hit.edu.cn/en/publications/a-survey-ofdeep-model-compression-andacceleration/)
- 一句话创新点：从架构与算法两个维度综述 DNN 压缩加速。
- 核心方法：架构侧覆盖紧凑结构设计与神经架构搜索；算法侧覆盖静态压缩（剪枝、量化、低秩、蒸馏）与动态加速，并分析多方法集成。
- 报告效果：综述类，无单一数字；给出每类方法的优缺点与适用场景。
- 证据分级：B（LNCS 摘要/正文可查）。
- 批判性评估：结构清晰但深度有限，属于入门型综述；动态加速部分覆盖较浅。
- 与 3DGS 相关性：间接。多方法集成的分析支持 3DGS 的“剪枝+量化+熵编码”组合路线。

### 3.5 《A survey of model compression techniques: past, present, and future》

- 出处：Frontiers in Robotics and AI, 2025（Mini Review；注意：不是“无年份”论文）· [DOI](https://doi.org/10.3389/frobt.2025.1518965)
- 一句话创新点：按“浅层网络时代—深度模型时代—大模型时代”三阶段梳理压缩技术演进。
- 核心方法：覆盖剪枝、蒸馏、低秩分解、量化四类方法，强调原理与代表性工作（OBD/OBS、Deep Compression、BinaryNet、AdaRound、LLM.int8 等），并展望免微调剪枝与全量化。
- 报告效果：综述类，无单一数字；以历史脉络和代表性结果举例。
- 证据分级：B（开放获取全文可查）。
- 批判性评估：历史梳理有价值，但 Mini Review 篇幅受限，近两年工作覆盖不全；对“未来方向”的论述偏乐观。
- 与 3DGS 相关性：间接。量化历史（训练量化→后训练量化→低比特）与 3DGS 压缩路线高度平行。

## 4. 模型压缩技术

### 4.1 《MCNC: Manifold-Constrained Reparameterization for Neural Compression》

- 出处：ICLR 2025 · [arXiv:2406.19301](https://arxiv.org/abs/2406.19301) · [代码](https://github.com/mint-vu/MCNC)
- 一句话创新点：把参数空间约束到**预定义、冻结的低维非线性流形**上训练，替代 LoRA/剪枝/量化式压缩。
- 核心方法：利用过参数化网络中“好解很多”的特性，用低维流形重参数化覆盖参数空间；训练/微调全程在流形上进行，重建时只需存流形坐标。
- 报告效果：摘要未给具体数字；宣称在 CV/NLP 多种任务上相对 SOTA 在压缩率、精度或重建时间上显著更优（如 750 GB 的 Llama 3.1 405B 级别的存储动机）。
- 证据分级：A（官方代码公开；具体数字可在论文正文/仓库复核）。
- 批判性评估：动机合理，但“unprecedented compression rates”缺少摘要级量化支撑；基线是否覆盖同计算预算需看正文；流形覆盖质量对任务泛化影响需消融验证。
- 与 3DGS 相关性：间接。低维流形重参数化可类比“把高斯属性约束到低维码本/流形”，但 MCNC 面向模型权重而非场景属性，不能直接搬。

### 4.2 《TropNNC: Structured Neural Network Compression Using Tropical Geometry》

- 出处：TMLR 2026 · [arXiv:2409.03945](https://arxiv.org/abs/2409.03945) · [代码](https://github.com/kostfoto/TropNNC)
- 一句话创新点：用热带几何把网络输出表示为热带有理函数，通过约简热带多项式做结构化压缩。
- 核心方法：将线性/卷积层与 ReLU 编码为热带多项式；自适应选择保留神经元的权重以改进近似；**无训练数据**，只读权重；首次把热带几何用于卷积层，并给出已知最紧的压缩理论界。
- 报告效果：MNIST/CIFAR/ImageNet 上与 ThiNet、CUP 等强基线持平，压缩线性层时甚至超过 ThiNet；无摘要级具体压缩倍数。
- 证据分级：A（TMLR + 完整代码 + 复现命令）。
- 批判性评估：理论界有意义但实验多为“持平”，对工程用户增量有限；ImageNet 实验规模与计算设置需对照论文；无数据特性既是优点也是局限（无法利用任务先验）。
- 与 3DGS 相关性：间接。结构化/无数据压缩思想可启发高斯分组与属性排序，但热带几何与 3DGS 渲染无直接接口。

### 4.3 《Neural Network Compression by Approximate Differential Equivalence》

- 出处：arXiv:2606.01402（2026，cs.LG）· [链接](https://arxiv.org/abs/2606.01402)
- 一句话创新点：不做“删权重”，而是把**功能行为相似的神经元聚合**起来（lumping），压缩视角从参数重要性转向动力学等价。
- 核心方法：把训练好的网络编码为多项式 ODE 系统，用 Approximate Forward Differential Equivalence 找近似对称神经元并合并；单一容差参数 ε 平滑控制压缩-精度权衡。
- 报告效果：参数通常减少 **60% 以上**，测试 MSE 接近原模型；同等压缩率下，幅度剪枝与 Wanda 的 MSE 常高出几个数量级。
- 证据分级：B（正文给出数字，未见官方代码）。
- 批判性评估：验证范围是合成动力学系统 + 4 个回归基准（Abalone、交通流量、家庭用电、Protein），缺少视觉/语言大模型证据；“MSE 高几个数量级”可能由任务尺度主导，需看归一化指标；代码缺失降低可复现性。
- 与 3DGS 相关性：间接。神经元聚合对应“合并行为相似的高斯/模板化”，与 CompGS 的 K-means 码本思想同源。

### 4.4 《Fast Filter Pruning Method for Neural Network Compression》

- 出处：INFORMS Journal on Computing, 2026 · [DOI](https://doi.org/10.1287/ijoc.2024.0991) · [归档代码](https://github.com/INFORMSJoC/2024.0991)
- 一句话创新点：把滤波器剪枝建模为“最大化滤波器多样性”的信息论组合问题。
- 核心方法：两阶段剪枝；先按信息论视角度量滤波器冗余/互补性，再在给定压缩率下保留互补性最强的滤波器集合。
- 报告效果：摘要未给出具体压缩倍数/精度数字；宣称在目标压缩率下比基线剪枝保持更好预测性能。
- 证据分级：B（期刊页可查、代码已归档，但数字未在本次调研中提取）。
- 批判性评估：方法动机清晰，但“多样性”的定义与剪枝后是否需要微调、计算开销多大是关键；缺少公开摘要级数字，需读全文确认基线公平性。
- 与 3DGS 相关性：间接。多样性最大化可类比“避免剪掉冗余但互补的高斯”，与 LightGaussian 的显著性剪枝互补。

### 4.5 《A Review of Neural Network Compression Baseline Algorithms and Comparative Study Analysis》

- 出处：ICSIP 2026 会议论文（第 11 届信号与图像处理国际会议）· [出版页](https://scholar.xjtlu.edu.cn/en/publications/a-review-of-neural-network-compression-baseline-algorithms-and-co/)
- 一句话创新点：对神经网络压缩基线算法做回顾与对比研究。
- 核心方法：整理常见基线（剪枝/量化/低秩/蒸馏）并做比较分析；从标题看是综述+实验对比的混合。
- 报告效果：未找到公开摘要/数字。
- 证据分级：C（仅有会议元数据）。
- 批判性评估：价值取决于对比实验是否公平（同预算、同调参）；目前信息不足以判断。
- 与 3DGS 相关性：间接。其基线对比方法论可用于 3DGS 压缩实验设计。

## 5. 神经数据压缩（神经信号）

### 5.1 《Spatiotemporal compression reconstruction: an efficient algorithm for neural signal reconstruction》

- 出处：Measurement（Elsevier），2026 · [文章页](https://www.sciencedirect.com/science/article/abs/pii/S0263224126020373)
- 一句话创新点：把压缩感知与自编码器结合成时空压缩重建（STCR），并提出首个基于自编码器的 LFP 压缩数字电路。
- 核心方法：对多通道 LFP 信号做时空联合压缩，自编码器学习非线性重建，硬件侧给出可部署的数字电路设计。
- 报告效果：模拟 LFP 上，压缩率 28 时 STCR 重建精度比纯自编码器高 **8%**；在三种数据集上验证。
- 证据分级：B（期刊摘要给出数字，无代码）。
- 批判性评估：效果数字来自模拟信号与有限数据集；缺少与压缩感知/CS 各变体的系统消融；“重建精度 8%”的指标口径需看全文。
- 与 3DGS 相关性：弱相关。时空联合压缩思想与 4D 动态 3DGS 压缩可类比，但方法本身不可迁移。

### 5.2 《Compression detects changes in spiking neural data from cortical lesions》

- 出处：Journal of Neural Engineering, 2026, 23(3) · [DOI](https://doi.org/10.1088/1741-2552/ae555b)（另有 bioRxiv 预印本）
- 一句话创新点：把“可压缩性”当作神经信号复杂度的信息论度量（逆压缩率 ICR），用 gzip/H.264/MPEG-2 检测皮层病灶。
- 核心方法：对 Utah 阵列记录的猕猴运动皮层尖峰数据（2 只动物，病灶前 3 天 vs 病灶后 3 天）计算 ICR；与平均发放率、Fano factor、PCA/FA 对比；扫描有损压缩码率参数。
- 报告效果：病灶检测准确率 ICR **85.7%** vs 单神经元指标 78.6%（Mann-Whitney U，p<0.01）；但降维方法 100% 仍最优；ICR 在病灶后统计上更稳定。
- 证据分级：B（PubMed/期刊摘要给出完整数字；无代码）。
- 批判性评估：样本量极小（2 只动物），100% 的降维结果暗示“检测病灶”问题本身较易；ICR 相对单神经元指标的增益有统计支持，但临床可推广性存疑。
- 与 3DGS 相关性：无关。唯一可借鉴点是“压缩率/熵率作为数据统计变化的度量”，可用于 3DGS 场景差异检测，属边缘启发。

### 5.3 《Compressing Ultra-Dense Neural Recordings in Space and Time》

- 出处：IEEE Transactions on Neural Systems and Rehabilitation Engineering, 2026 · [DOI](https://doi.org/10.1109/TNSRE.2026.3716012)
- 一句话创新点：对超高通道神经记录做 **3D 时空压缩感知**，同时压缩动作电位（AP）与局部场电位（LFP）。
- 核心方法：把多通道时序信号建模为 3D 时空矩阵，用三维压缩感知（3D-CS）联合利用空间与时间相关性；在 1024 通道真实系统上验证。
- 报告效果：压缩后所有 AP 完整保留；所有 LFP 的 SSIM > 0.95；平均 SDNR 约 **24.16 dB**；总压缩率 **156×**。
- 证据分级：B（摘要给出数字，无代码）。
- 批判性评估：数字来自单一 1024 通道系统，硬件资源评估被作者称为“保守估计”；缺少与其他神经压缩方法（如自编码器）的公平对比。
- 与 3DGS 相关性：无关。属硬件侧神经信号压缩，不涉及 3DGS。

## 6. 图像/视频压缩

### 6.1 《Optimal Neural Compressors for the Rate-Distortion-Perception Tradeoff》

- 出处：NeurIPS 2025 Spotlight（并获 NeurIPS 2025 AI4NextG Workshop 最佳论文）· [arXiv:2503.17558](https://arxiv.org/abs/2503.17558)
- 一句话创新点：把经典信息论的**格点编码 + 共享抖动**引入神经压缩器，同时实现 RDP 最优性与低复杂度。
- 核心方法：用格点量化获得高空间填充效率，用共享随机性（lattice cell 上的共享抖动）满足感知约束；对“无限共享随机性”和“零共享随机性”两种设定给出可达性分析与最优性证明。
- 报告效果：实验表明共享随机性越多、格点填充越好，性能越高；摘要未给具体 PSNR/码率数字。
- 证据分级：B（理论证明 + 实验，未见公开代码）。
- 批判性评估：理论贡献扎实，但实验规模偏小（合成 + 真实数据），未给出工程级 R-D 对比表；共享随机性的实际传输/存储开销在部署中是隐性成本。
- 与 3DGS 相关性：**直接相关**。格点编码对应 SALVQ/LVQ，共享抖动对应抖动量化——这正是上一轮量化调研里 v2 的两项增强，本篇给出理论依据；感知约束也提示 3DGS 评估应从 PSNR 扩展到 LPIPS 等感知指标。

### 6.2 《Ultra-Efficient Decoding for End-to-End Neural Compression and Reconstruction》

- 出处：NeurIPS 2025 · [arXiv:2510.01407](https://arxiv.org/abs/2510.01407)
- 一句话创新点：用**低秩表示 + 矢量量化**重构解码器，把神经压缩的解码端计算瓶颈基本消除。
- 核心方法：在自编码器潜空间上做低秩分解 + VQ，解码只用轻量低秩运算；提供应用相关参数显式权衡保真度与解码开销。
- 报告效果：图像大小压缩超 **21×** 时 MSE 低至约 **3.6×10⁻³**；解码计算量大幅下降，保真度接近原方法。
- 证据分级：B（arXiv 摘要给出数字；未确认官方代码）。
- 批判性评估：“消除解码瓶颈”依赖低秩假设，复杂纹理/高频内容下的退化未见摘要讨论；MSE 单一指标不足以支撑视觉质量结论。
- 与 3DGS 相关性：**直接相关**。3DGS 的 MLP 属性解码同样可以低秩化+VQ；渲染端计算与解码端复杂度是 3DGS 部署的核心瓶颈。

### 6.3 《Extreme Compression of Adaptive Neural Images》

- 出处：ICCV 2025 Workshops（BiVision）· [arXiv:2405.16807](https://arxiv.org/abs/2405.16807)
- 一句话创新点：提出自适应神经图像（ANI），把 INR 权重压到 **4-bit**，实现神经图像极压缩。
- 核心方法：分析神经场的可压缩性；ANI 支持按推理/传输需求自适应调整精度；通过 4-bit 量化与训练策略获得 PSNR/bpp 新 SOTA。
- 报告效果：bpp 降低 **8×** 且不损失关键细节；在 PSNR/bpp 权衡上刷新 SOTA。
- 证据分级：B（arXiv 摘要给出数字；未确认官方代码）。
- 批判性评估：结果集中在图像 INR，能否推广到 3D 场景/视频 INR 未验证；4-bit 权重与“不损失细节”的表述需看具体基准（自然图像 vs 医学/文档图像差异大）。
- 与 3DGS 相关性：**直接相关**。3DGS 的 59 维高斯属性与 INR 权重一样是“网络参数”，4-bit 后训练量化/自适应精度与 QuantStage 的位宽选择高度同构。

### 6.4 《SFNIC: Hybrid Spatial-Frequency Information for Lightweight Neural Image Compression》

- 出处：CAAI Transactions on Intelligence Technology, 2025, 10(6): 1717–1730 · [DOI](https://doi.org/10.1049/cit2.70034) · [代码](https://github.com/baoyu2020/SFNIC)
- 一句话创新点：用“卷积空间分支 + FFT 频域分支 + 特征移位”实现轻量神经图像压缩，复杂度约 **200 KMACs/pixel**。
- 核心方法：空间分支提取局部信息，频域分支用 FFT 获取全局信息（避免注意力/大核的高计算量），特征移位零成本扩大感受野。
- 报告效果：不同分辨率下 R-D 与 VVC intra 及 SOTA NIC 相当，同时计算量最低（约 200 KMACs/pixel）。
- 证据分级：A（期刊全文 + 官方代码仓库）。
- 批判性评估：复杂度数字清晰，但“与 VVC intra 相当”这类结论依赖码率区间与数据集；频域分支对分辨率/内容的鲁棒性需看消融。
- 与 3DGS 相关性：间接。频域全局建模思想可类比 SH 系数的频域结构，但方法本身不适用于 3DGS。

### 6.5 《Neural Image Compression with Multi-Scale Depthwise Separable Dilated Convolution and Multi-Distribution Mixture Entropy Model》

- 出处：IEEE Data Compression Conference (DCC), 2025, p. 411 · [DOI](https://doi.org/10.1109/DCC62719.2025.00098)
- 一句话创新点：用多尺度深度可分离空洞卷积（MSDSDC）构建编解码器，配合多分布混合熵模型。
- 核心方法：把深度可分离策略引入空洞卷积以降低复杂度；多尺度空洞卷积捕获不同感受野；熵模型用多分布混合估计码率。
- 报告效果：论文摘要称“在率失真与复杂度之间取得最佳平衡”，未给出具体数字。
- 证据分级：B（会议摘要可查，无代码）。
- 批判性评估：1 页会议论文，缺少可横向比较的数字；增益可能主要来自复杂度而非 R-D，需读全文。
- 与 3DGS 相关性：间接。混合熵模型与 HAC++ 的高斯概率估计同思路，复杂度-性能平衡方法可借鉴。

### 6.6 《Exploring Asymmetric Autoencoder Architectures for Computationally Efficient Neural Image Compression》

- 出处：IEEE Design & Test, 2025/2026 · [IEEE 页](https://ieeexplore.ieee.org/document/11184613)
- 一句话创新点：探索“编码器重、解码器轻”的非对称自编码器，降低解码复杂度。
- 核心方法：剪枝解码器结构、重新分配编码/解码计算预算，保持编码端能力的同时压缩解码端。
- 报告效果：解码速度 CPU 提升最多 **46%**、GPU 提升 **18%**，码率仅有小幅增加。
- 证据分级：B（IEEE 摘要给出数字，无代码）。
- 批判性评估：思路与 3DGS“训练重、渲染轻”天然契合，但数字依赖特定硬件与模型，通用性需谨慎；码率小幅增加的量化口径未在摘要中给出。
- 与 3DGS 相关性：间接偏直接。3DGS 的渲染端本身就是“解码器”，非对称设计提示把算力集中到训练/编码侧。

### 6.7 《COLI: A Hierarchical Efficient Compressor for Large Images》

- 出处：IEEE Transactions on Radiation and Plasma Medical Sciences（Accepted/In press, 2026）· [IEEE 页](https://ieeexplore.ieee.org/document/11359320)
- 一句话创新点：用 NeRV 式 INR + 预训练-微调 + **后训练“Hyper-Compression”** 压缩大图。
- 核心方法：把 INR 压缩视为训练过程，用预训练-微调范式、混合精度训练、并行化损失加速收敛；后训练阶段用 Hyper-Compression 显著提高压缩比。
- 报告效果：NeRV 训练加速最高 **4×**；在两个医学图像数据集上以显著更低的 bpp 达到相当或更优的 PSNR/SSIM。
- 证据分级：B（期刊摘要给出数字，未见代码）。
- 批判性评估：验证域是医学影像（两个数据集），自然图像泛化未证实；“Hyper-Compression”作为新术语本质是后训练量化和熵压缩的组合，需对照既有 PTQ 基线确认增量。
- 与 3DGS 相关性：**直接相关**。其“训练+混合精度+后训练压缩”流水线与 3DGS 的 v3（QAT+剪枝+熵编码）几乎一一对应。

## 7. 其他相关研究

### 7.1 《Bridging Compressed Image Latents and Multimodal Large Language Models》

- 出处：ICLR 2025 · [arXiv:2407.19651](https://arxiv.org/abs/2407.19651) · [项目页](https://nycu-mapl.github.io/BridgingCompressionMLLM_page/)
- 一句话创新点：首个让压缩图像潜空间直接适配 MLLM 下游任务的工作（transform-neck + 替代损失）。
- 核心方法：轻量 transform-neck 把压缩潜空间对齐到 MLLM 视觉编码器中间层；训练时排除整个下游 MLLM（只保留视觉编码器）；支持冻结/联合更新/仅机器感知三种编码器模式。
- 报告效果：相对“先重建图像再喂 MLLM”，同精度下码率节省 **60–80%**。
- 证据分级：B（项目页给出数字，未见官方代码仓库确认）。
- 批判性评估：增益来自“跳过重建”这一结构性优势，属合理但不意外；适用性依赖 MLLM 视觉编码器可分离（CLIP 类），对端到端大模型未必成立。
- 与 3DGS 相关性：**直接相关（应用侧）**。压缩潜空间直接供下游任务使用，提示 3DGS 量化误差目标可换成渲染/任务损失；其“替代损失”思路可迁移为 3DGS 的渲染损失感知量化。

### 7.2 《Latent-centric Isotropic Resolution Enhancement for Expansion Microscopy Imaging via Neural Compression and Self-supervised Learning》

- 出处：bioRxiv 预印本, 2026 · [链接](https://www.biorxiv.org/content/10.64898/2026.02.09.704755v1)
- 一句话创新点：单阶段自监督 VQ-VAE 同时解决显微图像各向异性分辨率和存储两个问题。
- 核心方法：潜空间中心设计，压缩感知自监督学习；VQ 码本压缩 + 各向同性超分辨率。
- 报告效果：轴向分辨率最高提升 **8×**；数据压缩约 **128×**；有效存储降低约 **1000×**。
- 证据分级：B（预印本摘要给出数字；无代码确认）。
- 批判性评估：预印本未经同行评审；数字来自特定显微成像数据集，跨模态泛化未验证；“有效存储降低”是分辨率提升与压缩的乘积，需区分两部分的独立贡献。
- 与 3DGS 相关性：间接。VQ-VAE 潜空间压缩与 3DGS 的 SH VQ 同思路，但领域较远；可借鉴“码本+分辨率增强联合学习”的框架。

## 9. 对 3DGS 项目的启示

结合 [未来改动方向.md](未来改动方向.md) 的 v1.1 / v2 / v3 路线：

1. **v1.1 基线不动**：这些论文没有推翻“均匀 8-bit 标量量化”作为基线的合理性；RDP 论文反而说明均匀量化+熵编码的路线是数学上正确的。
2. **v2 优先做 LVQ 与抖动**：RDP 论文（格点编码+共享抖动）和上一轮调研的 SALVQ 互相印证；建议 v2 实验把“uniform → lattice VQ”和“round → dithered round”作为两个可独立消融的开关。
3. **v2/v3 的解码轻量化**：Ultra-Efficient 的非对称/低秩+VQ 思路可用于 3DGS 的 MLP 属性解码或 SH 解码，压缩同时提渲染帧率。
4. **v3 的 QAT 与后训练压缩参照 COLI/ANI**：COLI 的“预训练-微调 + 混合精度 + 后训练超压缩”几乎就是 3DGS v3 流水线（QAT + 剪枝 + 熵编码）的现成模板；ANI 证明 4-bit 权重在 INR 上可行，可作为 3DGS 低位宽实验的目标参考。
5. **把失真目标从参数 MSE 换成渲染/任务损失**：Bridging 的“潜空间面向下游任务优化”提示：3DGS 量化误差最小化的对象应该是渲染图像误差（或下游任务误差），而不是属性参数的 MSE；这也是重要性加权量化的理论动机。
6. **联合压缩（综述共识）**：剪枝+量化+蒸馏联合优化的增益已被多篇综述确认；3DGS 的 v3 “RDO 训练”应坚持组合路线而不是单点优化。
