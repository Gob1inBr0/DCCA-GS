## 0. 项目说明与本文档规则

DCCA-GS（原名 PHG / PKUGS-HAC-Gsplat）是基于 gsplat + Scaffold-GS + HAC++ 的锚点式三维高斯泼溅压缩框架，目标是零侧信息提升率失真（RD）曲线。主创新点是"渲染敏感度损失的复杂度乘子"（解码端可重算的 `mlp_complexity` 预测量化步长，训练期用渲染敏感度监督）。
